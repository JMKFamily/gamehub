# 품질 기준 (누적)

리뷰 라운드마다 QA 담당이 새 체크 항목을 추가합니다. 항목은 지우지 않고, 더 이상 적용되지 않으면 `(폐기: 이유)`를 붙입니다.
각 역할은 자기 영역 항목의 통과율과 판단을 근거로 0~10점을 매깁니다.

## 점수 산정

| 영역 | 채점 역할 | 가중치 |
|---|---|---|
| 게임 감각·핵심 루프 | benchmark-analyst | 25% |
| 밸런스·레벨 | balance-designer | 20% |
| 시각·사운드 | art-director | 20% |
| 세계관·텍스트 | lore-writer | 10% |
| 기술 품질·안정성 | qa-engineer | 25% |

게이트 (웹 버전 검수 요청 조건)
- 가중 총점 8.0 이상
- 모든 영역 6.0 이상
- blocker 0개
- 위 조건을 충족한 라운드가 나오면 요청자에게 검수를 알립니다. 5라운드 안에 못 넘으면 현재 점수와 막힌 이유를 요청자에게 보고합니다.

## 체크 항목

### 기술 품질 (qa-engineer)
- [ ] 콘솔 에러·경고 0
- [ ] 외부 네트워크 요청 0
- [ ] 360x640에서 HUD와 게임 화면이 잘리지 않음
- [ ] 6배 CPU 스로틀링에서 평균 55fps 이상
- [ ] 사망 후 0.8초 이내 재시작
- [ ] 백그라운드 복귀 시 일시정지
- [ ] 진행도·최고 기록이 새로고침 후 유지

### 게임 감각 (benchmark-analyst)
- [ ] 입력 후 1프레임 이내 점프 시작
- [ ] 점프 높이·체공·거리가 balance.json과 ±3% 이내
- [ ] 시뮬레이터 완벽 입력열이 실제 빌드에서도 클리어

### 밸런스 (balance-designer)
- [ ] 모든 레벨 클리어 가능
- [ ] 레벨 1 첫 사망 위치 중앙값이 레벨 10% 이후
- [ ] 레벨 간 난이도가 단조 증가 (봇 평균 진행도 기준)

### 시각·사운드 (art-director)
- [ ] 위험 요소와 배경 명도 대비 4.5:1 이상
- [ ] 실루엣만으로 플레이어·발판·위험 구분 가능
- [ ] 비트와 장애물 배치가 어긋나지 않음

### 세계관·텍스트 (lore-writer)
- [ ] 화면의 모든 텍스트가 10-lore.md와 일치
- [ ] 텍스트 잘림·오탈자 없음

### 대상 연령·단순성 (전 역할 공통, 위반 시 major 이상)
- [ ] 조작이 1~2가지이고 승패 조건을 한 문장으로 말할 수 있음
- [ ] 글을 읽지 않아도 첫 레벨을 시작하고 조작을 배울 수 있음 (그림·아이콘·시연 튜토리얼)
- [ ] 첫 레벨이 5~6세 수준(초보 입력 봇 기준)에서 몇 번의 시도로 클리어 가능
- [ ] 아트가 기본 도형·평면 그래픽 위주이고 강한 화풍 컨셉에 기대지 않음
- [ ] 터치 버튼 최소 48dp, 광고·구매·외부 링크가 게임 조작 영역과 떨어져 있음

### 원본 보호 (전 역할 공통, 위반 시 blocker)
- [ ] 레퍼런스 게임의 이름·캐릭터·아트·음악·레벨 배치가 없음
