# 품질 기준 (누적)

리뷰 라운드마다 QA 담당이 새 체크 항목을 추가합니다. 항목은 지우지 않고, 더 이상 적용되지 않으면 `(폐기: 이유)`를 붙입니다.
각 역할은 자기 영역 항목의 통과율과 판단을 근거로 0~10점을 매깁니다.

## 점수 산정

| 영역 | 채점 역할 | 가중치 |
|---|---|---|
| 게임 감각·핵심 루프 | benchmark-analyst | 25% |
| 밸런스·레벨 | balance-designer | 20% |
| 시각·사운드 | art-director | 20% |
| 세계관·텍스트 | lore-writer | 10% |
| 기술 품질·안정성 | qa-engineer | 25% |

게이트 (웹 버전 검수 요청 조건)
- 가중 총점 8.0 이상
- 모든 영역 6.0 이상
- blocker 0개
- 위 조건을 충족한 라운드가 나오면 요청자에게 검수를 알립니다. 5라운드 안에 못 넘으면 현재 점수와 막힌 이유를 요청자에게 보고합니다.

## 체크 항목

### 기술 품질 (qa-engineer)
- [ ] 콘솔 에러·경고 0
- [ ] 외부 네트워크 요청 0
- [ ] 360x640에서 HUD와 게임 화면이 잘리지 않음
- [ ] 6배 CPU 스로틀링에서 평균 55fps 이상
- [ ] 사망 후 0.8초 이내 재시작 (폐기: round-1 결정, 레퍼런스 감각 재현 우선)
- [ ] (round-1 추가, benchmark-analyst 제안·오케스트레이터 결정 2) 사망 판정부터 플레이어가 다시 움직이기까지 레퍼런스 실측값 ±15 % 이내이고 1.2초 이하, 자동 (입력·확인 버튼 없음). 측정 정의: 사망 틱 시각 → 다음 시도 첫 프레임 (레퍼런스 실측과 같은 정의, 오케스트레이터 결정) (runner-01: 레퍼런스 실측 1.11 ± 0.03 s, benchmark/measurements.md → 0.94~1.20 s)
- [ ] 백그라운드 복귀 시 일시정지
- [ ] 진행도·최고 기록이 새로고침 후 유지
- [ ] (round-1 추가, runner-01) 완벽 입력열이 테스트 훅뿐 아니라 일반 모드 실시간 경로(rAF 루프 + 실제 입력 이벤트, 오디오 켜짐)에서도 클리어
- [ ] (round-1 추가, runner-01) 터치 영역끼리 겹치지 않음 (모든 화면 × 4해상도, 1 px 이하 맞닿음은 제외)
- [ ] (round-1 추가, runner-01) 640x360(휴대폰 가로)에서 모든 메뉴 화면이 스크롤 없이 들어가거나, 스크롤이 필요하면 눈에 보이는 스크롤 표시가 있음
- [ ] (round-1 추가, runner-01) 6배 CPU 스로틀링에서 1% low 45fps 이상 (레벨 시작·재시작 직후 포함, DPR 3 포함)
- [ ] (round-1 추가, runner-01) 테스트 훅(`?test=1`)으로 찍은 화면이 일반 모드와 같음 (튜토리얼 문구·토스트 표시 시간이 게임 시간 기준)

### 게임 감각 (benchmark-analyst)
- [ ] 입력 후 1프레임 이내 점프 시작
- [ ] 점프 높이·체공·거리가 balance.json과 ±3% 이내
- [ ] 시뮬레이터 완벽 입력열이 실제 빌드에서도 클리어
- [ ] (round-1 추가, benchmark-analyst 제안) 수평 속도·점프 높이·체공·점프 거리가 **레퍼런스 실측값**과 ±3 % 이내 (balance.json 일치와 별개로 검사) (runner-01: 속도 10.414 t/s, 높이 약 2.14 t, 체공 약 0.43 s, 거리 약 4.5 t)
- [ ] (round-1 추가, benchmark-analyst 제안) 바닥 장애물에 무입력으로 사망할 때 플레이어–장애물 중심 간격이 레퍼런스 실측 ±0.05 t 이내. 다르게 가려면 00-benchmark "바꿀 것"에 근거를 적음 (runner-01: 0.745 t, 오케스트레이터 결정 3)

### 밸런스 (balance-designer)
- [ ] 모든 레벨 클리어 가능
- [ ] 레벨 1 첫 사망 위치 중앙값이 레벨 10% 이후
- [ ] 레벨 간 난이도가 단조 증가 (봇 평균 진행도 기준)
- [ ] (round-1 추가, balance-designer 제안) 숙련 봇(σ25) 사망이 레벨별로 한 지점(±3 t)에 30 % 넘게 몰리지 않음
- [ ] (round-1 추가, balance-designer 제안) 레벨 1의 필수 탭 수와 모든 탭의 타이밍 창이 정한 한도 안 (`verify-levels.mjs` 기준) (runner-01: 필수 탭 12~16회, 모든 창 200 ms 이상, 2연속 장애물 없음, 5~6세 대리 봇 σ70 첫 클리어 중앙값 5회 이하, 오케스트레이터 결정 5)
- [ ] (round-1 추가, balance-designer 제안) 레벨 간 최소 타이밍 창이 직전 레벨의 50 % 밑으로 떨어지지 않음
- [ ] (round-1 추가, balance-designer 제안) 레벨마다 새 기믹은 1개 이하이고 그림 카드로 소개됨 (runner-01: L1 바닥 가시·낮은 장애물, L2 블록, L3 점프 발판, 오케스트레이터 결정 4)

- [ ] (rhythm-01 1-2 추가, balance-designer 제안·오케스트레이터 결정 8) 모든 레벨에서 5~6세 대리 봇(σ70) 첫 클리어 시도 횟수 중앙값 30회 이하, 레벨 간 증가가 직전 레벨의 2배 이하 (rhythm-01: L7까지 20회 이하)
- [ ] (2026-11-17 요청자 지시, 전 프로젝트) 레벨 10개 체계에서 레벨 10의 난이도는 "기존 3레벨 곡선을 그대로 이어 갔을 때의 레벨 6" 수준으로 맞춤. 측정: 레벨 1~3의 σ70 첫 클리어 중앙값 증가 추세(기하 평균 배율)로 레벨 6 값을 외삽해 레벨 10 목표로 삼고(±20 %), 레벨 4~9는 레벨 3과 그 목표 사이를 단조로 나눔. 위 30회·2배 한도도 함께 지킴
- [ ] (2026-11-17 rhythm-01 1-3 추가, 측정 도구) 위 레벨 10 목표 항목은 `projects/rhythm-01/tools/verify-levels.mjs` 전체 실행(`--quick` 아님, 표본이 작으면 L1~L3 중앙값이 흔들림)의 B6(L10 목표 ±20 %)·B7(L3~L10 엄격 단조)으로 판정

### 시각·사운드 (art-director)
- [ ] 위험 요소와 배경 명도 대비 4.5:1 이상
- [ ] 실루엣만으로 플레이어·발판·위험 구분 가능
- [ ] 비트와 장애물 배치가 어긋나지 않음
- [ ] (round-1 추가, art-director 제안) 화면 고정 UI(튜토리얼 카드·토스트)와 게임 좌표로 그리는 그림(손가락 시연·이펙트)이 4해상도 모두에서 겹치지 않음
- [ ] (round-1 추가, art-director 제안) 글을 지운 화면(`notext`)에서 튜토리얼 그림 속 플레이어가 16 px 이상이고, 레벨 선택 카드가 글 없이 서로 구분됨
- [ ] (round-1 추가, art-director 제안) 맞닿은 블록 묶음은 바깥 둘레에만 외곽선을 그림 (runner-01: 30-art 3절 규칙 6, 내부 칸 경계 0.03 · 25 %)

### 세계관·텍스트 (lore-writer)
- [ ] 화면의 모든 텍스트가 10-lore.md와 일치
- [ ] 텍스트 잘림·오탈자 없음
- [ ] (round-1 추가, lore-writer 제안·오케스트레이터 결정 6) 플레이 중 문구(튜토리얼·토스트)는 한 문장 12자 이내(영어 6단어 이내)이고, 세계관 고유 용어 대신 화면에 보이는 모양 이름을 씀
- [ ] (round-1 추가, lore-writer 제안) 한국어 문구가 낱말 중간에서 줄바꿈되지 않고(`word-break: keep-all`), 지원 언어마다 주요 화면 스크린샷으로 잘림을 확인함
- [ ] (round-1 추가, lore-writer 제안) 튜토리얼 그림이 바로 뒤에 처음 만나는 오브젝트의 실제 색·모양과 같음

### 대상 연령·단순성 (전 역할 공통, 위반 시 major 이상)
- [ ] 조작이 1~2가지이고 승패 조건을 한 문장으로 말할 수 있음
- [ ] 글을 읽지 않아도 첫 레벨을 시작하고 조작을 배울 수 있음 (그림·아이콘·시연 튜토리얼)
- [ ] 첫 레벨이 5~6세 수준(초보 입력 봇 기준)에서 몇 번의 시도로 클리어 가능
- [ ] 아트가 기본 도형·평면 그래픽 위주이고 강한 화풍 컨셉에 기대지 않음
- [ ] 터치 버튼 최소 48dp, 광고·구매·외부 링크가 게임 조작 영역과 떨어져 있음
- (round-1 추가, 측정 정의) "초보 입력 봇"은 검증기 완벽 입력열에 정규분포 타이밍 오차를 더한 봇으로 잽니다. 5~6세 대리 = σ70 ms·탭 놓침 3 %·헛탭 2 %, 누름 100 ms. 통과 = 60세션에서 레벨 1 첫 클리어까지 시도 횟수 중앙값 10회 이내. σ값은 실제 아동 테스트 자료가 생기면 바꿉니다. 도구: `projects/runner-01/tools/qa-round.mjs --part bots` (runner-01), `projects/rhythm-01/tools/verify-levels.mjs`·`tools/sim/bots.mjs` (rhythm-01, 헛탭 포함)
