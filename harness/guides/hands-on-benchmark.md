# 실측 벤치마크 가이드 (블루스택 등 에뮬레이터)

공개 자료만으로는 점프 높이·속도·판정 같은 감각 수치가 추정에 그칩니다. 레퍼런스 게임을 직접 플레이해서 재면 훨씬 비슷하게 만들 수 있습니다.
하네스의 클라우드 컨테이너는 에뮬레이터를 돌릴 수 없으므로(하드웨어 가상화 없음) **요청자 PC**를 씁니다.

## 방식 선택

| 방식 | 요청자가 할 일 | 장점 | 단점 |
|---|---|---|---|
| A. 원격 조작 (권장) | 블루스택 설치 + Claude 데스크톱 앱 연결 | 에이전트가 직접 보고 누르며 반복 측정 | PC를 켜 두어야 함, 처음 연결 승인 필요 |
| B. 녹화 업로드 | 지정 장면을 녹화해 업로드 | PC를 계속 켜 둘 필요 없음 | 측정 장면을 놓치면 다시 요청 |

## 공통 준비 (요청자, 1회)

1. **블루스택 5** 설치: https://www.bluestacks.com 에서 받아 설치
   - 설정 → 성능: 프레임 **60fps 고정**, 고성능 모드
   - 설정 → 디스플레이: 해상도 **1920x1080 가로**(가로 게임) 또는 **1080x1920**(세로 게임), DPI 기본값
2. 블루스택 안에서 Google 계정으로 로그인하고 Play 스토어에서 레퍼런스 게임 설치
   - 유료 게임이면 구매는 요청자가 직접 합니다. 에이전트는 결제 화면을 누르지 않습니다.
3. 게임 설정에서 가능하면 **FPS 표시, 진행도 표시** 켜기 (측정 기준점이 됩니다)

## 방식 A: 원격 조작

1. PC에 **Claude 데스크톱 앱** 설치 후 로그인 (이 세션과 같은 계정)
2. 데스크톱 앱에서 컴퓨터 사용(Computer use)과 Remote Control을 켭니다. 메뉴 위치는 앱 버전에 따라 다르며, 연결할 때 에이전트가 요청을 보내면 앱에 승인 창이 뜹니다.
3. 블루스택을 실행해 게임 첫 화면까지 띄워 둡니다.
4. 채팅에 "블루스택 준비됨"이라고 알려주세요. 에이전트가 연결을 요청하고, 승인하면 화면을 보며 측정합니다.
5. 측정 중에는 마우스·키보드를 만지지 말아 주세요. 끝나면 에이전트가 알립니다.

에이전트는 측정에 필요한 플레이만 하고, 결제·계정·설정 변경·광고 클릭은 하지 않습니다.

## 방식 B: 녹화 업로드

- 녹화 도구: 블루스택 내장 녹화(우측 툴바 → 화면 녹화) 또는 OBS. **60fps, 1080p** 필수 (30fps면 프레임 단위 측정이 부정확합니다)
- 파일은 장면별로 나눠 `장면번호_설명.mp4`로 저장하고, 대화에 첨부하거나 클라우드 드라이브 공유 링크를 주세요.

## 측정 장면 목록 (벤치마크 담당자가 게임마다 채움)

벤치마크 담당자는 `projects/<slug>/HUMAN_TASKS.md`에 아래 형식으로 장면을 정의합니다.

| # | 장면 | 하는 방법 | 재는 값 |
|---|---|---|---|
| 1 | 평지 제자리 점프 5회 | 장애물 없는 구간에서 0.5초 간격 탭 | 점프 높이(블록 대비), 체공 프레임 |
| 2 | 아무 입력 없이 5초 달리기 | 시작 직후 입력 없음 | 화면 스크롤 속도(블록/초) |
| 3 | 첫 장애물에 일부러 사망 3회 | 늦게 탭 | 사망→재시작까지 프레임, 판정 여유 |
| 4 | 첫 레벨 끝까지 플레이 (실패 포함) | 평소처럼 | 레벨 길이, 난이도 곡선, 진행도 % 표시 방식 |
| 5 | 메뉴 전체 둘러보기 | 모든 버튼 1회씩 | 화면 구성, 메뉴 흐름, 광고·수익화 위치 |

## 측정 방법 (에이전트)

- 영상에서 프레임을 뽑아(ffmpeg) 블록 한 칸 크기를 픽셀로 잰 뒤 모든 거리를 **블록 단위**로 환산합니다.
- 시간은 **프레임 수 ÷ 60**으로 계산하고, 같은 장면을 최소 3회 재서 평균과 편차를 적습니다.
- 결과는 `00-benchmark.md`의 수치 표에 "실측(n회 평균 ± 편차)"으로 표시하고, 추정치를 대체합니다.
- 측정에 쓴 프레임 이미지는 `projects/<slug>/benchmark/frames/`에 저장하되, **레퍼런스 게임 화면은 분석용으로만 쓰고 공개 배포물(games/, 스토어)에는 절대 넣지 않습니다.**
