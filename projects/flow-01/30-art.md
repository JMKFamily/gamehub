## 1. 아트 방향

**한 줄**: 밝은 소프트 그라디언트 바탕 위 흰 둥근 판, 손가락을 따라 **통통한 둥근 색 띠**가 칸을 지나가고, 짝을 만나는 순간 **톡 튀며 칸이 그 색으로 물드는** 조용한 미니멀 퍼즐.

레퍼런스 키워드(특정 게임이 아닌 일반 디자인 말): 무광 평면, 둥근 모서리 카드, 넓은 여백, 스프링 감속 모션, 색종이 테이프, 파스텔 바탕 + 또렷한 전경.

- **약한 아트**: 기본 도형(원·둥근 네모·둥근 선·세모·별·하트·초승달)만. 캐릭터·얼굴·질감·화풍 없음. 판에서 움직이는 것은 선과 점뿐.
- **모던함은 여기서**: ① 손에 붙는 선 머리(입력 다음 프레임, 머리가 손가락 쪽으로 반 칸 늘어남) ② 연결 순간 스프링 튐 + 밝은 띠 + 칸 물들임 + 음 하나 + 짧은 진동 ③ 넓은 여백·한 화면 한 할 일 ④ 색 정리(전경 6색만 진하고 나머지는 옅은 중성색) ⑤ 끊김 없는 화면 전환(겹쳐 흐려짐).
- **하지 않는 것**: 검은 바탕, 네온·발광·글로우, 얇은 격자선, 화면 흔들림·번쩍임, 빨간 ✕·버저, 판 위 글자 팝업, 원작 아이콘·로고·효과음·레벨 판, 참고 모던 게임(10-1 R1~R4)의 지도 그림·캐릭터·아이콘·색 배합.

### 1-1. 원작과 다른 점

| 항목 | 원작 (기능만 기술) | 우리 |
|---|---|---|
| 바탕 톤 | 검은 바탕 | **밝은 2색 세로 그라디언트**(레벨마다 아침 → 노을 색 방향, 움직이지 않음) + 그 위 **흰 둥근 판 카드** |
| 격자 | 칸 경계 선 격자 | 선 없음. 칸마다 **옅은 둥근 타일**(틈 0.1칸) + 가운데 작은 점(= 칠할 곳 표지) |
| 선 모양 | 칸 가운데를 잇는 선, 어두운 바탕에서 빛나 보이는 색 | **칸 폭 60 % 통통한 띠**, 둥근 끝·둥근 꺾임, 무광 단색. 연결되면 지나간 칸 타일이 같은 색 옅은 톤(tint)으로 물듦 |
| 점 모양 | 큰 단색 원 | 원(0.74칸) **+ 흰 모양 표지 6종**(하트·동그라미·별·세모·초승달·네모, 처음부터 켜짐). 연결되면 바깥 **고리** 생김 |
| 연결 피드백 | 소리·진동 | 스프링 튐 180 ms + 밝은 띠 300 ms + 작은 원 조각 + 음 사다리 + 판정 이름(판 밖) |
| 빈칸 남음 | 끝나지 않음(글 없음) | 빈칸 타일만 따뜻한 노랑 테두리로 **한 번 숨 쉼**(최대 3회) |
| 레벨 선택 | 팩별 번호 격자 | 곡선 길 위 10노드 **진행 지도**, 완료 노드 = 그 판 완성 미니 그림 |
| 진행 숫자 | 이동 수·최고 기록 숫자 | 플레이 중 늘 떠 있는 숫자 없음(쌍 점 줄만). 연결 순간에만 판정 이름 아래 작은 **판 채움 %**(연결된 쌍이 칠한 칸만, 이름과 함께 나타나고 사라짐, G3). 결과에 별 + 작은 **한 번에 이은 쌍 %**(G2) |

### 1-2. 참고 모던 패턴(00-benchmark 10-1)과의 선

가져온 것은 **패턴**뿐입니다: 잇기가 음을 쌓음(R1) · 굵은 둥근 선 = 칠하기, 판 밖 아이콘 버튼 최소 구성(R2) · 실패·타이머 없는 흐름, 완성 순간 판 전체 물결(R3) · 글 없는 아이콘 + 시연 + 소리(R4). 각 게임의 바탕색·점 모양·지도 그림·아이콘 모양·효과음은 쓰지 않았습니다(우리 점은 "원 + 흰 표지", 지도는 기본 원·둥근 네모 노드, 소리는 C 장조 5음 사다리를 직접 합성).

## 3. 형태 언어 (실루엣만으로 구분)

| 물체 | 모양 | 크기(칸 = 1) | 구분 규칙 |
|---|---|---|---|
| 판 | 흰 둥근 카드, 둘레 1.5 px `boardEdge`, 그림자는 투명도 ≤ 0.10 흐림 하나 | 칸 바깥 0.06, 모서리 0.30 | 바탕보다 늘 밝음 |
| 빈칸 | 옅은 둥근 타일 + 가운데 작은 점 | 안쪽 여백 0.05, 모서리 0.22, 점 지름 0.07 | **가운데 점 = 칠할 곳** |
| 구멍 칸 | 판 안: 판 카드에서 도려내 바탕이 보임 + 둘레 선 / **판 둘레에 닿으면 외곽선을 오목하게 파냄**(판 여백까지 빼서 바탕이 판 밖과 이어짐, 안쪽 모서리 반경 0.22칸, 둘레 선이 파낸 선을 따라감) | 타일과 같은 둥근 네모 | 점 없음·바탕 색 → "칸이 없는 자리"(lore 4절). 규칙 원본 `layout.json hole_rule`, 목업 `mockups/board-l06.svg`·`board-l08.svg` |
| 칠한 칸 | 타일이 그 쌍 tint로 | 같음 | 연결된 쌍만 |

### 4-3. 판정 이름·% 자리 (00-benchmark 13-2, lore 6-1)

- **판 밖에만 그립니다.** 세로: 판 윗변 바로 위 띠, 가로 가운데 = 방금 연결된 짝 점의 x(화면 안으로 자름). 가로: 짝 점의 열 x로 기둥을 고름 — **2x + 1 < 판 폭이면 왼쪽 기둥, 아니면 오른쪽 기둥**(폭 5 판의 가운데 열 x = 2는 오른쪽 기둥, L3~L6의 가운데 열 점 5개, 검사 J1). 세로 가운데 = 그 점의 y(자리 범위로 자름).
- 이유: 13-2·lore 6-1은 "짝 점 위쪽, 판 가장자리면 안쪽"을 권했지만, 판 안에 그리면 6x6에서 이름(114 px)이 칸 2개를 가려 "다른 선·점을 가리지 않음"과 동시에 지킬 수 없습니다. 세로 화면에서 손은 아래에서 오므로 판 위쪽 띠는 손에 안 가리고, 같은 x에 떠서 "어느 점의 판정인지"가 이어집니다. 연결 순간의 **점 자체 반응**(튐·고리·조각)이 판 안의 국소 피드백을 맡습니다. → **1-2 교차 리뷰 안건 A1**(lore와 맞춤).
- 등급 단서 순서: **주 단서 = 튐 세기(1.22/1.18/1.14)·조각 수(8/6/4)·연결음 음 개수(3/2/1, 7절)**, 글자 크기는 보조. 글자: 1단 38 px·2단 33 px·3단 28 px(× k, 1-2에서 34/31/28 → 단계 차를 벌림, 3단 하한 28 유지), 색 = 그 쌍 shade + 흰 테두리 3 px. 2·3단도 회색·빨강 없음.
- %(F4·G3 확정): 이름 아래 0.55배(최소 15 px), `inkSoft`. 값 = **판 채움 % = 연결된 쌍이 칠한 칸 / 판 칸**(이어지지 않은 선·끄는 중인 선의 칸은 세지 않음 → 화면 tint 칸과 숫자가 늘 같음, G3). **이름과 함께 나타나고 함께 흐려짐**(`judge.pct_lifetime: with_judge_name`, 시간축은 balance가 정한 판정 이름 시간과 같음). `aria-hidden`(대체 글 키 없음). 결과 %(한 번에 이은 쌍 %)와 헷갈리지 않게 플레이 % 앞에는 작은 "칠한 칸" 그림(`icon-filled.svg`, 0.6배), 결과 % 앞에는 "한 번에 이은 선" 그림(`icon-one_go.svg`).
- 시간: 나타남 + 튐 80 ms → 유지 400 ms → 흐려짐 150 ms(djmax 7-3). 새 연결이 오면 그 프레임에 바꿔 그림(표시 하나). **판을 끝낸 마지막 연결의 이름은 완료 연출 시작(+150 ms)부터 150 ms에 흐려짐**(lore 6-3). 낭독 안 함.

### 4-4. 쌍 점 줄 (콤보 대응, 13-2 C1)

## 7. 사운드 (`assets/sound.json`, 검사 `assets/check/sound-check.mjs`)

- 모두 Web Audio 합성(sine·triangle만, 잡음·사각파 없음), 외부 음원 0. 원작 효과음·음형을 쓰지 않고 패턴만("잇는 동작이 음을 쌓는다", R1).
- **연결음 사다리**: C 장조 5음계 C5 D5 E5 G5 A5 C6. 연결음 음 높이 = 사다리[지금 이어진 쌍 수 − 1] → 판이 찰수록 음이 오르고(진행이 숫자 없이 들림), 풀리면 내려가 다음 연결이 같은 음을 다시 냄. 어느 순서로 이어도 5음계라 어울림.
- 등급은 **음 개수 + 크기 계단**으로(G4, 1-2 2차): 1단 = 사다리 음 → 45 ms 뒤 +5도 → 90 ms 뒤 +옥타브(**3음 올림**), 2단 = 사다리 음 → 45 ms 뒤 +옥타브(**2음**), 3단 = 사다리 음 **1개**. 크기 계단: 같은 음끼리 등급 사이 RMS 차 ≥ 1.5 dB(측정 최소 2.04 dB), 최고값 약 −7.7 / −9.2 / −10.7 dBFS. 1차의 "층 수(35 ms 반짝임)" 방식은 RMS 차가 0.42~0.78 dB로 들을 수 있는 차이 밑이라 바꿈. 길이 합은 그대로라 다음 연결과 안 겹침.
- 배경음: 같은 C 장조 화음 4개(C → Am → F → G, 4 s마다, 박·리듬 없음)를 아주 작게, 기본 켬. 퍼즐은 생각하는 놀이라 박이 강한 곡을 쓰지 않음.

### 13-5. 그리기 규칙 — 성능 S1·S2 (`layout.json render`, 개발 전달)
1. 바탕(그라디언트 + decor)은 레벨 시작 때 한 번(CSS 배경 또는 오프스크린). **매 프레임 전체 화면 다시 그리기 금지**.
2. 판(카드·타일·구멍)은 오프스크린 캐시 1장, tint는 바뀐 칸만. 점·표지·조각·빛 번짐은 미리 그린 비트맵 + `globalAlpha`·transform.
3. 판정 이름 3등급 × 쌍 색은 레벨 시작 때 비트맵(흰 테두리 포함) → **매 프레임 strokeText·shadowBlur·글자 테두리 금지**. % 는 값이 바뀔 때만.
4. 카드·지도 미니 그림·실루엣·별·아이콘 SVG는 부팅(지도는 첫 진입 전 유휴 시간)에 `<img>`(Blob URL) + `decode()`로 래스터해 재사용 — innerHTML SVG 금지. 카드 닫힘은 opacity·transform만.
5. 바뀐 것이 없으면 rAF에서 그리지 않음. 캔버스 DPR 최대 2. 타이틀 첫 탭 오디오 잠금 해제와 지도 그리기는 다른 프레임.
6. 에셋 SVG는 그라디언트·필터 없음(검사).
