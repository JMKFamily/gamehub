# 1-1 게임 이름 후보 충돌 확인

- 날짜: 2026-11-17
- 역할: benchmark-analyst
- 프로젝트: flow-01
- 단계: 1-1 (lore-writer 보조)

## 요청 받은 일
lore-writer는 웹 검색 도구가 없어, 게임 이름 후보 3개가 이미 있는 이름과 겹치는지 확인하지 못했습니다. 오케스트레이터가 그 확인을 맡겼습니다. 대상은 앱 스토어·Google Play·일반 웹에서 같거나 매우 비슷한 게임·앱이 있는지입니다. 후보는 ① Pairpaint / Pair Paint / 짝꿍색칠(추천) ② Tintrail / 색깔길 ③ Fillmates / 칸칸짝꿍입니다.

## 한 일
1. 웹 검색을 6회 했습니다. 영문 이름별로 3회, 세 영문 이름을 묶어 Google Play 대상으로 1회, 한글 이름 3개를 묶어 1회, 앞선 1-0 조사 결과도 함께 대조했습니다.
2. 결과를 같은 이름·비슷한 이름·장르가 겹치는지로 나눠 판정했습니다.

### 이름별 판정

| 후보 | 같은 이름 | 비슷한 이름(가장 가까운 것) | 판정 |
|---|---|---|---|
| ① Pairpaint / Pair Paint | 못 찾음 | "PairDrawing"(둘이 함께 그리는 드로잉 앱, 앱 정보 사이트 등재). 색 맞추기 색칠 앱("Coloring Match", "Paint Color Match") 등 일반 낱말 조합 | **충돌 없음(낮은 위험).** 장르(선 잇기 퍼즐)가 겹치는 같은·비슷한 이름은 없습니다. 원작·1-0 참고 게임 이름과도 닮지 않았습니다 |
| ① 짝꿍색칠 | 못 찾음 | 숫자 색칠·자유 색칠 앱(일반 낱말 "색칠") | 충돌 없음 |
| ② Tintrail | 못 찾음 | **"Tint"**(칠해서 푸는 퍼즐 게임, 애플 아케이드 계열), "Tint 3D"(미로 칸을 칠하는 캐주얼 게임), "Color Paint - fill the trail"(Google Play, 약 17만 설치), "follow.trail"(점 길 따라 지우는 퍼즐) | **주의(중간 위험).** 같은 이름은 없습니다. 다만 앞부분 "Tint"가 같은 "칠하기 퍼즐" 장르의 기존 게임 이름이고, "trail"도 칸 칠하기 앱 이름에 쓰였습니다. 상표 충돌로 단정할 근거는 없지만 혼동될 수 있습니다 |
| ② 색깔길 | 못 찾음 | 두 점을 길로 잇는 아동 퍼즐("타이니 로드", 한국 앱스토어)이 장르상 가깝지만 이름은 다름 | 충돌 없음 |
| ③ Fillmates | 못 찾음 | "Fill" 계열 칸 채우기 앱이 아주 많음(Fill, Fill More!, Fill Fill, FillKo, Fill Master 3D, Fill People, Fill and Flow 등) | **같은 이름 충돌 없음, 단 흔함.** "Fill-"로 시작하는 칸 채우기 퍼즐이 많아 스토어 검색에서 눈에 띄기 어렵습니다. "Fill and Flow"는 원작을 떠올리게 하는 조합이라, "Fill"과 "flow" 계열 낱말을 함께 쓰지 않는 편이 안전합니다 |
| ③ 칸칸짝꿍 | 못 찾음 | 없음 | 충돌 없음 |

- **권장**: lore-writer의 추천 ①(Pairpaint / 짝꿍색칠)이 가장 안전합니다. ②는 "Tint" 계열 퍼즐과 혼동될 수 있어 뒷순위로 둡니다. ③은 충돌은 없지만 흔한 "Fill-" 이름 무리에 묻힙니다.
- 최종 확정은 lore-writer·오케스트레이터가 합니다. 출시 단계(4단계)에서는 요청자가 상표 검색(KIPRIS·USPTO 등)을 따로 해야 합니다. 이번 확인은 웹 검색 수준입니다.

## 검증 결과
- 검색 6회 모두에서 세 이름의 **정확히 같은 이름**은 나오지 않았습니다.
- 한계
  - 이 검색 도구는 정확 일치 연산자를 보장하지 않고, 미국 기준 결과입니다.
  - 스토어 안 검색(play.google.com·앱스토어 앱 안 검색)은 직접 하지 못했습니다(페치·스토어 조작 없음).
  - 작은 인디 앱이나 최근 앱은 검색 색인에 없을 수 있습니다.
  - 그래서 "못 찾음"은 "없음을 증명"이 아닙니다.

## 규칙 준수 확인
- [x] 원본 보호: 후보는 원작·참고 게임 이름과 닮지 않았습니다. ③에 "flow" 계열 낱말을 붙이지 말라는 주의를 적었습니다.
- [x] 게임 선정·설계 원칙: 해당 없음(이름 확인만)
- [x] 결제·광고 클릭·계정 변경 없음(검색만)
- [x] 내 보고서와 README 한 줄만 썼습니다. 10-lore.md 등 다른 역할 파일은 수정하지 않았고, git은 쓰지 않았습니다.

## 다른 팀에 줄 인사이트
