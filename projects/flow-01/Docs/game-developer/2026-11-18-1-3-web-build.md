### UX 요청자 지시(2026-11-18) 구현 표

| 지시 | 구현 | 위치 |
|---|---|---|
| ① 6색 짝마다 모양 표지로 색 없이도 구분 | 판의 모든 점 = 쌍 색 원 + 흰 모양 표지(palette `mark`: 하트·동그라미·별·세모·달·네모, layout `marks.paths`), 쌍 점 줄에도 같은 표지(아직 = 흰 원 + 색 테두리·색 표지 / 이어짐 = 색 원 + 흰 표지), 튜토리얼 손가락은 실제 첫 쌍(빨강·하트), 카드 그림도 같은 표지. 쌍 색은 레벨 `color_slot` → palette 순서라 10레벨 내내 같은 쌍 = 같은 색·같은 모양 | render `drawMark`, main `layoutPlay`·`drawPlay` |
| ② 막힌 상태·"왜 안 되는지" | (가) 다른 색 점으로 못 들어감: 선 머리가 그 점 앞(축 방향 최대 0.5칸)에서 멈추고, 막은 점이 1.08배 숨 쉼 + 그 점 색 고리가 한 번 옅게 퍼짐(소리 없음 — art 규칙, D3). (나) 다른 색 선 위로 가면 잘림: 잘린 부분이 200 ms 옅어지며 가늘어짐 + `cut` 소리, 같은 드래그에서 되돌아오면 되살아남. (다) 다 이었는데 안 끝남: 빈칸만 gapGlow 테두리로 숨 쉼 + `gap_hint` 부드러운 소리(3회), 그림을 두 번 본 뒤 3번째에만 `gap_left` 글(보조), 스크린 리더는 1회. (라) 할 수 없는 버튼: 되돌리기·처음부터가 할 것이 없을 때 흐리게 + aria-disabled(D5), 잠긴 지도 노드는 회색 원·누름 무반응(겁주는 자물쇠 없음). (마) 빈칸을 눌렀을 때: 안 이은 점들이 숨 쉼 = "점에서 시작"(D4). 빨간 ✕·경고음·흔들림 없음 | main `handleEvents`·`emptyPress`·`updatePlay`·`syncPairs` |
