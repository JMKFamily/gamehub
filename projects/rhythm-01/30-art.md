## 1. 아트 방향 — **round-3에서 대체(16절)**

**한 줄**: 어두운 단색 바탕 위에 **원 하나, 공 하나, 별 몇 개**. 평면 단색 면 + 짙은 잉크 외곽선, 그라데이션·발광·질감 없음. "도는 공이 별에 닿으면 톡"이 사진 한 장으로 읽히는 것이 목표입니다.

레퍼런스 키워드 (특정 게임이 아닌 일반 사물): 부엌 타이머 다이얼, 보드게임 말판의 원형 길, 장난감 북, 색종이 오리기.

**원본 보호: 원형 판정 UI를 닮지 않기 위해 하지 않는 것**
| 하지 않는 것 | 대신 하는 것 |
|---|---|
| 표식 둘레에서 **오므라드는 접근 고리** | 시간은 오직 "공이 원 위를 얼마나 남았나"로 보임. 별 주변에 시간 고리 없음 |
| 숫자가 적힌 원형 표식, 순서 번호 | 별은 모두 같은 모양·크기, 숫자 없음 |
| 가운데에서 바늘(시곗바늘·레이더 선)이 도는 방식 | 바늘 없음. **공이 궤도 위를 직접 굴러감**. 가운데는 멈춰 있는 북 |
| 가운데에서 바깥으로 날아가는 노트, 여러 겹 원형 레인 | 레인은 원 1개. 별은 제자리에서 나타나고 움직이지 않음 |
| 네온 외곽선·발광·검은 배경 위 형광색, 판정 글자 팝업 | 평면 단색, 판정은 빛살 개수·크기·소리 층으로만 |
| 기존 리듬 게임 특유의 아이콘(음표 모양 버튼, 원형 재생 버튼 등) | 메뉴 아이콘도 기본 도형 조합(5-6절). 다음 = 가로 화살표, 시작·계속 = 공 + 궤도 조각 |

컨셉을 약하게 두는 이유: 재미는 박 판정과 즉시 재시도에서 나옵니다. 장식은 레벨별 바탕 색과 **정지 실루엣(bgFar 색 기본 도형 3개 이하, 2-2·3절)**뿐이고, 이를 모두 지워도 플레이가 그대로 성립해야 합니다. 실루엣은 움직이지 않고, 별 모양을 쓰지 않습니다(치는 별과 헷갈림).

**퇴장 0.25박 그리기 규칙 (round 3 R14, round-2 리뷰 N2 "사라짐 끝에 굵은 크림 고리 번쩍임" 해결)**
- 배율 k: 작아짐 구간 `[shrinkStart, gone)`에서 `q = (x − shrinkStart) / (gone − shrinkStart)`, **k = 1 − q²**(북채 크기 배율과 같은 값, 하나만 계산해 같이 씀). 구간 앞 k = 1, gone 이후 k = 0.
- 앞 상태(점선 마디) = 궤도 띠 + 가는 테두리 2줄 + **띠 가운데 점선**(trackEdge, 굵기 = 띠 × 0.35, 32칸 중 45 % 선) + 북 면 + **북 테두리 점선**(trackEdge, 굵기 = 북 외곽선 굵기, 대시 8 / 빈칸 6). 뒤 상태(실선) = 궤도 띠 + 가는 테두리 2줄 + 북 면 + **북 테두리 실선**(outline 색, 같은 굵기).
- 전환 중 각 요소:
  | 요소 | 굵기 | 불투명도 | 대시 무늬 |
  |---|---|---|---|
  | 띠 가운데 점선 | 띠 × 0.35 × **k** | **k** | 선 길이·빈칸 길이 **그대로**(빈칸 × k 금지) |
  | 북 테두리 점선 | 북 외곽선 × **k** | **k** | 8 / 6 **그대로** |
  | 북 테두리 실선(뒤 상태) | 북 외곽선 그대로 | **1 − k** (점선 아래에 먼저 그림) | 실선 |
  | 궤도 띠·가는 테두리 2줄·눈금·12시 표식 | 그대로 | 1 | 그대로(앞뒤 상태 모두에 있음) |
  | 북채 | 크기 × k (5-4 표) | 1 | — |

### 12-3. 크기와 효과음

|---|---|---|
| 아이 탭 북 T/T1 | **−6 dB** (−6.6 / −16.4) | 가장 큰 소리 = 내가 낸 소리 |

### 12-4. 합성 파라미터 (1-3 구현용, 12-2·12-3을 한 표로 확정, round 2 게인 수정 — 값의 원본은 `assets/sound.json` `sounds`)

공통 규칙
- **게인 dB(sound.json `db`) = 그 소리의 층마다 곱하는 기준 게인**(dBFS). 선형 = 10^(dB/20). 층(layer)의 상대 크기는 괄호 안 배율(그 소리 게인에 곱함). round 1까지의 정의 "게인 dB = 그 소리 하나의 최고 크기"는 **폐기**: 층이 겹치면 실제 최고값이 1~2 dB 커져(round-1 리뷰 이슈 7) 크기 순서가 깨졌습니다.
- **크기 규칙은 렌더 측정값으로 판단(층 합산 최고값 기준)**: 소리 하나를 빌드 `AudioOut.play` 그대로 마스터 컴프레서 뒤까지 오프라인 렌더(48 kHz, 음 높이 있는 소리는 10레벨 근음 전부, 그중 가장 큰 값)한 최고값 `peak_db`와 소리 시작 100 ms RMS `rms_db`를 sound.json에 적어 둡니다.
  - ① **아이 탭(T·T1·통과 탭 중 가장 작은 최고값)이 다른 모든 효과음(버스 sfx)의 최고값보다 1 dB 이상 큼**
  - ② **아이 탭 RMS(셋 중 최소) − 둥둥이 Tt RMS ≥ 6 dB**
  - 검사 `PLAYWRIGHT_CORE=<playwright-core> node assets/sound-check.mjs --render`(설치된 Edge 헤드리스, 서버 불필요). 현재 ① **1.89 dB**(탭 −6.58 vs 가장 큰 효과음 클리어 −8.46), ② **6.40 dB**(−16.36 vs −22.75). 게인이나 합성값을 바꾸면 다시 돌려 `--write`로 측정값을 갱신합니다.
- **엔벨로프**: A = 0에서 게인까지 선형 오름(ms). **감쇠 X ms** = A 끝에서 `exponentialRampToValueAtTime(0.001 × 게인, t + X)`(−60 dB), 끝나면 노드 정지. ADSR 표기는 D 동안 S(게인 배율)까지 지수 하강, 음 길이 끝에서 R 동안 0.001까지.
- **주파수 미끄럼** "a→b Hz c ms" = `frequency.setValueAtTime(a)` + `exponentialRampToValueAtTime(b, t + c)`.
- 노이즈 = 1 s 백색 잡음 버퍼 1개를 만들어 재사용(`Math.random()*2−1`).
- 버스: **효과음 버스**(설정 효과음) = 탭 북·둥둥이 북·방울·똑딱·실패·클리어·기록·메뉴. **음악 버스**(설정 음악) = 가이드 킥·베이스·패드·멜로디·셰이커. 켜고 끌 때 50 ms 램프.

- **별 시각에 새 음을 시작하지 않음**: 그 마디 판정 별 자리와 같은 자리의 음은 같은 마디 안에서 −1 → +1 자리 순서로 (별·다른 멜로디 음이 없는 곳으로) 옮기고, 둘 다 안 되면 그 음을 뺍니다. 동기 자체를 별이 거의 없는 엇박(자리 1·3·5·7, 지금 레벨 데이터에서 자리 7은 별 0개)에 많이 두어 옮김이 적습니다.
- 악기 = `melody[동기 음 번호 % 악기 수]`(L10 O·X 번갈아). 3단계부터 화음 = 도수 + 2를 −24 dB로 같이. outro 첫 마디 자리 0에 도수 0을 8분 4개 길이로(마무리 음).
- 검사 `node assets/sound-check.mjs`(지금 레벨 데이터로 배치를 다시 계산): **멜로디 음 168개, 별 시각에 시작 0개**, 옮김 17, 뺌 2(L10). balance가 R3로 L4~L10 무늬를 바꿔도 규칙이 자리를 피하므로 동기는 그대로 쓰고, 검사만 다시 돌립니다.
- 1-3 자리 표시(`melody_placeholder`, degree_walk)는 **폐기**(D10 임시 승인 종료). sound.json에 참고로만 남겨 둡니다.

- **크기 순서(오프라인 렌더, 빌드 `AudioOut.play`)**: 콤보 화음 최고값 **−13.5 dB**(10·20 둘 다) → 아이 탭 −6.6 dB보다 **6.9 dB 작음**(기준 1 dB). 규칙 ① 탭 − 다른 효과음 최고(클리어 −8.46) = **1.90 dB ≥ 1**, ② 탭 RMS − Tt RMS = **6.40 dB ≥ 6**. `sound.json`의 `peak_db`·`rms_db`는 이번 빌드 렌더값으로 다시 적음(rhythm-02 insights "소리 표 원본 = 빌드 렌더").
- 콤보가 길어질 때 곡에 악기 층을 더하는 안(00-benchmark 8-8)은 쓰지 않음: djmax 4-4의 단계 화음으로 대체(층이 늘면 탭 소리 순서·별 시각 비우기 검사가 레벨마다 바뀌고, 실패 때 층이 한꺼번에 빠지는 것이 "벌"처럼 들릴 수 있음).
