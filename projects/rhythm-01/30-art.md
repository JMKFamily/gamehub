## 1. 아트 방향

**한 줄**: 어두운 단색 바탕 위에 **원 하나, 공 하나, 별 몇 개**. 평면 단색 면 + 짙은 잉크 외곽선, 그라데이션·발광·질감 없음. "도는 공이 별에 닿으면 톡"이 사진 한 장으로 읽히는 것이 목표입니다.

레퍼런스 키워드 (특정 게임이 아닌 일반 사물): 부엌 타이머 다이얼, 보드게임 말판의 원형 길, 장난감 북, 색종이 오리기.

**원본 보호: 원형 판정 UI를 닮지 않기 위해 하지 않는 것**
| 하지 않는 것 | 대신 하는 것 |
|---|---|
| 표식 둘레에서 **오므라드는 접근 고리** | 시간은 오직 "공이 원 위를 얼마나 남았나"로 보임. 별 주변에 시간 고리 없음 |
| 숫자가 적힌 원형 표식, 순서 번호 | 별은 모두 같은 모양·크기, 숫자 없음 |
| 가운데에서 바늘(시곗바늘·레이더 선)이 도는 방식 | 바늘 없음. **공이 궤도 위를 직접 굴러감**. 가운데는 멈춰 있는 북 |
| 가운데에서 바깥으로 날아가는 노트, 여러 겹 원형 레인 | 레인은 원 1개. 별은 제자리에서 나타나고 움직이지 않음 |
| 네온 외곽선·발광·검은 배경 위 형광색, 판정 글자 팝업 | 평면 단색, 판정은 빛살 개수·크기·소리 층으로만 |
| 기존 리듬 게임 특유의 아이콘(음표 모양 버튼, 원형 재생 버튼 등) | 메뉴 아이콘도 기본 도형 조합(5-6절). 다음 = 가로 화살표, 시작·계속 = 공 + 궤도 조각 |

컨셉을 약하게 두는 이유: 재미는 박 판정과 즉시 재시도에서 나옵니다. 장식은 레벨별 바탕 색과 **정지 실루엣(bgFar 색 기본 도형 3개 이하, 2-2·3절)**뿐이고, 이를 모두 지워도 플레이가 그대로 성립해야 합니다. 실루엣은 움직이지 않고, 별 모양을 쓰지 않습니다(치는 별과 헷갈림).

## 2. 팔레트

원칙: **환경 색(바탕·실루엣·궤도·북·카드 색)만 레벨마다 바뀌고, 공·별·외곽선·HUD 색은 10레벨 공통**입니다. 처음 보는 레벨에서도 "노란 별 = 칠 것, 하늘색 공 = 나"를 다시 배우지 않습니다. 10레벨 모두 **어두운 바탕 + 밝은 전경**(결정 4, 대비 우선). **노랑(`star`)은 치는 별과 그 판정 빛살에만** 씁니다. 등급·최고 기록 표시·카드 색에는 쓰지 않습니다(결정 2).

## 3. 형태 언어 (테마와 무관하게 고정)

| 역할 | 실루엣 규칙 | 금지 |
|---|---|---|
| 나(공) | 완전한 원 1개 + 왼쪽 위 작은 흰 점. 뒤로 작은 원 3개 꼬리 | 별·뾰족한 모양, 얼굴 |
| 칠 것(꽉 찬 별) | 꼭짓점 5개 별, 둥근 모서리, 꽉 찬 노랑 + 검은 외곽선 | 다른 크기의 별 섞기. **반박 별도 정박 별과 같은 크기**(크기는 판정 단계 신호로 쓰고, 작은 별은 맞추기 어려워 보임) |
| 볼 것(속 빈 별) | 같은 별 외곽선만, 두께 = 별 반지름 0.16 | 반투명 면(어두운 바탕에서 탁해짐) |

### 4-4. 터치와 엄지

- **화면 전체가 탭 영역**입니다(일시정지 버튼 48×48 제외).
- 세로 화면: 궤도 아래 빈 곳에 **엄지 받침**(둥근 네모, bgFar 면 + trackEdge 50 % 점선 테두리). 범위: 위 = `max(cy + R + 2.05·별r + 12, 0.70·H)`, 아래 = `H − 16 − safeBottom`, 좌우 16. 받침 밖을 쳐도 똑같이 판정. 실루엣은 받침 밑에 그리지 않습니다.
- 가로 화면: 받침 없음.
- **레벨 1 손가락 그림 위치**: 세로 = 엄지 받침 가운데, 가로 = 오른쪽 아래 구석(궤도 바깥, `x = W − 72`, `y = H − 64`). 손가락은 북채가 아직 보이는 마지막 1박에 나타나므로(5-4) **북 위에 그리지 않아** 두 그림이 겹치지 않게 합니다.

### 4-5. 고정 UI와 게임 그림의 겹침 금지

진행도·시도 점·일시정지(화면 고정)와 궤도·별·이펙트(게임 좌표)는 4해상도 모두에서 겹치지 않아야 합니다. 4-2 값으로 확인했고, 구현 후 QA가 스크린샷으로 다시 확인합니다.

### 5-1. 공 `assets/ball.svg`

### 5-2. 별 `assets/star-play.svg`(꽉 찬 별), `assets/star-show.svg`(속 빈 별)
- 꼭짓점(반지름 1 기준, 12시부터 시계 방향): 바깥 (0,−1)(0.951,−0.309)(0.588,0.809)(−0.588,0.809)(−0.951,−0.309), 안쪽 0.5배. `stroke-linejoin: round`. 별은 회전하지 않음.
- **커지며 나타남(결정 6)**: 다음 마디 별은 한 마디 앞 같은 자리의 **(별 시각 + 늦은 통과 창 끝 + 가장 긴 판정 이펙트)** 가 지난 뒤 **크기 0.4 → 1.0배로** 커집니다. 시각·길이 값은 `balance.json` `preview`(`grow_start`, `grow_in_beats`, `judge_fx_max_ms`)가 기준입니다. 그 자리에 앞 별이 없어도(쉬는 자리, 카운트인) 같은 시각에 커집니다. 그래서 **치지 않은 별·판정 이펙트와 새 별이 한 자리에 겹치지 않습니다**. `judge_fx_max_ms`는 7절 딱 이펙트 길이(220 ms)와 같아야 합니다.
- 투명도는 쓰지 않습니다.
- 공 앞(이번 마디) 별과 공 뒤(다음 마디) 별은 **따로 구분 표시하지 않습니다**. 한 자리에는 늘 별이 하나뿐이고, 칠 별은 늘 "공 바로 앞, 시계 방향 다음 별"입니다.

## 12. 사운드 설계 (Web Audio 절차적 합성)

원칙: 외부 음원 파일 0개. 오실레이터·노이즈 버퍼·엔벨로프만. 기존 곡(동요 포함)의 선율·진행을 쓰지 않고 5음 음계 안에서 2마디 동기를 새로 만듭니다(레벨별 동기 음표 목록은 1-3 착수 전, 이번 범위 밖).

### 12-1. 곡 구조: "타악 자리가 비어 있고 탭이 채운다"

- 배경 곡에는 가이드 박(아주 작은 킥), 베이스, 패드, 멜로디, (반박 레벨부터) 셰이커만. 판정 별 자리의 중음역 타악은 곡에 없고 **아이의 탭 북**(보여 주기 마디에서는 둥둥이 북)이 채웁니다.
- 주파수 자리 비우기: 탭 북 몸통 90~200 Hz + 딸깍 3 kHz. 가이드 킥은 110 Hz 아래·짧게, 베이스는 별 시각마다 −6 dB 80 ms 숙임, 패드 lowpass 1500 Hz, 멜로디는 어택 30 ms 이상 + 별 시각에 새 음을 시작하지 않음.
- 탭 북은 `pointerdown` 즉시 재생(양자화 없음).
- **셰이커는 정박(짝수 자리)에만**(결정 10, `balance.json` `accompaniment.shaker_slots`). 8분마다 울리면 빈 반박 자리 탭을 부릅니다.

| 마디 | 가이드 킥 | 베이스 | 패드 | 멜로디 | 셰이커 | 북 |
|---|---|---|---|---|---|---|
| 카운트인 | 박마다 | - | 마지막 박에서 부풀어 시작 | - | - | **똑딱** 4번(1박 높게) |
| 보여 주기 | 박마다 | 켬 | 켬 | **끔** | 정박 | **둥둥이 북 Tt "둥"**(별 시각) |
| 따라 치기 | 박마다 | 켬 | 켬 | 켬(단계 2부터) | 정박 | 아이 탭 T |
| 쉬는 마디 | 박마다 | - | 켬 | - | - | - |
| 클리어(outro) | - | 켬 | 켬 | 마지막 음 | - | 클리어 음 + 등급 북마다 방울 |

- 진행 단계에 맞춰 파트가 늘어남: 1단계 = 킥·베이스·패드, 2단계 = + 멜로디, 3단계 = + 멜로디 화음(3도 위).
