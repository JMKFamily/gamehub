- 입력: `00-benchmark.md`(추천 코어 A "박자 시계 + 보여 주기 마디", 7절 art 요구 1~5), 참고 `projects/runner-01/30-art.md`(형식·합성 방식만 참고, 색·도형은 새로 정함). `10-lore.md`·`20-balance.md`는 1-1 병렬 작성 중이라 아직 없습니다. 이름·수치가 정해지면 1-2 교차 리뷰에서 맞춥니다(14절 질문 목록).

- 요청자 지시 반영: 기본 도형·평면 색, 강한 화풍 컨셉 금지 / 5~6세가 글 없이 이해하는 그림 튜토리얼 / 터치 버튼 48dp 이상 / 번쩍임·강한 흔들림 금지 / 기존 게임의 UI(특히 원형 판정 UI)·아이콘·음악을 닮지 않는 자체 디자인 / 음악·효과음 절차적 합성 / **레벨 10개, 테마 색 10개**.

- 팔레트 키는 `level01` ~ `level10`(밸런스의 `theme_id`와 맞출 예정, 14절 B-8).

## 1. 아트 방향

**한 줄**: 어두운 단색 바탕 위에 **원 하나, 공 하나, 별 몇 개**. 평면 단색 면 + 짙은 잉크 외곽선, 그라데이션·발광·질감 없음. "도는 공이 별에 닿으면 톡"이 사진 한 장으로 읽히는 것이 목표입니다.

레퍼런스 키워드 (특정 게임이 아닌 일반 사물): 부엌 타이머 다이얼, 보드게임 말판의 원형 길, 장난감 북, 색종이 오리기.

**원본 보호: 원형 판정 UI를 닮지 않기 위해 하지 않는 것**
| 하지 않는 것 | 대신 하는 것 |
|---|---|
| 표식 둘레에서 **오므라드는 접근 고리**(타이밍 원이 줄어들며 겹치는 방식) | 시간은 오직 "공이 원 위를 얼마나 남았나"로 보임. 별 주변에 시간 고리 없음 |
| 숫자가 적힌 원형 표식, 순서 번호 | 별은 모두 같은 모양, 숫자 없음 |
| 가운데에서 바늘(시곗바늘·레이더 선)이 도는 방식 | 바늘 없음. **공이 궤도 위를 직접 굴러감**. 가운데는 멈춰 있는 북 |
| 가운데에서 바깥으로 날아가는 노트, 여러 겹 원형 레인 | 레인은 원 1개. 별은 제자리에서 나타나고 움직이지 않음 |
| 네온 외곽선·발광·검은 배경 위 형광색, 판정 글자(PERFECT 류) 팝업 | 평면 단색, 판정은 빛살 개수·크기·소리 층으로만 |
| 기존 리듬 게임 특유의 아이콘(음표 모양 버튼, 원형 재생 버튼 등) | 메뉴 아이콘도 기본 도형 조합(5-6절) |

컨셉을 약하게 두는 이유: 재미는 박 판정과 즉시 재시도에서 나옵니다(00-benchmark 0절). 장식은 레벨별 바탕 색과 **바탕 뒤 큰 원 2~3개(bgFar)**뿐이고, 이를 모두 지워도 플레이가 그대로 성립해야 합니다.

## 3. 형태 언어 (테마와 무관하게 고정)

| 역할 | 실루엣 규칙 | 금지 |
|---|---|---|
| 나(공) | 완전한 원 1개 + 왼쪽 위 작은 흰 점. 뒤로 작은 원 3개 꼬리(방향 표시) | 별·뾰족한 모양, 얼굴 |
| 칠 것(진한 별) | 꼭짓점 5개 별, 둥근 모서리, 꽉 찬 노랑 + 검은 외곽선 | 다른 크기의 별 섞기(반박 별도 같은 크기) |
| 볼 것(흐린 별) | 같은 별 외곽선만(속 빔), 외곽선 두께 = 별 반지름 0.16 | 반투명 면 채우기(어두운 바탕에서 탁해짐) |
| 길(궤도) | 원 고리 1개. 띠 면(track) + 안·밖 가는 테두리(trackEdge) | 홈·레인 여러 줄 |
| 박 눈금 | 궤도 **안쪽** 0.78R 위치. 정박(3·6·9시) = 작은 네모, 반박 = 작은 점. **12시 = 세로로 긴 둥근 막대(시작 표식)** | 궤도 바깥(별 겹침, HUD 겹침) |
| 북(가운데) | 원 0.42R + 안쪽 가는 원. 탭할 때마다 물결 고리 | 바늘·숫자·눈금 |
| 선생(북채) | 둥근 네모 머리 + 막대, 30° 기울임. **보여 주기 마디에만** 북 위에 나타남 | 얼굴·손 모양 캐릭터(lore가 원하면 1-2에서 협의) |
| 톡 손가락 | 둥근 네모 3개(검지·손바닥·엄지) + 끝에 짧은 선 3개 | 실제 손 그림, 특정 앱 아이콘 모양 |

- 판정 이펙트가 가장 멀리 뻗는 거리(딱) = 별 중심에서 `2.05·별r + 4`(7절). 12시·6시 별의 딱 이펙트까지 넣은 세로 범위: 360x640 y 96~480, 412x915 y 192~631, 640x360 y 38~358, 1280x720 y 81~711. 모두 화면 안이고 진행도 막대·시도 점(세로 y 52, 가로 y 49 아래끝)과 겹치지 않습니다.
- 12시 표식은 궤도 **안쪽**에 둡니다. 처음 목업에서 바깥에 두었더니 가로 화면에서 진행도 막대와 겹쳤고, 가로 R 0.36·H에서는 12시 딱 빛살이 막대를 덮어 R을 0.33·H로 줄이고 빛살을 짧게 바꿨습니다(목업 2판에서 확인).

### 4-4. 터치와 엄지

- **화면 전체가 탭 영역**입니다(일시정지 버튼 48×48 제외). 버튼은 일시정지 하나뿐이므로 터치 영역 겹침이 없습니다.
- 세로 화면: 궤도 아래 빈 곳에 **엄지 받침**(둥근 네모, bgFar 면 + trackEdge 50% 점선 테두리)을 그립니다. 엄지가 궤도의 6시 별을 가리지 않게 손을 아래로 유도하는 그림일 뿐이고, 받침 밖을 쳐도 똑같이 판정합니다. 범위: 위 = `max(cy + R + 2.05·별r + 12, 0.70·H)`(6시 딱 이펙트 아래 8 px), 아래 = `H − 16 − safeBottom`, 좌우 16.
- 가로 화면: 엄지가 좌우 가장자리에 오므로 궤도(가운데 약 40 %)를 가리지 않습니다. 받침은 그리지 않습니다.
- 첫 레벨 첫 별의 손가락 그림은 세로 = 엄지 받침 가운데, 가로 = 북 가운데에 그립니다(궤도와 별을 가리지 않음).

## 8. 이펙트 규칙 (번쩍임·흔들림 금지)

- **화면 흔들림 0 px**(모든 상황). 카메라·궤도·HUD는 움직이지 않습니다.
- **전체 화면 밝기 변화 금지**: 바탕 색은 단계 전환(1마디 동안 섞기) 외에 바뀌지 않습니다. 흰 화면 번쩍임, 바탕 깜빡임, 박마다 바탕 맥동 없음.
- 판정 이펙트 1개의 외접원 면적은 **화면의 5 % 이하**(360x640에서 딱 이펙트 외접 반지름 약 48 px → 3.2 %, 실제 칠해진 면적은 그 절반 이하). 반박 연타(140 BPM에서 초당 약 4.7번)라도 작은 영역이라 WCAG 2.3.1 일반 번쩍임 기준(시야 10°의 25 %)에 들지 않습니다. 이펙트는 켜짐/꺼짐이 아니라 ease-out으로 줄어들며 사라집니다.
- 실패: 별 조각 + 공이 **속 빈 원**(테두리만)으로 바뀌어 그 자리에 멈춤 + 궤도 띠가 300 ms 동안 track1으로 어두워짐 → 약 1.1 s 뒤(밸런스 확정 값) 공이 12시 표식 자리에서 0.6 → 1.0배로 커지며 다시 나타나고 카운트인 시작. 진행도 최고 기록을 넘었으면 최고 기록 막대가 새 위치로 200 ms 미끄러짐.
- 클리어: 마지막 마디가 끝나면 궤도 띠가 1마디 동안 cardTint로 물들고, 받은 별(1~3개)이 하나씩 1박 간격으로 북 안으로 모입니다. 그 뒤 결과 화면(다시·다음 레벨 아이콘 버튼 2개, 각 64×64).
- 진행 단계 전환(track1→2→3): 1마디 동안 색 섞기. 동시에 바탕 장식 원(bgFar)이 1개씩 늘어남(최대 3개, 화면 가장자리, 궤도와 겹쳐도 별·공 대비는 2-3에서 확인됨).

### 11-1. 곡 구조: "타악 자리가 비어 있고 탭이 채운다"

- 배경 곡에는 **가이드 박(아주 작은 킥)**, 베이스, 패드, 멜로디만 있습니다. 스네어·박수·탐 같은 **중음역 타악 파트는 곡에 없습니다.** 그 자리를 아이의 탭(별을 맞춘 북소리)이 채웁니다.
- 놓친 별은 소리가 나지 않으므로 "구멍"이 들립니다(곧 실패 처리).
- **주파수 자리 비우기**: 탭 북은 몸통 90~200 Hz + 딸깍 3 kHz. 곡은 그 자리를 비웁니다: 가이드 킥은 110 Hz 아래·짧게, 베이스는 별 시각마다 −6 dB 80 ms 숙임(사이드체인), 패드 lowpass 1500 Hz, 멜로디는 어택 30 ms 이상(톡 쏘는 소리 없음) + 별 시각에 새 음을 시작하지 않음.
- 탭 북은 `pointerdown` 즉시 재생합니다(양자화 없음, 입력 손맛 우선). 판정 단계에 따른 방울 소리도 같은 순간에 겹칩니다.

| 마디 | 가이드 킥 | 베이스 | 패드 | 멜로디 | 셰이커(반박 레벨부터) | 북 |
|---|---|---|---|---|---|---|
| 카운트인 | 박마다 | - | 마지막 박에서 부풀어 시작 | - | - | **똑딱** 4번(1박 높게) |
| 보여 주기 | 박마다 | 켬 | 켬 | **끔**(무늬가 잘 들리게) | 켬 | 북채가 별 시각에 침(선생 북) |
| 따라 치기 | 박마다 | 켬 | 켬 | 켬(진행 단계 2부터) | 켬 | 아이 탭 |
| 숨 고르기 | 박마다 | - | 켬 | - | - | - |
| 클리어 | - | 켬 | 켬 | 마지막 음 | - | 클리어 음 |

- 진행 단계(track1~3)에 맞춰 파트가 늘어납니다: 1단계 = 킥·베이스·패드, 2단계 = + 멜로디, 3단계 = + 멜로디 화음(3도 위).
- 재시작 때 음악은 카운트인 마디부터 다시 시작합니다(곡 버퍼·스케줄러 재사용, runner-01 9절 방식).
