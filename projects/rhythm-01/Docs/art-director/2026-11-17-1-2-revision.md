## 요청 받은 일
오케스트레이터가 `Docs/orchestrator/2026-11-17-1-2-cross-review-decisions.md` 결정 1~12에 맞춰 `30-art.md`와 `assets/`를 고치도록 요청. 특히 북채 차례 신호(1), 등급 = 작은 북·노랑 금지(2), `level01`~(3), lore 하루 흐름 팔레트 + 대비 재검사 + 정지 실루엣(4), 실패 타임라인(5), 다음 별 표시 시점(6), 그림 카드(7), 보정 화면(9), 결과 버튼·깃발·다음 버튼·용어(10), BPM은 balance 참조(12). 작업 중 추가 전달: 카드 파일 이름 5개, lore 색 방향(L1 겨자 … L10 남색 밤), 판정 이름 "딱/좋아/통과", 끝 장면 "실루엣 하나가 카드 색으로 물듦". 요청자 규칙(runner-01 핵심 재미 유지, 기획까지, 기본 도형·평면 색, 5~6세 글 없이, 48dp, 번쩍임·흔들림 금지, 원본 보호, 10레벨) 그대로.

## 한 일
1. 결정 문서, 교차 리뷰 3개, 수정된 `10-lore.md`, `balance.json`(1-2 수정판: `preview`·`teacher`·`restart`·`cards`·`calibration`·`grade_rule` 등)을 읽고 키 이름으로 참조하도록 30-art를 다시 씀.
2. 팔레트: lore 5절 색 방향 순서로 같은 명도 구조의 생성 규칙(`pal.mjs`)을 만들어 10색을 다시 뽑음. lore 안(1-1 색 그대로 재배치)과 다른 점 3개(L1 카드 색 살구, L3 채도 낮춤, L7~L10 명도 단계)와 근거를 2-2·15절에 기록.
3. 대비 검사를 230쌍으로 넓혀(북채 막대/북, 카드 테두리/카드 면, 실루엣/바탕 상한 추가) 재검사 → 첫 시도 FAIL 0.
4. 북채 시간표(1박 전 커짐, 별 시각 타격, 마디 끝에 맞춰 작아짐), 손가락 위치(북채와 안 겹치게 북 밖), 둥둥이 북 소리 Tt 재정의(낮은 "둥", 딸깍 없음, −12 dB).
5. 등급 = 작은 북(hud 크림), 노랑은 별·빛살 전용으로 제한. 최고 기록 표시도 노란 막대 → 공 색 점.
6. 다음 별 등장 = balance `preview.grow_start`(별 시각 + 늦은 통과 창 끝 + 딱 이펙트 220 ms), 실패 1.08 s 5구간, 클리어를 outro 2마디 안으로(궤도·실루엣 하나 물듦 → 등급 북 1박 간격 → 버튼 3개).
7. 그림 카드 5장, 보정 화면, 결과 화면·아이콘 12개, 10레벨 테마 시트를 SVG로 그리고 Edge 헤드리스로 렌더해 확인. 확인 중 고친 것: 카드에서 공이 판정 별을 가림 → 공을 조금 지난 위치로 / 북채가 카드에서 너무 작음 → 키움 / 결과 화면 실루엣 물듦이 너무 밝고 화면 밖으로 넘침 → 30 % 섞기 + 잘라냄 / 보정 아이콘이 해처럼 보임 → 빈 원 + 점 8개.
8. 15절 "1-2 반영 기록"에 결정별 반영 위치와 반영하지 않은 지적 11건의 이유를 적음.
