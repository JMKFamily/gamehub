## 한 일
1. 데이터 생성 스크립트 `tools/build-web-data.mjs`: balance·levels·palette 복사, 10-lore 7절 표에서 텍스트 키 64개(KR/EN) 추출, 30-art 12-5 표에서 근음·방울 Hz·음계 추출, 30-art 12-4 합성 표·4~10절 규격을 `sound.json`·`art.json`으로, assets SVG 복사 + 목업 6·7에서 메뉴 아이콘 14개 추출, `tools/sim/judge.mjs`를 `js/judge.js`로 복사(판정 기준 구현을 그대로 씀).
2. 코어: 원형 궤도·공(12시 시작, 자리 0~7), 보여 주기 마디(북채·점선 궤도·속 빈 별·둥둥이 "둥") → 따라 치기(꽉 찬 별), 탭 1가지(`pointerdown` `event.timeStamp` → 오디오 시간), 판정 딱/좋아/통과·놓침 구역·헛탭(judge.mjs와 한 탭씩 같은 규칙), 판정 이펙트(빛살 8/4/0), 실패 연출 1.08 s 4단계 → 자동 재시작 + 카운트인 1마디(북 안 점 4개), 다음 마디 별 커지며 나타남(previewSchedule), 그림 카드(첫 플레이 1회, 레벨 선택에서 다시 보기), 손가락 튜토리얼 `tut_tap`, 등급 작은 북 1~3(크림색), 진행도 막대(판정 별 기준)·최고 기록 점·시도 점, 연습 모드(깃발 체크포인트), 해금(일반·연습 클리어), 결과 버튼 3개, 레벨 선택 10개(level01~10 테마·실루엣·클리어 물듦).
3. 오디오: WebAudio 합성만(30-art 12-4 표), 버스 2개(음악·효과음) + 컴프레서, 오디오 시계 예약(lookahead 0.1 s), 12-1 마디별 파트(가이드 킥·베이스 덕킹·패드·셰이커 정박만·멜로디 단계 2부터·화음 단계 3), 12-5 자리 표시 멜로디, BPM은 레벨 파일.
4. 결정 9: 첫 실행 자동 보정(타이틀 탭 → 보정, "어른과 같이" 그림, 건너뛰기), 보호자 보정 2회×8번·회 IQR·두 회 차이·재시도 1번·12탭 중앙값·30 ms 문턱·자름, 화면은 박에 맞춰 움직이지 않음(소리만), 설정은 레벨 선택 왼쪽 위 버튼 2000 ms 길게 누르기(한 번 탭 = 빈 고리 0.6 s, 일찍 떼면 0.2 s 비움), 설정의 박자 맞추기로 다시, 오프셋 자동 변경 없음, 큰 지연(A 오프셋 > 100 / B 자동 지연 ≥ 100·변화 > 40·기기 바뀜 / C 플레이 중 밀림 감지)일 때 레벨 선택 설정 버튼·설정 박자 맞추기 줄에 모래시계 표지만(3세션 뒤 숨김, 보정하면 해제).
5. 저장(localStorage: 해금·최고 기록·등급·깃발·카드 본 여부·오프셋·소리), 백그라운드 → 일시정지(`paused_background`), 소리 켜기/끄기(타이틀·멈춤), 설정 음악·효과음 토글, 기록 지우기 확인 창.
6. 테스트 훅 `window.__game`(DEV_NOTES 표), `?test=1` 가상 시계, 일반 모드 실시간 자동 입력(`autoplay` → 실제 PointerEvent), 광고 어댑터 웹 더미.
7. 자체 확인 도구 `tools/selfcheck-sim.mjs`(node), `tools/selfcheck-browser.mjs`(Edge 헤드리스), `tools/serve.mjs`.
