## 다른 팀에 줄 인사이트
- 6배 스로틀 시작 창의 "스크립트 0 긴 프레임"은 SVG 탭 아이콘(favicon)일 수 있다: 브라우저가 첫 탭 직후 불러와 SVG 문서를 메인 스레드에서 만든다(Chrome 추적 `SVGImage::DataChanged`). PNG로 바꾸자 35~48 ms 프레임이 사라졌다. 근거: 이 보고서 "R12". 적용: game-developer(탭 아이콘은 작은 PNG), qa-engineer(긴 프레임은 Chrome 추적으로 확인).
- "거의 투명(opacity 0.001)" 미리 그리기는 래스터화를 미리 하지 못했다. 캔버스 뒤(z-index −1)에 불투명하게 몇 프레임 그리고, 이미지 해독(`img.decode()`)이 끝난 뒤 준비 완료로 하자 새 브라우저 첫 그림 카드 98~248 ms 프레임이 0이 됐다. 적용: game-developer.
- 큰 오프스크린 캔버스를 레벨 시작 때 처음 `getContext`하면 외부 메모리 증가로 주요 GC(18~22 ms)가 그 프레임에 겹친다. 크기를 정할 때 버퍼를 미리 잡는다. 적용: game-developer.
