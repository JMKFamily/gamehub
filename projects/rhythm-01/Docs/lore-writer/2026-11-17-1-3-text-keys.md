## 요청 받은 일
오케스트레이터 요청: 웹 빌드에 필요한데 `10-lore.md` 7절에 빠진 텍스트 키를 찾아 추가만 하기. 대상은 레벨 4~10 화면 키, 다른 문서가 참조하는 키, 결정 9 보호자 보정·소리 지연 신호, 멈춤·소리·결과·연습 모드 키. 요청자 최신 지시: 5~6세 단순 규칙, 글 없이 진행, 원본 보호, 스토어 문구 작업 금지, git 금지.

## 한 일
1. `balance.json`·`20-balance.md`·`30-art.md`에서 키 이름을 grep으로 대조했습니다(`_key`, `aria_key(s)`, `card_*`, `calib_*`, `btn_*`, `tut_*` 등). 참조된 키 13개는 모두 7절에 이미 있었습니다. 빠진 키 0개.
2. 화면 흐름(타이틀 → 박자 맞추기 → 그림 카드 → 플레이 → 멈춤 → 결과 → 레벨 선택 → 설정)을 art 4-3·5-6·5-7·9·10절과 맞춰 보고, 이름 없는 상태·버튼에 키 26개를 추가했습니다.
   - 7-7 레벨 선택 카드 상태 7개: 대체 글 = `level<n>_name` + 상태 키. 10레벨이 같은 규칙이라 4~10도 1~3과 같은 수준이 됩니다.
   - 7-8 플레이·멈춤·결과 9개: 모두 aria 전용(화면 글 늘리지 않음).
   - 7-9 보호자·박자 맞추기·소리 지연 10개: balance 8-3 "보호자가 보정" 권장과 R1 블루투스를 위한 키.
3. 7-6의 "보정 다시 하기는 `btn_retry`를 같이 씀" 설명 한 줄을 전용 키 `calib_redo`로 바꿨습니다. 근거: 화면 낭독기에서 레벨 "다시"와 같은 글이 되어 헷갈림. `btn_retry` 키 자체는 그대로입니다.
4. 확정값 표 키 수 38 → 64, 7절 합계, 끝에 "1-3 보강 기록" 절을 추가했습니다.

## 문제·남은 일
- (major, 오케스트레이터·art) **보호자 진입 방식 미정.** 설정 버튼 그림이 art 5-7에 없고, 아이가 기록을 지우지 않게 할 진입 방식(예: 길게 누르기)도 정해지지 않음. 길게 누르기가 아니면 `guardian_hold`는 쓰지 않음.
- (minor, art) 아이콘 추가 필요: 설정(`btn_settings`), 닫기(`btn_close`), 뒤로(`btn_back`), 그림 카드 다시 보기(`btn_card_replay`), 한 번에 소리 켜기/끄기(`btn_sound_on/off`, 놓을 곳: 멈춤 화면·타이틀), 보정 "어른과 같이" 그림(`calib_with_grownup`), 소리 늦음 신호 그림(`latency_warn/tip`).
- (minor, art) 박자 맞추기 끝 화면에 "다시 맞추기"(`calib_redo`) 버튼을 둘지 결정. 둘 수 없으면 설정 안에서만 씀.
- (minor, qa·balance) 소리 늦음 신호를 보여 줄지는 R1 측정 뒤 결정. 안 쓰면 `latency_*` 2개는 남겨 두기만 함.
- (minor, game-developer) 레벨 카드 대체 글은 `level<n>_name` + ", " + 상태 키(`levelcard_new`/`levelcard_locked`/`grade_1~3`/`practice_clear`)로 이어 붙임. 판정 단계·실패에는 대체 글을 붙이지 않음(낭독이 박자 방해).
