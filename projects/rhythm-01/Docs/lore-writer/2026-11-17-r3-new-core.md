## 요청 받은 일
오케스트레이터가 결정 R18~R22(새 코어 "북길", 반복 회피, 콤보 예비)에 맞춘 세계관·텍스트 기획을 요청했습니다. 요청자 지시: "지오메트리대시처럼 몰입감이 좀 있는게 좋겠습니다. 이 몰입감은 오른쪽에서부터 다가오는 여러가지 패턴으로 짧은순간 판단해야하는 상황에서 생깁니다. 리스크가 반복적이지않게 만드는것을 초점으로 개선하세요." + 전 프로젝트 콤보 시스템(등급 3개 이하, 글 없이 색·모양·소리, 끊김은 겁주지 않게). 작업 중 오케스트레이터가 공통 문서 `harness/benchmarks/djmax-judgement.md`(콤보 = 점 10칸 + 10마다 큰 표지, 숫자 없음, 끊김은 소리 없이 사라짐, `aria-valuenow`, DJMAX 용어 금지)에 맞추라고 추가로 전달했습니다.

## 한 일
1. `10-lore.md` 맨 아래에 "round-3 북길" 절(R3-0~R3-11)을 덧붙이고 맨 위에 이 절이 우선한다는 안내 한 줄을 넣었습니다. 대체되는 앞 절 13곳(확정값 표 4줄, 3·4·5절 제목, 6-1·6-3 제목, 7-1 `tut_tap`, 7-5 `card_star_tap`·`card_two_bar`, 8절 제목)에 "round-3에서 대체 → R3-n" 표시를 달았고, 기존 문장·키는 지우지 않았습니다.
2. 설정 다시 잇기(R3-1·R3-2): 북시계 → **북길 / Drum Road**(새 세계관 이름), 둥둥이 = 길 왼쪽 판정 북(더는 먼저 쳐 주지 않음), 콩이 = 북 위에서 박마다 통통 뛰는 공("똑딱"), 소리별 = 오른쪽에서 흘러오는 별. 북채·보여 주기·속 빈/꽉 찬 별·"동그라미" 폐기. 이름 가안 뜻(똑딱 = 공·카운트인, 북 = 판정 북)이 그대로 이어집니다.
3. 화면 이름(R3-3): **공 / 별 / 북 / 길**. 콤보는 세계관 이름 없이 대체 글만 두고, 화면 글·키 이름에 "콤보"·레퍼런스 용어를 쓰지 않습니다(키는 `streak`).
4. 텍스트 키(R3-7): 새 5개, 폐기 3개, 기존 문구 변경 0, 삭제 0. 빌드 규칙 표(R3-a~d): 콤보 표시는 `aria_streak` + `aria-valuenow`, 값이 바뀌거나 끊길 때 `aria-live` 없음, `aria-hidden`에 이름 붙이지 않음, 접근성 트리로 확인.
5. 레벨 이름(R3-4): **10개 모두 유지**하고 레벨별 장소·이야기 한 줄을 길 기준으로 다시 썼습니다. N4는 문구가 아니라 R16 표시 규칙으로 풉니다. 예비안 "Cloudtops"는 채택하지 않았습니다.
6. 실패·판정·클리어 반응(R3-5)과 튜토리얼(R3-6)을 길·판정 북 기준으로 다시 썼습니다. 콤보 끊김은 실패 연출 안에서 소리 없이 조용히 사라집니다. 빨간 ×, "0", 잃은 개수, 경고음은 쓰지 않습니다. 콤보는 카드로 가르치지 않습니다.
7. 스토어 문구 초안(R3-8)을 새 코어로 바꾸고, 원본 보호(R3-9)에는 쓰지 않는 말 목록을, 가정(R3-10)에는 A1~A8을 적었습니다.

## 문제·남은 일
- **major · 오케스트레이터/balance**: 콤보 규칙이 둘로 갈립니다. R22는 "좋아 이상 연속, 통과는 콤보만 끊음(+ '퐁')"이고, 공통 문서 4-2·4-5는 "통과도 +1, 끊김 = 실패뿐, 소리 없음"입니다. 오케스트레이터 전달은 "끊김은 소리 없이"였습니다. lore 문구는 두 안 모두에 맞지만, R3-2·R3-5 문장은 공통 문서 안을 기준으로 썼습니다(R3-10 A4). balance가 확정해 주면 그에 맞게 고칩니다.
- **minor · balance/art 교차 리뷰**: 가정 A1(새 기믹 레벨 L1·2·3·6·7), A2(L6 = 긴 별 줄), A3(카드 파일 이름 = 키: `card_drum_tap.svg`·`card_long_row.svg`), A6(레벨 카드 최고 콤보 표지)을 맞춰야 합니다.
- **minor · game-developer**: `strings.json`에 새 5키를 추가하고 폐기 3키는 쓰지 않아야 합니다(DEV_NOTES에 "10-lore R3-7 폐기"). balance `cues[].key`는 `tut_drum_tap`으로 바꿉니다.
- **minor · qa**: en 360x640 L9 이름이 R16 뒤에 보이는지, `aria_streak` 이름·값이 접근성 트리에 나타나는지 확인해야 합니다.
