## 1. 설계 의도 【r2 바뀜】

1. **치는 신호는 여전히 하나.** "길 위 표시가 북에 오면 = 공이 북에 닿으면 톡". 표시는 공이 북에 닿는 박마다 하나씩 길 위에 놓여 오른쪽에서 다가오고, 표시 사이 간격 = 비행 길이라 **넓게 다가오면 오래, 촘촘하면 금방**(높이 = 시간이 앞쪽 길에도 보임). 다른 신호("콩"·토스·착지·손가락·클리어 큰 튐·콤보 화음)는 모두 치지 않아도 되는 때이고, 위험 구간과 겹치지 않음을 S1~S9로 확인합니다.
2. **새 판단 하나: 지붕 밑에서는 참기.** 지붕이 북 위를 덮는 동안 1박 비행으로 들어온 공은 북 위에 앉아 쉬고(판정 없음 = 참기 성공), 그 착지 순간 치면 공이 지붕에 콩 닿아 실패. 지붕은 아이에게 가장 비싼 규칙(insights "반대 행동")이라 L5부터, 배치 규칙 7개(8-4)와 레벨당 개수 예산으로 묶습니다.
3. **리스크가 반복되지 않음.** round-1은 화면이 고정이라 미리 보이는 시간이 그 비행 길이뿐이어서 일부러 짧은 무늬를 되풀이했습니다. 이제 앞쪽 3.5~4박(1.72~2.40 s)이 보이므로 그 이유가 사라졌습니다. 레벨마다 **모두 다른 위험 덩어리**(L9 7개)를 두고, 같은 덩어리가 연달아 오지 않으며, 레벨 사이 구절 시작·2마디 창이 같지 않게 했습니다(10절). 레벨 배치는 데이터 고정이라 시도마다 같아 숙달(암기)은 그대로입니다.
4. **곡선은 지붕 수와 1박 통 수로 만든다.** 요청자 곡선 제약(L1 ≤ 2.5, L1~L3 배율 r 먼저, L10 = T ±20 %, L3~L10 엄격 단조, 30회 이하, 직전 2배 이하)을 그대로 지킵니다. 지붕 하나의 비용(σ70 + 참기 실패율 0.15)은 hit 접촉 약 2개라서, 지붕이 있는 L5~L10은 hit 접촉 수를 round-1보다 줄였습니다(9-2).
5. **실패 비용은 약 1.1 s**(그대로). 실패 → 다음 시도 첫 프레임 1.1 s 고정·자동. 지붕에 콩(bump_roof)도 같은 1.1 s.

### 19-1. 왜 다시 맞추나

- 옛 레벨(5~6세 σ70로 맞춤)을 σ50으로 재면 **L1 0.51 → L10 1.03**(첫 시도 클리어 74 % → 49 %)으로 거의 평평합니다. σ50의 접촉당 실패 위험은 "놓침 1 % + 헛탭 약 0.5 %"가 바닥이고 옛 창(±125~150)에서는 타이밍 꼬리가 0.1~0.3 %뿐이라, 곡선은 **접촉 수 × 창 폭**으로만 만들 수 있습니다(봇은 높이·물체를 읽지 않음 — 읽기 부담은 K2).
- 접촉당 위험(σ50, 실측): 통과 창 이른 쪽 125 ms 2.3 % · 120 ms 2.5 % · 115 ms 2.9 % · 110 ms 3.3 % · 100 ms 4.6 %. 연속 중앙값 m̃은 시도당 위험 합 H = −ln(첫 시도 클리어율)에 대해 m̃ = ln0.5 / ln(1 − e^−H)라, m̃ 1 → 4는 H 0.69 → 1.84(2.7배)가 필요합니다.

### 19-2. L1 목표 (σ50)

- **목표 0.8 ≤ m̃1 ≤ 1.5**(첫 시도 클리어 37~58 %, 정수 중앙값 1~2회), 상한 10회(criteria). 근거: L1은 튜토리얼이라 12세가 "1~2번 만에" 깨야 하고(옛 목표 ≤ 2.5는 5~6세의 "몇 번"), 0.8 아래(첫 시도 60 % 넘게 그냥 통과)면 곡선의 뿌리가 0에 붙어 r로 이은 L10 목표가 무의미해집니다. **결과 0.898**(시드 3개 0.892~0.898). L1 실패 위치 중앙값 40.8 %(B4 ≥ 10 %).
- L1 내용: 1박 통만 27개, 구절 4개(7·6·7·7), 31.2 s, 통과 −125/+145(270 ms ≥ L1 하한 266.7). 첫 접촉 손가락·카드 그대로.

### 19-3. r·T·L10 (B6·B7·B8)

- **r = (m̃3/m̃1)^½ = (1.697/0.898)^½ = 1.375**(단계 1.35·1.40배, 범위 1.3~1.65), m̃1·r⁵ = 4.41 ≤ 25. **T = m̃3·r³ = 4.41 → L10 목표 3.53 ~ 5.29, L10 = 4.196(−4.8 %)**.
- T가 옛 12.3보다 작은 이유: σ50으로 L10 ≈ 12를 만들려면 −110/+130에서 hit 약 75개(레벨 60 s 이상) 또는 통과 창을 좋아 경계(±90) 안쪽까지 좁혀야 합니다. 등급 창(공통 문서)·레벨 길이 ≤ 50 s를 지키는 쪽을 골랐고, L1이 1회 안팎이면 r ≤ 1.65에서도 T는 최대 약 1.5·1.65⁵ ≈ 18이라 30회 한도와 멀리 떨어진 곡선입니다. 더 어렵게 하려면 오케스트레이터가 좋아 경계(±90 → ±80)나 레벨 길이 상한을 풀어야 합니다(보고서 안건).
