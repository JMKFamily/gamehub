2. runner-01 실측에서 몰입 수치를 계산: 플레이어 자리 0.368 W, 앞쪽 12.0블록 = 미리 보임 1.16 s(2.7박), 판단 시간 약 0.80 s, 입력 창 0.269 s, 한 화면 위험 2~3개, 기능 어휘 13종, 구간 8~16박 교체(구조만, 배치 재현 없음).
3. round-1 레벨 10개를 node 스크립트로 재서 반복 정도를 수치화: 레벨당 서로 다른 위험 덩어리 1~4개, L2 같은 덩어리 3연속, 구절 시작 "1 1 1 1 1.5 1.5 1"이 L4·5·7·8·9에 같음, 3-gram 중복 0.14~0.60.
4. 후보 3개 비교: R2-A 흘러오는 길(선정), R2-B 공중 고리 통과(고리 = 꼭짓점 = 접촉 −300 ms가 놓침 구역 → 일찍 실패 유도, 탈락), R2-C 날아오는 공 받아치기(코어 약화·신호 최다, 탈락).
5. 선정 코어 기믹 어휘 W0~W7(지붕 = 치지 마 신규, 두 공은 예비로 내림), 10레벨 구조(앞쪽 보이는 박 4/3.5, 미리 보이는 시간 2.40~1.72 s), 지붕 배치 규칙 7개, q_nogo 봇 행 제안.
6. 반복 없음 검증 수치 V-R1~R7, 안전 한계(보임 → 판정 ≥ 1.7 s·지붕 ≥ 2.0 s, 반박 간격 ≥ 32 px로 3.5박 결정, 한 화면 위험 상한), 신호 겹침 검사 S6~S10.
7. M1(따로 고침)·M2(구조 원인 사라짐, 대신 모든 세계 물체 ↔ HUD 일반화)와 minor 관계, 구현 변화 표, 3역할·dev 이월과 위험 K10~K16.
8. 콤보 14-8: 공통 문서 4절·5-3절(insights 콤보 2줄 포함)을 읽고 그대로 따름 — 콤보 = 이번 시도의 성공 판정 수(통과 포함, grades 길이에서 파생), 등급 3개·판정 창 불변, 콤보 2부터 점 10칸 + 10마다 큰 표지(HUD 띠 안), 단계 5/10/20, 화음 탭보다 1 dB 이상 작게 다음 정박, 끊김 = 실패 연출 0.3 s 안 소리 없이 작아짐. 이 코어 고유 판단 2개만 덧붙임: ① 지붕 참기(nogo 성공) +1(판정 대상 성공이므로, 판정 결과 배열에 한 칸 넣어 파생 유지) ② 단계 화음·연출이 지붕 착지 ±1박(S9)을 피함, 지붕 밑 쉼으로 미루지 않음. 공통 문서와 다르게 하자는 부분 없음.

## 검증 결과
- 반복 측정: 스크래치 node 스크립트(레포 밖)로 `levels/*.json` 10개 → 14-1 표. 정의는 14-4와 같음. balance가 검증기에 같은 정의로 넣고 이 표와 같은 값이 나오는지로 도구를 확인하도록 요구함.
- 계산 확인: 미리 보이는 시간 4박 × 60/100 = 2.40 s … 3.5박 × 60/122 = 1.72 s, 판단 시간 L10 1.72 − 0.115 = 1.61 s ≥ 1.55, 360x640 앞쪽 252 px / 3.5박 → 반박 36 px(4박이면 31.5 px로 32 미달), 지붕 비용 −ln 0.85 = 0.16 vs L5 접촉 0.079.
- 봇·검증기·빌드 실행은 하지 않음(범위 밖, balance 1-1). 아동 Go/No-Go 문헌은 검색 요약 수준이라 q_nogo는 추정으로 표시.
