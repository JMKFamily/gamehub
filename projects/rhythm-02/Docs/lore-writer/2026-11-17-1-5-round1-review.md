## 다른 팀에 줄 인사이트 (인사이트 후보)
- [rhythm-02·2026-11-17] 대체 글은 코드에서 `aria-label`을 붙였는지가 아니라 접근성 트리(`locator.ariaSnapshot()`)로 확인한다. 레벨 시작 판에서 `aria-hidden="true"` 요소에 레벨 이름 aria-label을 붙여 "aria로만 보인다"던 이름이 실제로는 어디에도 없었다. 근거: projects/rhythm-02/reviews/round-1/lore-writer.md 이슈 3. 적용: game-developer(구현), qa-engineer·lore-writer(리뷰 때 주요 화면 트리 스냅샷).
- [rhythm-02·2026-11-17] 불러오기 실패 화면의 다시 버튼 그림은 데이터 로드와 무관하게 있어야 한다. 아이콘을 JSON 다음에 불러오면 JSON 실패 때 버튼이 빈 칸이 되어 "다시 눌러 주세요" 글만 남는 막다른 화면이 된다. 부트 글과 함께 ↻ SVG·문서 제목·html lang도 빌드 스크립트가 `index.html` 부트 블록에 넣는다. 근거: 같은 리뷰 이슈 1·2. 적용: game-developer(전 프로젝트), qa-engineer(데이터 요청 하나를 막고 오류 화면 스크린샷).
