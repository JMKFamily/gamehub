# 00. 벤치마크: 원터치 리듬 오토러너 플랫포머

- 레퍼런스: Geometry Dash (RobTop Games, 2013~, iOS/Android/Steam)
- 목적: 장르, 조작, 핵심 루프, 수치 감각, 진행 구조만 추출합니다. 원작의 이름, 캐릭터, 아트, 음악, 레벨 배치, UI 디자인, 텍스트는 가져오지 않습니다 (`harness/PIPELINE.md` 원본 보호 규칙).
- 단위 약속: 이 문서에서 **1타일 = 플레이어 기본 몸체 한 변**입니다. 원작 에디터 그리드 1칸(내부 30 유닛)과 같고, 실측 문서(`benchmark/measurements.md`)의 "1블록"(플레이어 큐브 외곽선 한 변)과 같은 정의입니다. 시간은 초(s), 속도는 타일/초(t/s)로 씁니다.
- 표기: **[실측]** 레퍼런스 직접 플레이 녹화에서 잰 값, "실측(n회 평균 ± 표준편차)"로 씁니다. **[확인]** 공개 자료에 수치가 있음. **[추정]** 커뮤니티 분석·플레이 관찰을 근거로 계산한 값(실측 못 한 항목만 남음).
- 실측: 2026-11-17, 무료 체험판 첫 레벨, 게임 60 fps, 녹화 약 60 fps. 방법·불확실성·근거 프레임은 `benchmark/measurements.md`. 실측 단위 오차(블록 크기 ±1 px)는 모든 타일 단위 값에 같은 비율(±2.4%)로 들어갑니다.
- 갱신: 2026-11-17 round-2, 실측 반영(4절, 7절), 선정 적합성 판정(0절), 오케스트레이터 round-2 결정(기믹 범위 축소, 재시작 레퍼런스 ±15%, 가시 판정 레퍼런스 맞춤) 반영.

## 0. 선정 적합성 판정

기준: `harness/PIPELINE.md` "게임 선정·설계 원칙". 요청자 지시: 레퍼런스와 플레이 감각이 최대한 같은 게임, 5~6세도 할 수 있는 아주 간단한 규칙, 아트 컨셉은 약하게.

| 조건 | 판정 | 근거 |
|---|---|---|
| ① 조작 1~2가지 | **적합** | 화면 아무 곳 탭(점프) 1가지. 홀드는 같은 버튼을 누르고 있는 것뿐이라 새 조작이 아님 (3절) |
| ① 승패 조건 한 문장 | **적합** | "가시와 벽에 닿지 않고 끝까지 가기" |
| ① 글 없이 이해 | **적합** | 캐릭터가 저절로 달리고, 닿으면 깨지고 약 1 s 뒤 다시 출발. 진행도는 막대로 보임. 실측(장면 3·7)에서도 일반 모드 사망 시 글·확인 버튼 없이 자동 재시작 |
| ① 첫 레벨을 몇 번 시도로 클리어 | **조건부 적합** | 원작 첫 레벨도 연속 가시·높이 차 읽기가 섞여 5~6세에게는 어렵습니다. 핵심 조작은 그대로 두고 **레벨 배치와 기믹 수로 난이도를 낮춥니다**(10절 "5~6세용으로 덜어낼 것", 11절) |
| ② 아트 컨셉이 약함 | **적합** | 원작 화면은 정사각형·삼각형·직사각형 같은 기본 도형과 단색 배경이 바탕이고, 재미는 박자에 맞춘 점프 타이밍과 즉시 재시작에서 나옵니다. 화려한 빛·배경 펄스는 연출이라 빼도 규칙이 그대로 성립합니다. 우리 빌드도 단순 도형과 또렷한 색만 씁니다 |

**결론: 레퍼런스 유지.** 단, 원작의 여러 이동 모드·중력 반전·크기 변경·속도 문·공중 고리·천장 장애물처럼 "규칙을 하나 더 배워야 하는" 요소는 MVP에서 덜어냅니다(10절 표).

## 1. 한 줄 요약과 타깃 유저

**한 줄 요약**: 캐릭터는 일정한 속도로 오른쪽으로 계속 달리고, 플레이어는 화면 탭 하나로 점프 타이밍만 정합니다. 음악 박자에 맞춰 배치된 장애물을 통과하고, 한 번 닿으면 약 1초 뒤 처음부터 다시 시작합니다.

**원작 타깃 유저**
- 1차: 10~20대 모바일 캐주얼·미드코어. 짧은 시도를 많이 반복하며 "한 번만 더" 하는 걸 즐기는 유저.
- 2차: 대기 시간에 가로 화면 한 손 엄지로 1~5분씩 하는 유저.
- 동기: 숙달(같은 구간을 외워서 넘는 쾌감), 진행도 % 갱신, 클리어 인증.

**우리 타깃 유저**: 5~6세 아이부터 성인까지. 조작과 감각은 원작과 같고, 첫 레벨들은 5~6세가 몇 번 만에 깰 수 있게 배치를 쉽게 합니다.

## 2. 핵심 루프

| 단위 | 시간 | 루프 | 감정 곡선 |
|---|---|---|---|
| 초 단위 | 0.3~1 s | 장애물을 보고 → 박자에 맞춰 탭 → 착지·통과 | 긴장 → 해소. 박자와 점프가 맞을 때 "손맛" |
| 시도(판) 단위 | 2~90 s | 시작 → 구간 진행 → 사망 → **약 1.1 s 뒤 자동 재시작 [실측]** → 최고 진행도 % 갱신 | 실패해도 바로 재시도. 최고 기록 바가 조금씩 앞으로 나감 |
| 레벨 단위 | 10~60분 (수십~수백 회 시도) | 구간 암기 → 클리어 → 보상(재화·별) → 다음 레벨 해금 | 첫 클리어 순간이 가장 큰 보상 |
| 세션 단위 | 5~20분 | 한 레벨을 몇 % 더 밀거나, 연습 모드로 어려운 구간만 반복 | "오늘 50% 넘겼다" 같은 작은 목표 |

핵심은 **실패 비용이 거의 0**이라는 점입니다. 사망부터 다음 시도까지 1.11 s이고, 메뉴나 확인 버튼이 없습니다(광고 타이머가 찼을 때만 예외, 7절).

## 3. 조작 방식과 입력 판정

| 항목 | 원작 방식 | 비고 |
|---|---|---|
| 입력 | 화면 아무 곳이나 탭/홀드 (PC는 클릭, 스페이스, 위 화살표) | 버튼이 1개뿐 |
| 탭 | 지면에 있을 때 누르면 고정 높이로 점프 | 점프 높이는 누른 시간과 상관없음 (가변 점프 없음) |
| 홀드 | 누르고 있으면 **착지하는 그 프레임에 바로 다시 점프** [실측: 지면 정지 0프레임 28/29회, 1프레임 1회] | 사실상 "착지 순간 즉시" 입력 버퍼. 연속 점프 구간을 홀드로 넘음 |
| 공중 입력 | 지면 점프에는 쓰이지 않음. 공중 재점프 트리거에 닿은 상태에서 눌렀을 때만 반응 | 트리거는 "겹친 상태 + 새로 누름"으로 발동 [추정, 미측정: 장면 6을 재지 못함] |
| 코요테 타임 | 사실상 없음. 지면을 벗어나면 점프 불가 [추정] | 대신 판정 박스가 몸체 한 변 전체라서 모서리에 걸쳐도 지면으로 인정됨 |
| 입력 샘플링 | 1.x~2.1: 렌더 프레임마다 입력 처리. 2.2: 물리 240 tick/s, 입력을 프레임 사이에서도 반영 [확인: 커뮤니티 봇·모드 개발자 글] | 우리 빌드는 입력 타임스탬프를 물리 틱에 매핑 (9절) |
| 다른 이동 모드 | 비행(홀드 시 상승, 떼면 하강), 중력 반전 탭, 일정 각도 지그재그 등 | MVP에서는 지면 점프 모드만 (10절) |

## 6. 레벨 구조, 난이도 곡선, 진행·보상

**레벨 구조 (원작 공식 레벨의 패턴)**
- 한 레벨 = 한 곡. 곡의 구조(도입, 빌드업, 드롭, 브리지, 마무리)에 맞춰 구간이 나뉩니다.
- 구간 길이는 약 8~16박. 구간마다 기믹이나 이동 모드가 바뀌고, 드롭에서 밀도와 속도가 올라갑니다.
- 레벨 안의 난이도는 단조 증가가 아니라 **톱니 모양**입니다. 어려운 구간 뒤에 쉬운 숨 고르기 구간(2~4박)이 옵니다.
- 새 기믹은 **안전한 첫 등장 → 단독 연습 → 다른 기믹과 조합** 순서로 나옵니다 [추정: 초기 공식 레벨들의 공통 패턴].

**레벨 간 난이도 곡선 (원작 초기 레벨 기준 관찰)**

| 순번 | 새로 배우는 것 | 속도 | 체감 시도 횟수 [추정] |
|---|---|---|---|
| 1 | 탭 점프, 블록 올라타기, 연속 장애물 | 보통 | 3~15회 |
| 2 | 발판 자동 점프, 공중 재점프 | 보통 | 10~30회 |
| 3 | 중력 반전, 비행 모드 | 보통~빠름 | 20~60회 |
| 4~ | 속도 변화, 크기 변경, 조합 | 빠름 이상 | 50회 이상 |

원작은 레벨마다 새 규칙을 2개씩 넣습니다. 우리 MVP는 레벨당 1개로 줄입니다(11절).

**진행·보상**
- 레벨별 최고 진행도 %(일반 모드, 연습 모드 따로) 저장. 레벨 선택 카드에 진행도 바 2개로 보임 [실측: 장면 7].
- 레벨 안 숨겨진 수집품 3개. 경로 분기나 위험한 우회 루트 끝에 둠. 수집 후 그 시도에서 클리어해야 인정.
- 클리어 보상: 난이도별 별, 재화. 별과 재화로 외형(아이콘, 색) 해금.
- 연습 모드: 체크포인트에서 재시작. 클리어로 인정되지 않음(방식은 7절).
- 업적: 시도 횟수, 점프 횟수, 클리어 수 등 누적 지표.

## 7. 화면 흐름, 리텐션·수익화 장치

### 7-1. 화면 흐름 [실측: 장면 7, 기능만]

```
메인 메뉴 ──(가운데 큰 시작 버튼)──▶ 레벨 선택 ──(카드 탭)──▶ 플레이(일반 모드)
                                         ▲                        │ 사망 → 1.11 s 자동 재시작 (반복)
                                         │                        │ 광고 타이머가 찬 뒤 사망 → 결과 화면 → 전면 광고
                                         │                        ▼
                                         └──(메뉴)── 일시정지 (뒤로 가기 키 / 오른쪽 위 버튼)
                                                      버튼 4개: 연습 모드 / 계속 / 메뉴 / 재시작
```

| 화면 | 구성 (기능만) | 광고 위치 |
|---|---|---|
| 메인 메뉴 | 가운데 큰 시작 버튼, 옆에 캐릭터 외형 선택·온라인 레벨, 아래 업적·설정·통계 등 원형 버튼 줄 | 없음 |
| 레벨 선택 | 좌우 화살표로 레벨 넘김. 카드에 난이도 표시·별·수집품 3개·일반/연습 진행도 바 2개 | 정식판 구매 버튼, 사운드트랙 링크 (광고성) |
| 플레이 | 상단 진행도 % 바, 일시정지 버튼 | **플레이 중 광고 없음** |
| 일시정지 | 최고 기록 %, 현재 모드 진행도 바, 버튼 4개, 음악·효과음 음량 슬라이더 | **위쪽 가운데 배너** |
| 결과 화면 (광고 타이머가 찼을 때만) | 시도 횟수, 진행도 %, 점프 수, 플레이 시간, 재시작·메뉴 버튼 | **위쪽 배너 + 광고 제거(유료) 버튼 + 보상형 광고 버튼**, 3~6 s 뒤 **전면 광고** |

- **전면 광고 빈도 (관찰)**: 플레이 중에는 뜨지 않고, 마지막 광고 후 약 1.2~3분이 지난 뒤 처음 죽을 때 결과 화면 → 전면 광고. 한 세션에서 7회(정지 이미지 3, 동영상·플레이어블 3, 빈 화면 1). 일부 동영상 광고는 30 s 넘게 닫을 수 없었습니다. 타이머가 차지 않았을 때는 1.11 s 자동 재시작이 유지됩니다.
- 해석: 원작도 "몇 분에 한 번, 사망 시점"에만 광고를 넣어 짧은 재시도 리듬 대부분을 지킵니다. 하지만 그 한 번은 결과 화면 + 닫을 수 없는 동영상으로 루프를 30 s 이상 끊습니다.

### 7-2. 연습 모드 체크포인트 방식 [실측: 장면 7]

- 플레이 중 화면 아래 가운데에 버튼 2개: **체크포인트 놓기 / 마지막 체크포인트 지우기**. 놓은 자리에 표식이 남습니다.
- 사망하면 마지막 체크포인트에서 약 1 s 만에 부활합니다. 자동 체크포인트는 보지 못했습니다(수동 방식).
- 실측 중 관찰: 체크포인트를 "가시 바로 앞, 이미 피할 수 없는 상태"에 찍으면 그 자리에서 즉시 사망·부활을 반복하는 고리에 갇혔습니다(시도 208 → 458). **화면 아래 버튼을 플레이 탭과 같이 누르고, 찍을 때를 판단해야 하는 수동 방식은 5~6세에게 맞지 않습니다** (조작이 2개에서 3개 이상으로 늘고, 잘못 찍으면 빠져나올 수 없음).
- 우리 방식(바꿀 것, 10절): 연습 모드는 **자동 체크포인트**. 지면에 안전하게 서 있고 앞쪽 일정 거리(예: 점프 거리 4.5 t 이상)에 장애물이 없는 박자 지점에만 자동으로 찍습니다. 부활 시간은 일반 모드 재시작과 같은 레퍼런스 ±15% 리듬. 아이는 탭 하나만 씁니다.

| 진행도 % | 시도마다 최고 기록 갱신 표시 | 실패해도 성장감 |
| 시도 횟수 표시 | 레벨 시작 시 "N번째 시도" 표시 | 끈기 자체가 콘텐츠 |
| 외형 수집 | 아이콘·색·이펙트 해금 (능력치 없음) | 장기 목표. 공정성 유지 |
| 유료 앱 + 무료 체험판 | 정식판 유료, 무료판은 레벨 일부 + 위 광고 | 일회성 결제 |
| 유저 제작 레벨 | 레벨 에디터와 온라인 공유 | 콘텐츠 무한 공급 (우리 범위 밖) |
| 일일·주간 레벨 | 정해진 레벨을 기간 한정 제공 | 매일 접속 이유 |

**우리 쪽 시사점**: 웹 무료 MVP는 광고 없음. 이후 수익화 단계(요청자 승인 후)에서도 **플레이·재시작 사이 전면 광고 금지**, 닫을 수 없는 동영상 광고 금지. 광고가 필요하면 메뉴·레벨 선택처럼 플레이 밖 화면에만 둡니다(5~6세 대상이라 아동용 광고 정책도 따라야 함). 리텐션의 핵심은 % 바, 시도 횟수입니다.

## 8. 사운드와 리듬의 역할

- 음악이 **레벨 설계의 박자 격자**입니다. 장애물은 박·반박 위치에 놓이고, 점프 입력이 비트와 겹칩니다. 실측 체공 0.433 s는 약 139 BPM 한 박입니다(4-1 BPM 표).
- 음악은 플레이어 위치와 1:1로 묶여 있습니다. 사망하면 음악도 함께 끊기고 재시작 시 처음부터 다시 나옵니다. 따라서 **음악이 진행도 지표 역할**을 합니다.
- 효과음은 최소입니다. 사망음 1개, 수집음, 메뉴음 정도. 점프음은 기본적으로 없고, 음악 자체가 피드백입니다 [확인: 플레이 관찰].
- 시각 연출(배경 펄스, 색 전환)이 음악의 킥·드롭에 맞춰 리듬 체감을 강화합니다. 우리는 약하게만 씁니다(아트 컨셉 약하게).
- 우리 게임: 음악·효과음은 전부 자체 제작이거나 라이선스가 명확한 것만 씁니다. 원작 곡과 유사한 곡은 금지합니다.

## 11. 첫 버전(MVP) 범위

**목표**: 웹에서 "탭 → 점프 → 즉사 → 약 1초 뒤 재시작" 루프의 손맛이 레퍼런스 실측과 같은지 검증하고, 5~6세가 첫 레벨을 몇 번 만에 깰 수 있는지 확인합니다. 같은 빌드를 Capacitor로 Android 내부 테스트 트랙에 올립니다(요청자 승인 후).

| 항목 | MVP 포함 | MVP 제외 (다음 버전) |
|---|---|---|
| 레벨 수 | **3개** (각 40~75 s, 한 곡씩) | 4번 이후, 일일 레벨 |
| 이동 모드 | 지면 점프 모드 1개, 보통 속도 1단계 | 비행, 지그재그, 크기 변경, 속도 단계 |
| 기믹 (레벨당 새 기믹 1개) | 레벨 1: G2 바닥 가시·G3 낮은 장애물 / 레벨 2: + G1 블록 / 레벨 3: + G5 점프 발판. G13 연출은 약하게 | G4 천장, G6 공중 고리, G7 중력 반전, G8 속도 문, G12 얇은 발판, G9~G11 (`20-balance.md` 확장 후보) |
| BPM 참고 | 쉬운 레벨은 120~128 BPM(박마다 뛰어도 여유), 점프 = 박자 감각은 136~139 BPM (4-1 BPM 표) | - |
| 시스템 | 진행도 % 바, 시도 횟수, 레벨별 최고 기록 저장(localStorage), 연습 모드(자동 체크포인트), 일시정지, 오디오 오프셋 보정 | 수집품 3개(2차), 외형 해금, 업적, 계정·클라우드 저장 |
| 음악 | 자체 제작 또는 라이선스 명확한 곡 3개 | - |
| 성공 기준 (자동 플레이·지표) | 콘솔 에러 0. 속도·점프 높이·체공·점프 거리가 4-1 실측 ±3%. 단독 가시 통과 이륙 경계 0.88 / 3.68 t ±0.05. 사망 → 다시 움직임 레퍼런스 ±15%·1.2 s 이하·자동. 60/120 Hz 같은 입력 = 같은 궤적. 오디오-위치 오차 ≤ 20 ms(보정 후). 레벨 1 5~6세 대리 봇 첫 클리어 중앙값 5회 이하 | - |

### 12-3. 제안 (balance-designer 판단, 직접 수정하지 않음)
1. 천장 가시 판정을 바닥 가시와 같은 판정(뒤집은 0.49 × 0.24)으로 맞출지 검토. 지금 값(0.25 × 0.45)은 round-1 추정치가 그대로 남은 것이고, 겉모양이 같은 물체의 판정이 위아래로 다르면 "겉모양보다 판정이 항상 관대" 원칙(4-2)의 여유가 위·아래에서 달라집니다. 바꾸면 레벨 7~10 창 재계산과 `verify-levels` 재실행이 필요합니다. 현 배치(천장은 쉬는 박, 앞뒤 0.14 s 여유)라 영향은 작을 것으로 봅니다.
2. 울림 고리 입력 버퍼: 레퍼런스 실측 전까지 현행(새로 누름, 버퍼 없음) 유지. 실측에서 "이른 입력 버퍼"가 확인되면 아이 비용(꼭대기 고리 한 쌍 약 0.25)이 줄어드는 방향이라 레벨 6~10 난이도 재측정이 필요합니다.
3. 템포 문 음악: 레퍼런스 확인 전까지 "곡 박자는 그대로, 거리만 바뀜"을 기본 가정으로 권합니다(art-director 임시 곡 하프타임 결정과 함께 검토).
