# 30. 아트·사운드 디렉션: runner-01

- 입력: `00-benchmark.md` (MVP: 레벨 3개, 약 120 / 128 / 140 BPM). `10-lore.md`는 동시 작성 중이라 아직 반영하지 않았습니다.
- 테마 이름이 없으므로 팔레트 키는 `level1 / level2 / level3`입니다. 교차 리뷰 때 세계관에 맞춰 **색값만** 조정하고, 이 문서의 형태 언어·가독성 규칙·대비 기준은 그대로 유지합니다. 색을 바꿀 때는 부록 A의 스크립트를 다시 돌려 표를 갱신합니다.
- 단위: **1타일 = 100 SVG 단위**. 모든 `assets/*.svg`의 viewBox가 이 규칙을 따릅니다(아이콘만 5×5타일 = 500). 아래 좌표 표의 값은 타일 단위(= SVG 값 ÷ 100)이고, 원점은 오브젝트가 놓인 타일 칸의 **왼쪽 위**, y는 아래로 증가합니다.

---

## 1. 아트 방향

**한 줄**: 무광 색종이를 오려 붙인 판화 포스터. 평평한 면 색 + 짙은 잉크 외곽선, 빛 번짐·발광 없음.

레퍼런스 키워드 (원작이 아닌 독자 방향): 리소그래프 인쇄, 색종이 콜라주, 바우하우스 기본 도형, 1960년대 교통 표지판의 단순 기호, 실크스크린 2~3도 인쇄.

원본 보호 관점에서 하지 않는 것:
- 발광(glow)·네온 외곽선, 검은 배경 위 형광 격자, 반짝이는 큐브 질감, 사각형 얼굴 캐릭터.
- 플레이어는 정사각형이 아니라 **팔각형**이고 얼굴이 없습니다. 장애물은 그라데이션·광택 없이 단색 면 + 잉크 선입니다.
- 배경은 격자 타일 패턴 대신 크고 둥근 색종이 도형(언덕, 아치, 원)의 2겹 패럴랙스입니다.

## 2. 팔레트

토큰은 빌드에서 `palette.level1.bg`처럼 그대로 씁니다. SVG 원본은 level1 색으로 칠했고, Canvas는 토큰으로 다시 칠합니다.

색 사용 규칙
1. `hazard` 색상(빨강~주황 계열)은 **즉사 요소에만** 씁니다. 배경 장식, UI 강조, 이펙트에 쓰지 않습니다. 예외는 사망 이펙트 파편(플레이어 색 + hazard 색 섞임) 하나뿐입니다.
2. 레벨 1은 밝은 배경에 어두운 위험, 레벨 2·3은 어두운 배경에 밝은 위험입니다. 명도 극성은 바뀌어도 **"위험 = 가장 채도 높은 따뜻한 색 + 뾰족한 형태"**는 세 레벨 모두 같습니다.
3. 배경 색 전환·펄스 연출은 `bg`~`bgPulse` 사이, 먼 도형은 `bgFar`까지만 움직입니다. 이 범위를 벗어나는 색(특히 level1에서 `bgFar`보다 어두운 배경)을 쓰면 위험 대비가 4.5:1 아래로 떨어집니다. level1 `hazard`/`bgFar`는 4.53:1로 여유가 작으니 이 둘은 교차 리뷰 때 더 어둡게만 조정합니다.
4. 레벨 1의 `hazard`(빨강)와 `trigger`(초록)는 적록색약에서 비슷해 보일 수 있습니다. 그래서 둘은 형태(뾰족함 vs 둥긂)로 먼저 구분되어야 하며, 색만으로 구분하는 디자인 변경은 금지합니다.

## 3. 형태 언어 (테마와 무관하게 고정)

실루엣(단색으로 칠한 모양)만 보고도 세 부류가 구분되어야 합니다.

| 부류 | 형태 규칙 | 금지 |
|---|---|---|
| 플레이어 | 화면에 하나뿐인 **팔각형**(모서리 0.2타일 잘림). 꽉 찬 면, 둥근 꼭짓점 처리, 회전 표식 원 1개 | 다른 오브젝트에 팔각형 사용 |
| 안전 (블록·얇은 발판) | **직사각형**, 평평한 윗면, 모서리 반경 0.04. 올라설 수 있는 모든 윗면에 `groundEdge` 띠(블록 0.08, 발판 0.05) | 윗면에 뾰족한 장식, 경사면 |
| 위험 (즉사) | **꼭짓각 60° 이하의 뾰족한 삼각형**. 날카로운 마이터 꼭짓점, `hazard` 단색 + 안쪽 어두운 심지 삼각형 | 둥근 꼭짓점, `groundEdge` 띠, 위험이 아닌 곳의 `hazard` 색 |
| 상호작용 (발판·오브) | **원과 호**. 반타원 돔, 속 빈 고리 | 뾰족한 꼭짓점 |
| 통과형 (속도 게이트) | 세로로 긴 **캡슐 테두리**(속이 비침, 면 투명도 12%) + 둥근 선 꺾쇠 | 꽉 찬 면, 바닥에 닿는 형태 |

가독성 규칙
1. **판정 ≤ 겉모양**: 위험 요소의 판정 박스는 항상 그려진 삼각형 안에 완전히 들어갑니다(4절 표에서 확인). 안쪽 심지 삼각형은 "진짜 위험한 곳은 가운데"라는 시각 힌트입니다.
2. **외곽선 두께**: 모든 게임플레이 오브젝트 0.06타일(SVG 6). 360×640 가로(1타일 = 36px)에서 약 2px, 1280×720(1타일 = 72px)에서 약 4px. dpr 보정 후 최소 1.5 CSS px 아래로 내려가지 않게 `max(0.06*tile, 1.5)`로 그립니다.
3. **크기 하한**: 1타일 = 화면 높이 ÷ 10(벤치마크 9절). 360px 높이 폰에서 36px. 가장 작은 위험(낮은 장애물)도 높이 0.48타일 = 17px 이상.
4. **배경은 판정 없는 층**: 먼 배경 도형은 `bgFar` 단색, 외곽선 없음, 패럴랙스 속도 0.2배와 0.5배 두 층. 외곽선이 없다는 것 자체가 "닿아도 되는 것"의 신호입니다.
5. **맞닿음 규칙**: 위험 요소가 블록에 붙을 때(바닥 위, 천장 아래) 그 사이에는 반드시 `outline` 선이 보입니다. 블록과 위험을 하나의 경로로 합쳐 그리지 않습니다.
6. **블록 이어 그리기**: 연속된 블록은 바깥 둘레에만 외곽선을 그리고, 위가 비어 있는 칸에만 `groundEdge` 띠를 그립니다. 내부 칸 경계는 0.03 두께, `outline` 25% 불투명도 선으로만 표시합니다.
7. **회전**: 플레이어는 점프당 180° 회전(벤치마크)하며 착지 시 90° 스냅. 팔각형은 90° 대칭이라 스냅 후 모양이 항상 같고, 회전 표식 원으로 회전이 읽힙니다.

## 4. 오브젝트 도형 구성 (Canvas 2D 재현용, 타일 단위)

원점 = 해당 타일 칸 왼쪽 위. 외곽선 `lineWidth = 0.06`(타일). 외곽선은 SVG처럼 경로 중심에 그려지므로 경로를 0.03 안쪽으로 넣어 두었습니다. Canvas에서는 `ctx.scale(tilePx, tilePx)` 후 아래 숫자를 그대로 씁니다.

### 4-1. 플레이어 `assets/player.svg` (1×1)
| 순서 | 도형 | 좌표 | 칠 / 선 |
|---|---|---|---|
| 1 | 팔각형 몸체 | (0.21,0.03) (0.79,0.03) (0.97,0.21) (0.97,0.79) (0.79,0.97) (0.21,0.97) (0.03,0.79) (0.03,0.21) | fill `player`, stroke `outline` 0.06, lineJoin round |

## 7. 사운드 방향 (Web Audio 합성)

원칙: 외부 음원 파일 없이 오실레이터·노이즈 버퍼·엔벨로프만으로 합성합니다. 원작 곡과 비슷한 선율·진행을 쓰지 않습니다. 점프음은 없고(음악이 피드백), 효과음은 최소입니다.

### 7-1. 악기 정의 (모든 레벨 공통)

| 악기 | 합성 | 엔벨로프·필터 |
|---|---|---|
| 킥 K | sine, 주파수 150→45 Hz 지수 하강 0.12 s | gain 1.0→0.001, 0.30 s 지수 감쇠 |
| 스네어 S | 화이트노이즈 → bandpass 1800 Hz Q 0.9 + triangle 190 Hz | 노이즈 0.6→0 0.18 s, 톤 0.4→0 0.08 s |
| 클랩 C | 노이즈 → bandpass 1200 Hz, 10 ms 간격 3회 재트리거 | 각 0.5→0, 마지막 0.15 s |
| 하이햇 H | 노이즈 → highpass 7000 Hz | 닫힘 0.03 s, 열림 O 0.18 s |
| 베이스 B | sawtooth + square(1옥타브 아래, 0.3 믹스) → lowpass 600 Hz Q 4, 필터 엔벨로프 1600→400 Hz 0.15 s | A 5 ms, D 0.12 s, S 0.6, R 0.05 s |
| 리드 L | triangle + sine 5도 위(0.2), 비브라토 5 Hz ±6 cent | A 10 ms, D 0.2 s, S 0.4, R 0.15 s |
| 패드 P | sawtooth 2개 ±8 cent 디튠 → lowpass 1200 Hz | A 0.4 s, R 0.8 s |

- 마스터: compressor(threshold −14 dB, ratio 4) → gain 0.8. 킥이 울릴 때 베이스·패드에 사이드체인 느낌으로 gain 1→0.6→1 (0.15 s) 자동화.
- 스케줄링: `audioContext.currentTime` 기준 lookahead 0.1 s, 25 ms 간격 스케줄러. 16분음표 = 1스텝, 1마디 = 16스텝.

### 7-2. 레벨별 패턴

표기: 16스텝, `x` = 타격, `o` = 열린 햇, `.` = 쉼. 베이스 음은 마디(16스텝) 단위로, `음:스텝위치`.

**level1: 120 BPM, A 단조 펜타토닉, 밝고 느긋한 종이 공작 느낌** (1스텝 = 0.125 s)
| 파트 | 패턴 |
|---|---|
| 킥 | `x.......x.......` (도입) → `x...x...x...x...` (본편) |
| 스네어 | `....x.......x...` |
| 햇 | `..x...x...x...x.` |
| 베이스 (2마디 반복) | 마디1 `A1:0 A1:6 C2:8 E2:12` / 마디2 `G1:0 G1:6 D2:8 E2:12`, 음 길이 2스텝 |
| 리드 | 본편 후반만. A3 C4 D4 E4 G4 중 4분음표 선율, 마디당 3음 이하 |

**level2: 128 BPM, D 도리안, 해질녘의 들뜬 그루브** (1스텝 = 0.117 s)
| 파트 | 패턴 |
|---|---|
| 킥 | `x...x...x...x...` |
| 클랩 | `....x.......x...` |
| 햇 | `xxoxxxoxxxoxxxox` (닫힘 x, 열림 o) |
| 베이스 (2마디 반복) | 마디1 `D2:0 D2:3 D2:6 F2:8 A2:10 C3:14` / 마디2 `G1:0 G1:3 B1:6 D2:8 E2:12`, 음 길이 1~2스텝 (엇박 강조) |
| 패드 | 마디마다 Dm7 → G 화음, 드롭 구간에서만 필터 2400 Hz까지 개방 |

**level3: 140 BPM, E 단조(자연 단음계), 밤 도시의 질주감** (1스텝 = 0.107 s)
| 파트 | 패턴 |
|---|---|
| 킥 | `x...x...x...x...`, 드롭 마지막 마디 `x...x...x.x.x.xx` 필 |
| 스네어 | `....x.......x..x` |
| 햇 | `x.x.x.x.x.x.x.x.` + 드롭에서 16분 `xxxxxxxxxxxxxxxx` (짝수 스텝 gain 0.5) |
| 베이스 (1마디 반복, 드롭은 8분 연타) | 빌드 `E1:0 E2:2 E1:4 G1:6 E1:8 B1:10 D2:12 E2:14` / 드롭 `E1` 8분음표 연타, 2마디마다 `C2`→`D2`로 이동 |
| 리드 | 드롭에서 E4 G4 A4 B4 D5 아르페지오 16분 |
| 속도 게이트 연동 | 빠름 게이트 통과 마디부터 햇 16분 + 리드 진입, 느림 게이트 마디는 킥만 남김 |

**구간 구조 (세 레벨 공통 뼈대, 구간 길이는 밸런스 기획자의 레벨 데이터에 맞춤)**
| 구간 | 켜지는 파트 | 화면 연출 |
|---|---|---|
| 도입 (튜토리얼) | 킥(2박마다) + 패드 | 펄스 약하게(50%) |
| 빌드업 | + 햇, 베이스 | 펄스 100% |
| 드롭 | 전 파트 | 펄스 100% + 먼 배경 도형 박자마다 1.03배 |
| 숨 고르기 (2~4박) | 킥·베이스만 | 펄스 50% |
| 마무리 | 패드 + 리드 마지막 음 | 클리어 연출과 겹침 |

- 장애물은 킥·스네어 스텝(4·8·12·16분음표 위치) 위에 놓이도록 밸런스 기획자와 맞춥니다. 레벨 데이터의 x 위치 ↔ 스텝 변환은 `x = step × (60/BPM/4) × 속도`.

### 7-3. 효과음

| 효과음 | 합성 | 크기 |
|---|---|---|
| 사망 | 노이즈 → lowpass 3000→200 Hz 0.25 s + square 220→55 Hz 0.2 s | −6 dB |
