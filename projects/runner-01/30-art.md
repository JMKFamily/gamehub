# 30. 아트·사운드 디렉션: runner-01

- 입력: `00-benchmark.md`, `10-lore.md`(이름·테마), `20-balance.md`·`balance.json`·`levels/*.json`(판정·레벨 구성). 1-2 교차 리뷰 반영본입니다. 충돌 목록은 `reviews/cross/art-director.md`.
- 소유권: 이름·텍스트·테마는 10-lore.md, 수치·판정 크기·기믹 포함 여부·레벨 구성은 밸런스 문서가 기준입니다. 이 문서는 색·형태·이펙트·사운드를 정합니다.
- 팔레트 키는 `theme_id`와 같은 `level1 / level2 / level3`(= 새벽 조율장 / 줄다리 야시장 / 폭풍 종탑)입니다. 색을 바꿀 때는 부록 A의 스크립트를 다시 돌려 표를 갱신합니다.
- 단위: **1타일 = 100 SVG 단위**. 모든 `assets/*.svg`의 viewBox가 이 규칙을 따릅니다(아이콘만 5×5타일 = 500). 아래 좌표 표의 값은 타일 단위(= SVG 값 ÷ 100)이고, 원점은 오브젝트가 놓인 타일 칸의 **왼쪽 위**, y는 아래로 증가합니다.

---

## 1. 아트 방향

**한 줄**: 무광 색종이를 오려 붙인 판화 포스터. 평평한 면 색 + 짙은 잉크 외곽선, 빛 번짐·발광 없음.

레퍼런스 키워드 (원작이 아닌 독자 방향): 리소그래프 인쇄, 색종이 콜라주, 바우하우스 기본 도형, 1960년대 교통 표지판의 단순 기호, 실크스크린 2~3도 인쇄.

원본 보호 관점에서 하지 않는 것:
- 발광(glow)·네온 외곽선, 검은 배경 위 형광 격자, 반짝이는 큐브 질감, 사각형 얼굴 캐릭터.
- 플레이어(핑, 울림돌)는 정사각형이 아니라 **팔각형**이고 얼굴이 없습니다. 장애물은 그라데이션·광택 없이 단색 면 + 잉크 선입니다.
- 배경은 격자 타일 패턴 대신 크고 둥근 색종이 도형의 2겹 패럴랙스입니다. 레벨별 모티프(세계관 4절): level1 소리굽쇠 기둥(U자)·공명 상자 더미·먼 작은 종탑 / level2 노점 천막(둥근 지붕)·늘어진 현 다리 곡선·둥근 등불 / level3 종탑 벽 아치·둥근 톱니 바퀴·매달린 종. 배경 도형에는 뾰족한 꼭짓점을 쓰지 않습니다(번개도 지그재그 선 대신 먼 배경 층 전체가 `bgPulse`까지 밝아지는 것으로 표현).

## 2. 팔레트

토큰은 빌드에서 `palette.level1.bg`처럼 그대로 씁니다. 팔레트 키는 레벨 데이터의 `theme_id`(현재 `level1/2/3`, 밸런스 소유)와 같게 둡니다. `theme_id`가 바뀌면 키 이름만 따라 바꾸고 색은 유지합니다.

교차 리뷰 반영(1-2): 세계관 레벨 테마(10-lore.md 4절)에 맞춰 세 레벨 모두 **어두운 배경 + 밝은 전경** 극성으로 통일했습니다. 그리고 "환경 색만 레벨마다 바뀌고, 플레이어·위험·상호작용·게이트 색은 세 레벨 공통"으로 정리했습니다. 처음 보는 레벨에서도 색 의미를 다시 배울 필요가 없고, 앱 아이콘·스토어 그래픽의 플레이어 색이 항상 같습니다.

### 2-2. 세 레벨 공통 색

| 토큰 | 용도 | 값 |
|---|---|---|
| `outline` | 모든 게임플레이 오브젝트의 잉크 외곽선 | `#0D0F14` |
| `groundEdge` | 올라설 수 있는 윗면 띠 | `#F4EEDF` |
| `hazard` | 즉사 장애물(잡음 결정) 전용 | `#FF8C6E` |
| `player` | 핑 몸체 | `#FFD66B` |
| `playerCore` | 핑 안쪽 코어 면(박자마다 맥동) | `#FFF0BE` |
| `playerAccent` | 회전 표식(울림 구멍) | `#2A2140` |
| `trigger` | 북 발판·울림 고리 | `#5FE0C0` |
| `gateSlow` / `gateNormal` / `gateFast` | 템포 문 늘임 / 제박 / 몰아침 | `#8FB8FF` / `#ECE6D8` / `#F28AD0` |
| `hud` | HUD 글자·진행도 바 | `#F4F0E8` |

- `player` 금색은 세계관의 "핑이 지나간 자리에 돌아오는 새벽 금빛"입니다. 회색으로 빠진 세상에서 가장 따뜻한 색이 핑입니다.
- 클리어 연출(세계에 색이 돌아오는 장면)에서만 위 대비 규칙을 벗어난 밝은 색을 씁니다. 클리어 후에는 판정이 없으므로 가독성 기준 밖입니다.

색 사용 규칙
1. `hazard` 색(산호 주황)은 **즉사 요소에만** 씁니다. 배경 장식, UI 강조, 이펙트, 게이트에 쓰지 않습니다. 예외는 사망 이펙트 파편(플레이어 색 + hazard 색 섞임) 하나뿐입니다. 그래서 세계관의 "빠름 = 붉은 문"은 `gateFast` 자홍으로 바꿨습니다.
2. 세 레벨 모두 어두운 배경에 밝은 위험입니다. **"위험 = 가장 따뜻한 산호색 + 뾰족한 형태"**는 레벨과 무관하게 같습니다.
3. 배경 색 전환·펄스·번개는 `bg`~`bgPulse` 사이, 먼 도형은 `bgFar`·`bgAccent`까지만 움직입니다. 이 범위보다 밝은 배경을 쓰면 위험 대비가 4.5:1 아래로 떨어집니다. 그래서 등불·새벽빛·번개는 **밝은 발광이 아니라 어두운 채도 색 면**으로 표현합니다(1절 "발광 없음"과도 일치).
4. `hazard`(산호)와 `trigger`(민트)는 적록색약에서 명도로 갈리지만(상대 명도 약 0.39 vs 0.61), 형태(뾰족함 vs 둥긂)로 먼저 구분되어야 하며 색만으로 구분하는 디자인 변경은 금지합니다. 템포 문도 색 + 꺾쇠 개수로 이중 구분합니다.
5. `player`(금)와 `trigger`·`gateNormal`이 같은 색이 되지 않게 합니다. 세계관의 "금빛 울림 고리", "금색 보통 문"은 플레이어와 겹쳐 각각 민트·상아색으로 바꿨습니다.

### 2-3. 대비 검증 결과 (WCAG 2.x 상대 명도 대비, 부록 A 스크립트, node로 계산)

기준: 위험 요소 vs 모든 배경 층(`bg`, `bgFar`, `bgPulse`, `bgAccent`) **4.5:1**(하네스 필수 기준). 그 밖의 비텍스트 그래픽은 WCAG 1.4.11 기준 **3:1**, HUD 글자는 **4.5:1**.

## 3. 형태 언어 (테마와 무관하게 고정)

실루엣(단색으로 칠한 모양)만 보고도 세 부류가 구분되어야 합니다.

| 부류 | 형태 규칙 | 금지 |
|---|---|---|
| 플레이어 | 화면에 하나뿐인 **팔각형**(모서리 0.2타일 잘림). 꽉 찬 면 + 안쪽 코어 팔각 면, 둥근 꼭짓점 처리, 회전 표식 원(울림 구멍) 1개 | 다른 오브젝트에 팔각형 사용 |
| 안전 (블록·얇은 발판) | **직사각형**, 평평한 윗면, 모서리 반경 0.04. 올라설 수 있는 모든 윗면에 `groundEdge` 띠(블록 0.08, 발판 0.05) | 윗면에 뾰족한 장식, 경사면 |
| 위험 (즉사) | **꼭짓각 60° 이하의 뾰족한 삼각형**. 날카로운 마이터 꼭짓점, `hazard` 단색 + 안쪽 어두운 심지 삼각형 | 둥근 꼭짓점, `groundEdge` 띠, 위험이 아닌 곳의 `hazard` 색 |
| 상호작용 (발판·오브) | **원과 호**. 반타원 돔, 속 빈 고리 | 뾰족한 꼭짓점 |
| 통과형 (속도 게이트) | 세로로 긴 **캡슐 테두리**(속이 비침, 면 투명도 12%) + 둥근 선 꺾쇠 | 꽉 찬 면, 바닥에 닿는 형태 |

가독성 규칙
1. **판정 ≤ 겉모양**: 위험 요소의 판정 박스는 항상 그려진 삼각형 안에 완전히 들어갑니다(4절 표, `reviews/cross/art-sheet.png` 점선 박스로 확인). 고체·얇은 발판·발판 트리거도 그림 높이 ≥ 판정 높이입니다. 안쪽 심지 삼각형은 "진짜 위험한 곳은 가운데"라는 시각 힌트입니다.
2. **외곽선 두께**: 모든 게임플레이 오브젝트 0.06타일(SVG 6). 360×640 가로(1타일 = 36px)에서 약 2px, 1280×720(1타일 = 72px)에서 약 4px. dpr 보정 후 최소 1.5 CSS px 아래로 내려가지 않게 `max(0.06*tile, 1.5)`로 그립니다.
3. **크기 하한**: 1타일 = 화면 높이 ÷ 10(벤치마크 9절). 360px 높이 폰에서 36px. 가장 작은 위험(낮은 장애물)도 높이 0.5타일 = 18px 이상.
4. **배경은 판정 없는 층**: 먼 배경 도형은 `bgFar` 단색, 외곽선 없음, 패럴랙스 속도 0.2배와 0.5배 두 층. 외곽선이 없다는 것 자체가 "닿아도 되는 것"의 신호입니다.
5. **맞닿음 규칙**: 위험 요소가 블록에 붙을 때(바닥 위, 천장 아래) 그 사이에는 반드시 `outline` 선이 보입니다. 블록과 위험을 하나의 경로로 합쳐 그리지 않습니다.
6. **블록 이어 그리기**: 연속된 블록은 바깥 둘레에만 외곽선을 그리고, 위가 비어 있는 칸에만 `groundEdge` 띠를 그립니다. 내부 칸 경계는 0.03 두께, `outline` 25% 불투명도 선으로만 표시합니다.
7. **회전**: 플레이어는 점프당 180° 회전(벤치마크)하며 착지 시 90° 스냅. 팔각형은 90° 대칭이라 스냅 후 모양이 항상 같고, 회전 표식 원으로 회전이 읽힙니다.

## 7. 사운드 방향 (Web Audio 합성)

원칙: 외부 음원 파일 없이 오실레이터·노이즈 버퍼·엔벨로프만으로 합성합니다. 원작 곡과 비슷한 선율·진행을 쓰지 않습니다. 점프음은 없고(음악이 피드백), 효과음은 최소입니다.

### 7-1. 악기 정의 (모든 레벨 공통)

| 악기 | 합성 | 엔벨로프·필터 |
|---|---|---|
| 킥 K | sine, 주파수 150→45 Hz 지수 하강 0.12 s | gain 1.0→0.001, 0.30 s 지수 감쇠 |
| 스네어 S | 화이트노이즈 → bandpass 1800 Hz Q 0.9 + triangle 190 Hz | 노이즈 0.6→0 0.18 s, 톤 0.4→0 0.08 s |
| 클랩 C | 노이즈 → bandpass 1200 Hz, 10 ms 간격 3회 재트리거 | 각 0.5→0, 마지막 0.15 s |
| 하이햇 H | 노이즈 → highpass 7000 Hz | 닫힘 0.03 s, 열림 O 0.18 s |
| 베이스 B | sawtooth + square(1옥타브 아래, 0.3 믹스) → lowpass 600 Hz Q 4, 필터 엔벨로프 1600→400 Hz 0.15 s | A 5 ms, D 0.12 s, S 0.6, R 0.05 s |
| 리드 L | triangle + sine 5도 위(0.2), 비브라토 5 Hz ±6 cent | A 10 ms, D 0.2 s, S 0.4, R 0.15 s |
| 패드 P | sawtooth 2개 ±8 cent 디튠 → lowpass 1200 Hz | A 0.4 s, R 0.8 s |
| 소리굽쇠 톤 F (level1) | sine 기음 + sine 6.0배(0.08 믹스, 금속성 배음) | A 2 ms, 지수 감쇠 0.9 s |
| 종 Bl (level3) | sine 기음 + sine 2.76배(0.5) + sine 5.4배(0.25), 비정수 배음 = 종 | A 2 ms, 기음 1.6 s / 배음 0.6 s 지수 감쇠 |

- 마스터: compressor(threshold −14 dB, ratio 4) → gain 0.8. 킥이 울릴 때 베이스·패드에 사이드체인 느낌으로 gain 1→0.6→1 (0.15 s) 자동화.
- 스케줄링: `audioContext.currentTime` 기준 lookahead 0.1 s, 25 ms 간격 스케줄러. 16분음표 = 1스텝, 1마디 = 16스텝.

### 7-2. 레벨별 패턴

표기: 16스텝, `x` = 타격, `o` = 열린 햇, `.` = 쉼. 베이스 음은 마디(16스텝) 단위로, `음:스텝위치`.
BPM은 `levels/*.json`의 `bpm`(120 / 128 / 140)과 같고 레벨 안에서 바뀌지 않습니다. 속도 변경(템포 문)은 **1박에 지나가는 타일 수만 바꾸고 음악 템포는 그대로**이며, 대신 편곡 밀도가 바뀝니다.

**level1 새벽 조율장: 120 BPM, A 단조 펜타토닉, 서늘한 새벽 공방 → 점점 따뜻해짐** (1스텝 = 0.125 s)
| 파트 | 패턴 |
|---|---|
| 킥 | `x.......x.......` (intro) → `x...x...x...x...` (learn_tap부터) |
| 스네어 | `....x.......x...` |
| 햇 | `..x...x...x...x.` |
| 베이스 (2마디 반복) | 마디1 `A1:0 A1:6 C2:8 E2:12` / 마디2 `G1:0 G1:6 D2:8 E2:12`, 음 길이 2스텝 |
| 리드 (소리굽쇠 톤 F) | drop 구간만. A4 C5 D5 E5 G5 중 4분음표 선율, 마디당 3음 이하 |

**level2 줄다리 야시장: 128 BPM, D 도리안, 흔들리는 밤 시장 그루브** (1스텝 = 0.117 s)
| 파트 | 패턴 |
|---|---|
| 킥 | `x...x...x...x...` |
| 클랩 | `....x.......x...` |
| 햇 | `xxoxxxoxxxoxxxox` (닫힘 x, 열림 o) |
| 베이스 (2마디 반복) | 마디1 `D2:0 D2:3 D2:6 F2:8 A2:10 C3:14` / 마디2 `G1:0 G1:3 B1:6 D2:8 E2:12`, 음 길이 1~2스텝 (엇박 강조) |

**level3 폭풍 종탑: 140 BPM, E 단조(자연 단음계), 폭풍 속 상승과 종소리** (1스텝 = 0.107 s)

| 스네어 | `....x.......x..x` |

| 베이스 (1마디 반복, 드롭은 8분 연타) | 빌드 `E1:0 E2:2 E1:4 G1:6 E1:8 B1:10 D2:12 E2:14` / 드롭 `E1` 8분음표 연타, 2마디마다 `C2`→`D2`로 이동 |
| 리드 | fast_drop에서 E4 G4 A4 B4 D5 아르페지오 16분 |

- 구간 경계가 마디 중간인 곳(L1 58, L2 95)은 파트 전환을 그 박에서 바로 합니다(다음 마디까지 미루지 않음). 장애물이 박에 맞아 있으므로 연출이 박에 맞으면 됩니다.
- 장애물은 정박·반박(4분·8분음표 위치) 위에 있습니다(밸런스 1장). x ↔ 시간 변환은 속도가 구간마다 다르므로 구간별로 계산합니다: `t = beat × 60 / BPM`, 플레이어 x(t) = x_k + (t − t_k) × speed_k (x_k, t_k = 직전 속도 변경 지점). `sections[].x`는 플레이어 왼쪽 x, `speed_changes[].x`는 플레이어 중심 x(= 왼쪽 + 0.5)라 0.5 차이가 나는 것이 정상입니다.

## 부록 A. 대비 계산 스크립트

교차 리뷰에서 색을 바꾸면 `C`(공통)·`P`(레벨별)만 고쳐 다시 돌리고 2-3 표를 교체합니다.

```js
// node contrast.mjs
const C = {outline:'#0D0F14',groundEdge:'#F4EEDF',hazard:'#FF8C6E',player:'#FFD66B',playerAccent:'#2A2140',trigger:'#5FE0C0',gateSlow:'#8FB8FF',gateNormal:'#ECE6D8',gateFast:'#F28AD0',hud:'#F4F0E8'};
const P = {
 level1:{...C,bg:'#222B37',bgFar:'#2A3341',bgPulse:'#31343F',bgAccent:'#3C302C',ground:'#8A7F70'},
 level2:{...C,bg:'#1D1B36',bgFar:'#2A2650',bgPulse:'#30294F',bgAccent:'#45264E',ground:'#8C7FBC'},
 level3:{...C,bg:'#121820',bgFar:'#1F2833',bgPulse:'#2B3644',bgAccent:'#302F25',ground:'#6F8597'},
};
const lum=h=>{const c=[1,3,5].map(i=>parseInt(h.slice(i,i+2),16)/255).map(v=>v<=0.03928?v/12.92:((v+0.055)/1.055)**2.4);return 0.2126*c[0]+0.7152*c[1]+0.0722*c[2]};
const cr=(a,b)=>{const [x,y]=[lum(a),lum(b)].sort((p,q)=>q-p);return (x+0.05)/(y+0.05)};
const BG=['bg','bgFar','bgPulse','bgAccent'];
const checks=[...BG.map(b=>['hazard',b,4.5]),['outline','hazard',3],['outline','ground',3],['ground','bg',3],['ground','bgFar',3],['groundEdge','ground',3],...BG.map(b=>['player',b,3]),['outline','player',3],['playerAccent','player',3],...['trigger','gateSlow','gateNormal','gateFast'].flatMap(k=>[[k,'bg',3],[k,'bgFar',3]]),['hud','bg',4.5],['hud','bgFar',4.5],['hud','bgPulse',4.5]];
let fail=0,n=0,min={};
for(const [k,p] of Object.entries(P)) for(const [a,b,t] of checks){const r=cr(p[a],p[b]);n++;if(r<t)fail++;if(a==='hazard')min[k]=Math.min(min[k]??99,r);console.log(`| ${k} | ${a} ${p[a]} | ${b} ${p[b]} | ${r.toFixed(2)}:1 | ${t}:1 | ${r>=t?'통과':'**실패**'} |`)}
console.log('PAIRS',n,'FAIL',fail,'hazardMin',JSON.stringify(min));
```
