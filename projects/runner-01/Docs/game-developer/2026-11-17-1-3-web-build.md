## 검증 결과
- **`node scripts/validate.mjs`**: OK: 2 game(s).
- **`node projects/runner-01/tools/verify-levels.mjs`**: ALL PASS (3/3). 최소 타이밍 창은 145.8 / 45.8 / 45.8 ms로 기존과 같습니다. 물리를 공유 모듈로 옮기기 전후 출력도 같습니다.
- **`node projects/runner-01/tools/selfcheck-sim.mjs`**: 64/64 OK. 조합은 세 레벨 × 입력열 2종(검증기·박자대로) × 누르는 길이 2종(1틱·80 ms) × 프레임 5종(60/120/144 Hz, 불규칙, 30 Hz에 150 ms 끊김)입니다.
  - 모두 클리어했습니다.
  - 아무 입력 없이 죽으면 0.600 s 뒤 자동 재시작합니다.
  - 연습 체크포인트에서 정확히 다시 시작합니다.
- **Playwright**: playwright-core 1.48.2와 이미 설치된 Edge(`--channel msedge`)로 돌렸습니다.
  - 콘솔 에러·경고 0, 외부 요청 0.
  - `?test=1`에서 세 레벨 모두 클리어했습니다.
  - HUD는 1280x720, 640x360, 360x640에서 화면 밖으로 나가지 않고, 버튼은 48 px 이상이며, 서로 겹치지 않습니다.
  - 일반 모드에서 오디오가 실제로 돌아가고, 진짜 클릭 0.1초 뒤 점프 높이가 1.47 t였습니다.
- **못 한 것**
  - 헤드리스 환경이라 음악·효과음을 귀로 들어 확인하지 못했습니다.
  - 실제 모바일 기기, CPU 스로틀링 fps, 오디오-화면 지연 실측(보정 후 ≤ 20 ms)은 하지 못했습니다. 실기기와 계측 환경이 없습니다.

## 규칙 준수 확인
- [x] **원본 보호**: 레퍼런스의 이름·캐릭터·아트·음악·레벨 배치를 쓰지 않았습니다. 기획 문서의 자체 디자인(팔각형 플레이어, 자체 레벨)과 자체 합성 음악만 씁니다.
- [x] **게임 선정·설계 원칙**
  - 조작은 탭과 홀드뿐입니다.
  - 터치 버튼은 전부 48 px 이상입니다. 일시정지·체크포인트는 48×48, 메뉴는 52~64 px이고, 브라우저 검사로 확인했습니다.
  - 모든 버튼에 아이콘이 있습니다. 레벨 카드는 번호·별·자물쇠·체크로, 클리어 화면은 큰 별로 보여줍니다.
  - 튜토리얼 카드에는 실제 오브젝트와 같은 색·모양의 그림을 넣었습니다.
  - 레벨 1을 아직 못 깼으면 첫 24박 동안 손가락 탭 시연이 나옵니다.
  - 아트는 기본 도형과 평면 단색이고, 발광·그라데이션은 없습니다.
- [x] **결제·광고 클릭·계정 변경 없음**
  - 광고는 더미이고 배너는 메뉴에서만 띄웁니다. 플레이 중에는 숨깁니다.
  - 구매 버튼은 없습니다.
  - 허브로 가는 ⌂ 링크는 타이틀 화면 구석에만 있고 플레이 중에는 없습니다.
- [x] **내 담당 파일만 수정, git 커밋·푸시 안 함**: `benchmark/`, `balance.json`, `00-benchmark.md`, `levels/*.json`은 건드리지 않았습니다.
