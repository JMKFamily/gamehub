## 요청 받은 일
오케스트레이터가 round-2 빌드를 맡겼습니다. 요청자 지시로 레벨이 10개가 되었습니다. 아트 담당이 `30-art.md`를 동시에 고치는 중이라, 아트에 의존하지 않는 일부터 합니다.

1. round-1 게이트 결정 문서의 개발 할 일(QA·리뷰 이슈) 전부
2. `sync-data`로 10레벨·새 문자열 반영, `?test=1` 완벽 입력열 10/10 클리어
3. 레벨 선택 10장: 360x640·640x360·1280x720에서 잘림·겹침 없음, 터치 48dp 이상, `keep-all`
4. 새 기믹 4종을 검증기와 같은 물리로 동작시키고 ALL PASS 유지, 레벨 7 6배 스로틀 성능 확인
5. cue 키 5개를 그림 카드에 연결(`tut_tempo_slow` 새 카드)
6. 레벨 4~10 팔레트·곡·기믹 모양 임시값을 한 곳에 모으고 DEV_NOTES에 표시, 대비 4.5:1 유지

   - 카드 구성(30-art 5-5): 바탕 `bg`, 테두리 `cardTint`, 지면 띠, 대표 오브젝트.

   - 템포 문은 받침 위에 그립니다.
   - 울림 고리는 효과음을 없앴습니다(7-3: 발판 전용).
   - 레벨 4~10 배경 모티프 12종을 단순 원·둥근 도형으로 그렸습니다.

   - 곡은 base 곡에서 반음 이동으로 파생하고, 하늘색 문 구간은 하프타임입니다.
