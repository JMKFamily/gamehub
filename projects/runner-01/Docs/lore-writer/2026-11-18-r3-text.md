# round-3 텍스트 수정 (콤보 라벨·단수 문구·대체 글 키화·12세 근거)

- 역할: lore-writer
- 프로젝트: runner-01 (Reverbound)
- 단계: round-3 기획 수정 (배분 2번, balance·art와 병렬)

## 요청 받은 일
오케스트레이터가 round-3 배분 2번을 맡겼습니다. 결정 23(콤보 라벨 "연속" / "in a row", 대체 글 "연속 성공" / "Jump streak")과 결정 20(위쪽 중앙 큰 숫자)을 반영하고, `clear_attempts_one`을 추가하고, 하드코딩 aria 5곳과 음악 버튼을 키로 만들고, 부트 단계 lang과 `titleAlt` lang 처리 방안을 적습니다. 판정 글 자리 문구는 30-art·빌드에 맞추고, 근거 문장은 12세 기준으로 고칩니다. `tut_final`과 D21 미사용 키도 정리합니다. 수정 파일은 10-lore.md만입니다(strings.json·games/·다른 문서 수정 금지, git 금지).

## 한 일
1. **콤보 라벨 (결정 20·23)**: 5-2에 `combo_label` 연속 / in a row를 추가했습니다. 숫자를 먼저 쓰고 라벨을 뒤에 붙이며, 소문자·일반 글꼴로 둡니다. 대안 "연속!" / "Streak"도 적었습니다. 옛 "콤보는 화면에 글·숫자를 더하지 않음" 문장과 점 10칸 설명은 지웠습니다. 확정값 표에 콤보 라벨 행을 넣었습니다.
2. **5-8 다시 씀**: 대상을 큰 숫자 묶음 하나의 meter로 바꿨습니다(`aria-valuetext` 숫자만, 숨길 때 `hidden`만, aria-hidden + label 금지). 키 값도 바꿨습니다.
   - `combo_aria`: 연속 성공 / Jump streak
   - `combo_best_aria`: 최고 연속 성공 / Best jump streak (화면 라벨과 같은 낱말로 맞춤)
   - `combo_mark_aria`: 단계 5·10·15·20(결정 18)으로 고쳤고, 한 시도에 많아야 4번 읽힙니다.
   - 레퍼런스 화면 글자 "COMBO"와 그 음역 "콤보"를 쓰지 않는다고 명시했습니다.
3. **`clear_attempts_one`** 한 번에 성공! / First try!를 추가했습니다. `attempts === 1`이면 이 키를 쓰고, `{n}`=1을 `clear_attempts`에 넣지 않습니다.
4. **대체 글 키화 (5-7)**: 키 7개를 추가했습니다.
   - `aria_pause` 잠깐 멈추기 / Pause
   - `aria_back` 뒤로 / Back
   - `aria_hub` 게임 목록 / All games
   - `aria_game` 게임 화면 / Game screen
   - `aria_close` 닫기 / Close
   - `aria_music` 음악 소리 / Music sound: 상태는 `aria-pressed`로 주고, 이름에 켜짐·꺼짐을 붙이지 않습니다.
   - `aria_retry_load` 다시 불러오기 / Load again: 부트 ↻ 버튼 이름입니다.
5. **부트 단계**: 인라인 스크립트가 언어를 먼저 정하고 `<html lang>`을 바꿉니다. `loading`·`load_error`·`aria_retry_load`의 KR·EN 값은 10-lore에서 옮겨 넣고(sync가 넣거나 sync 때 같은지 검사), 영어 고정 "Load error"는 쓰지 않습니다. `<title>`은 두 언어 모두 Reverbound입니다.
6. **`titleAlt` lang**: 한국어 화면의 "Reverbound"에는 `lang="en"`, 영어 화면의 "잔향 질주"에는 `lang="ko"`를 붙입니다.
7. **판정 글 자리 (UX minor 6)**: 5-9의 "플레이어 위쪽"을 지웠습니다. 이제 "자리는 `30-art.md` 5-8-2가 정함(지금 빌드·30-art 표현: 플레이어 뒤쪽 위)"이라고만 적습니다.
8. **12세 근거**: 고친 곳은 아래와 같습니다. 화면 문구 키는 `clear_all`만 바꿨습니다("다 깼어요! 최고예요!" → "모든 레벨을 깼어요!", 칭찬이 겹치는 어린 말투를 줄임).
   - 머리말에 대상 연령 줄
   - 2절 톤
   - 4절 레벨 이름 체계·레벨 7 비고
   - 5-8 도입
   - 5-9 "정확도는 5~6세에게 어려워"·"글을 못 읽는 아이"
   - 4절·5-6의 "아이" 표현 3곳
9. **`tut_final` 폐기**: 키 표에서 빼고 "뺀 키" 목록으로 옮겼습니다. 이유(카드 1장 규칙의 예외, `level10_tag`·`clear_title_l10`·`clear_all`로 충분)를 적었습니다.
10. **D21 미사용 키 정리**: `result_accuracy`·`result_best_combo`·`result_new_best`·`best_accuracy_aria`를 5-9 표에서 빼고 "뺀 키" 목록에 되돌릴 문구와 함께 적었습니다. 이제 원본 키가 모두 빌드에서 쓰입니다(criteria R8 줄). `result_best_combo_aria`는 최고 연속 성공 / Best jump streak로 맞췄습니다.
11. 스토어 긴 설명의 "점이 하나씩 차올라요" / "dots fill up"을 큰 숫자 표시에 맞게 고쳤습니다. 끝에 "round-3 텍스트 수정 처리 결과" 절(dev·art·qa에 넘길 것)을 붙였습니다.
