## 검증 결과
- 콘솔 에러·경고 0, pageerror 0, 요청 실패 0, 외부 요청 0 (요청 658건).
- 완벽 입력열 60/60 클리어, 음성 대조 6/6 실패(정상), 빌드 타이밍 여유 = 검증기 창(±70.8 / ±20.8 / ±20.8 ms), 실시간 경로 3/3 클리어.
- 6배 스로틀 평균 59.7~60 fps, 1% low 37.8~56.1 fps, 입력→점프 1프레임 39/40.
- 재시작: 사망 → 새 시도 약 0.60 s, → 다시 움직임 약 0.72 s. 레퍼런스 실측 1.05 s와의 관계는 qa.md 메모(판단은 benchmark-analyst).
- 연습 모드·저장·백그라운드 일시정지·음소거 통과. 버튼 전부 48 px 이상, 글 없이 진행 가능.
- 레벨 1 5~6세 대리 봇(σ70) 첫 클리어 60세션 중 32세션이 200회 안에 실패 → 실패.
- 못 한 것: 실제 모바일 기기 성능·터치, 귀로 듣는 오디오·지연. σ70 아동 모델은 QA 가정.
