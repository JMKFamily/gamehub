### 봇 결과 (훅 `replay`, 레벨당 200회, 누름 100 ms)

봇 = 검증기 완벽 입력열에 사람 타이밍 오차(정규분포 σ)와 탭 놓침·헛탭을 더한 것. σ 값은 QA 가정입니다(5~6세 탭 타이밍 실측 자료 없음).

| 프로필 | L1 클리어율 / 평균 진행 | L2 | L3 |
|---|---|---|---|
| 숙련 σ25 ms | 95.5 % / 99.0 % | 44.0 % / 86.7 % | 51.0 % / 70.2 % |
| 초보 σ50, 놓침 1 % | 10.0 % / 47.4 % (첫 사망 중앙 33.5 %) | 1.5 % / 31.4 % | 0 % / 19.0 % |
| 5~6세 대리 σ70, 놓침 3 % | **0.5 %** / 26.5 % (중앙 23.1 %) | 0 % / 15.3 % | 0 % / 10.8 % |
| 5~6세 대리 σ90, 놓침 5 % | **0 %** / 18.3 % | 0 % / 10.8 % | 0 % / 8.6 % |
| 랜덤 (평균 0.5 s 간격) | 0 % / 10.1 % | 0 % / 7.1 % | 0 % / 5.4 % |

- 레벨 1 첫 클리어까지 시도 횟수 (60세션, 상한 200): 초보 σ50 중앙 5회(p75 9, p90 14) · σ70 중앙 >200(32/60 미클리어) · σ90 60/60 미클리어.
- 난이도 단조 증가(평균 진행도): 모든 프로필에서 L1 > L2 > L3 → 통과.
- 사망 몰림(한 지점 30 % 초과, 20-balance 8장 기준): 숙련 봇 L2 x≈456~460(93.5박 3연속) 60 %, L3 x≈254~257(60박 3연속) 62 % (이슈 2).

### 재시작 시간 메모 (판단은 benchmark-analyst 리뷰 몫)
- criteria "사망 후 0.8초 이내 재시작"은 벤치마크 목표(≤ 0.8 s) 기준이고 빌드는 `restart_delay_s` 0.6 s로 새 시도 시작 약 0.60 s, 오디오 선행 대기를 포함해 플레이어가 다시 움직이기까지 약 0.72 s(10회 중 1회 0.89 s, 6배 스로틀 첫 측정).
- 레퍼런스 실측 중간값(참고): 사망 → 재시작 약 1.05 s. 레퍼런스가 이 기준보다 느리므로, 기준을 "레퍼런스와 같은 감각"으로 볼지 "더 빠르게"로 볼지는 실측 반영 라운드에서 benchmark-analyst가 정해 주세요. 측정 정의(사망 판정 → 새 시도 / → 다시 움직임)도 함께 정하면 좋겠습니다.
