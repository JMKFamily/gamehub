## 1. 한 줄 요약과 타깃 유저

**한 줄 요약**: 30장 덱과 영웅 하나를 들고, 매 턴 1씩 늘어나는 마나로 하수인과 주문을 내 상대 영웅 체력 30을 먼저 0으로 만드는 1:1 턴제 카드 대결.

**레퍼런스 타깃**: 10대 후반~30대 PC·모바일 게이머. 실물 TCG보다 규칙이 가볍고(상대 턴에 대응 행동이 거의 없음), 한 판 6~8분이라 모바일 짬 플레이가 된다는 점이 핵심 [9][10].

**대상 연령: 18세(요청자 확정, 2026-11-17)**

성인 TCG 기준으로 판단합니다. 이 문서의 가져올 것/바꿀 것(10절)은 아래 기준을 따릅니다.

| 기준 | 성인 TCG 기준 판단 | 레퍼런스 대비 |
|---|---|---|
| 카드 텍스트 복잡도 | 한 카드에 조건 + 효과 2문장까지 허용(예: "들어올 때 조건이면 효과, 죽을 때 효과"). 숫자 계산(공격력만큼, 손패 장수만큼 등)과 "다음 턴" 같은 시간 조건도 허용 | 레퍼런스와 같은 수준. 단 모바일 세로 화면 글자 크기 때문에 카드 글은 확대 화면 기준 3줄 이내 권장 |
| 키워드 수 | **14~18개**로 시작(5절 기능 23개 중 고름). 200장 1세트에서 키워드당 평균 8장 이상 나오도록 | 레퍼런스(누적 20개 이상)보다 약간 적게. 1세트라 키워드당 카드 수가 너무 적으면 덱 축이 안 섬 |
| 덱 빌딩 깊이 | 덱 30장·같은 카드 2장 제한 유지, 영웅 전용 + 공용 카드, 영웅당 아키타입 2~3개, 태그(종족류) 시너지와 키워드 시너지 두 축 | 레퍼런스와 같은 깊이를 목표. 요청자 "다양한 덱 빌딩 패턴"과 직결 |
| 정보 공개 | 상대 손패 장수·덱 남은 장수·묘지(죽은 하수인) 기록 공개, 숨겨진 함정은 "있음"만 공개 | 레퍼런스와 같음. 성인 플레이어의 수 읽기 재료 |
| 판 길이·시간 | 한 판 5~8분, 턴 45~60 s | 모바일 짬 플레이 기준으로 약간 짧게 |
| 무작위 보상 | 팩 개봉 확률 공개, 천장 공개 | 실결제가 없어도 무작위 보상이므로 확률·천장을 화면에 공개(성인 대상이라도 투명성). 모바일 출시 때 연령 등급 "무작위 아이템" 표기 확인(오케스트레이터 참고) |

근거: 레퍼런스 핵심 재미(손패 자원 관리, 상대 덱 예측, 상성 판단)는 글 읽기·계산·예측을 요구하고, 요청자 판단 기준 "치열한 승부"는 이런 수 읽기가 깊을수록 커집니다. 18세 확정으로 단순화보다 **깊이 유지**를 우선하고, 단순화는 모바일 화면 제약(필드 칸 수·글 줄 수·조작)에서만 합니다. 게임 이름은 팀(lore-writer)이 정합니다.

## 2. 핵심 루프

| 단위 | 루프 | 걸리는 시간(레퍼런스) |
|---|---|---|
| **턴** | 턴 시작: 마나 +1(상한 10)·전부 회복 → 카드 1장 드로우 → 손패에서 마나 내에서 카드 내기(하수인 소환·주문) → 영웅 능력(보통 2마나, 턴당 1회) → 공격 선언(하수인·무기 든 영웅이 대상 선택) → 턴 종료 | 한 턴 최대 75 s, 실제는 대부분 20~40 s(추정: 한 판 약 6~7분 ÷ 양쪽 합 약 15턴) [3][9][10] |
| **판** | 멀리건(시작 손패 교체) → 초반 1~3턴 필드 다툼(템포) → 중반 4~7턴 가치 교환·큰 카드 → 후반 마무리(직접 피해·큰 하수인) 또는 피로로 소모전 → 영웅 체력 0 | 각자 약 7.4~7.8턴, 약 6~7분 [9][10]. 아주 긴 대결(서로 컨트롤)은 약 23턴·16분 [8] |
| **세션·메타** | 판 승리·일일 퀘스트 → 재화·보상 트랙 경험치 → 팩 구매·개봉 → 새 카드로 덱 수정 → 랭크 상승 → (시즌·확장 주기) 새 카드·메타 변화 | 하루 퀘스트 몇 판(추정 3~5판, 20~40분). 확장 약 4개월 주기(공개 출시 이력 기준 추정) |

판 단위 감각의 핵심: **"이번 턴에 마나를 다 쓰는가"(템포)**와 **"손패 장수를 지키는가"(가치)** 사이의 선택이 매 턴 반복됩니다.

## 3. 턴 구조·조작과 규칙 수치

### 3-1. 기본 수치

| 항목 | 값 | 출처 |
|---|---|---|
| 영웅 시작 체력 / 회복 상한 | 30 / 30(회복으로 넘지 못함, 방어도는 별도로 쌓임) | [13][14] |
| 덱 장수 | 30장. 같은 카드 2장, 최고 희귀도는 1장 | [6][14] |
| 마나 | 턴 시작마다 최대치 +1, 상한 10. 매 턴 전부 회복. 남은 마나는 다음 턴으로 넘어가지 않음 | [3] |
| 시작 손패 | 선공 3장, 후공 4장 + **후공 보상 카드**(0비용, 이번 턴에만 마나 +1 하는 1회용 카드) | [4][15] |
| 멀리건 | 시작 손패 중 원하는 장을 표시해 교체. 교체 카드는 같은 장을 다시 받지 않고(같은 카드 2장째는 가능), 교체 후 덱에 섞임. 선택 시간 65 s(전체 단계 75 s) | [4] |
| 드로우 | 턴 시작마다 1장. 추가 드로우는 카드 효과로만 | [3] |
| 손패 상한 | 10장. 가득 찬 상태에서 받는 카드는 버려짐(양쪽에 공개) | [12] |
| 필드 상한 | 한쪽에 하수인 7. 가득 차면 하수인을 낼 수 없음 | [13] |
| 피로 피해 | 덱이 빈 뒤 드로우를 시도할 때마다 1, 2, 3… 누적(N회 합 N(N+1)/2). 효과 드로우에도 적용 | [1] |
| 무승부 | 90번째 턴 시작에 무승부 | [1][2] |
| 턴 시간 | 75 s. 남은 약 20 s부터 화면에 타는 줄 표시. 아무 행동 없이 시간을 넘기면 다음 턴은 약 7 s로 단축(행동하면 복귀). 연출 시간은 다음 턴에 보전 | [3] |
| 영웅 능력 | 보통 2마나, 턴당 1회. 영웅마다 효과가 다름(작은 피해, 방어도, 1/1 소환, 무기 장착 등 — 기능만) | [5] |

### 3-2. 공격·방어 규칙

- 하수인은 **낸 턴에는 공격 못 함**(소환 피로). 다음 턴부터 턴당 1회 공격. 예외 기능: "즉시 공격", "즉시 공격(하수인만)".
- 공격은 **공격자가 대상을 고름**(상대 영웅 또는 상대 하수인). 방어자가 막을 하수인을 고르는 규칙이 없음 → 상대 턴에는 할 일이 없고, 판단이 모두 자기 턴에 몰림.
- 하수인끼리 싸우면 **서로 동시에** 공격력만큼 피해. 체력은 턴이 지나도 회복되지 않음(피해 누적).
- **공격 대상 강제**(방어 기능): 이 기능이 있는 하수인이 있으면 상대는 그 하수인부터 공격해야 함(주문·효과 대상은 제한 없음).
- 영웅도 무기를 들면 공격 가능(무기 내구도 소모). 영웅이 하수인을 치면 반격 피해를 받음.

### 3-3. 조작

| 행동 | 입력 |
|---|---|
| 카드 내기 | 손패 카드를 필드로 끌기(놓을 칸 위치 선택) |
| 대상 지정 | 카드·하수인에서 대상까지 화살표 끌기 |

| 정보 | 길게 누르기로 카드 확대 |

## 4. 게임 감각 수치 (balance-designer 시뮬레이터 목표값 원천)

| 항목 | 레퍼런스 값 | 출처·근거 |
|---|---|---|
| 평균 게임 길이(턴) | 각자 약 7.4~7.8턴(상위 7.36, 다이아 7.66~7.81). 덱별 평균 최저 6.5(빠른 공격 덱) ~ 최고 11.5(느린 컨트롤) | [10] (한 시점 표본, 턴 수는 각자 기준 0.5 단위) |
| 가장 긴 대결 | 서로 컨트롤 대결 약 23턴·16분 | [8] (2016년 표본) |
| 평균 게임 길이(분) | 약 6~7분 | [9][11] (제3자·개인 기록, **추정**) |
| 마나 곡선 평균(덱 평균 비용) | 전체 약 3~3.5. 빠른 공격 덱 약 2~2.5, 미드레인지 약 3~3.5, 컨트롤 약 4 이상 | **추정**. 근거: 7.5턴 안에 끝나는 게임에서 마나를 다 쓰려면 2~4비용이 덱의 절반 이상이어야 함. 공개 덱 목록 관찰 |
| 선후공 승률 편차 | 선공 우세, 시기별 편차 **약 1~5.75 %p**(선공 50.5~52.9 %). 대표값 약 3 %p(51.65 대 48.35). 빠른 공격 덱은 10 %p 넘는 경우, 같은 빠른 덱끼리는 24 %p(선공 62 %)까지. 반응형 컨트롤 덱만 후공이 유리했던 적 있음 | [7] (통계 사이트 시즌 분석), 개발진 언급 "거의 50:50, 선공이 약간 유리" [16] |
| 첫 턴 할 일 있음의 효과 | 한 모드 분석: 후공 손해 약 3.5~6 %p, 선공에 1턴 할 카드가 있으면 +5~13 %p | [17] (드래프트 모드, 2017) |
| 랭크 메타 아키타입 승률 폭 | 대부분의 주력 덱이 **약 45~55 %** 안. 최상위 덱 약 53~56 %, 그 이상이면 하향 대상. 같은 덱도 랭크 구간에 따라 49 % ↔ 57 %로 바뀜 | **추정**(공개 통계 사이트 관찰 범위). 랭크별 차이는 [18] |
| 대결(매치업) 승률 폭 | 대부분 35~65 %, 극단 25~75 % 이상(카운터 관계) | **추정**(통계 사이트 매치업 표 관찰). 수치 표가 이미지라 이번에 원문 확인 못 함 |
| 카드 비용별 스탯 기준선 | 효과 없는 하수인 **공격력+체력 ≈ 2 × 비용 + 1**(1~2비용은 +1 여유). 비율로는 (공+체)/비용 = 2가 기준, 효과가 붙으면 그만큼 스탯을 깎음. 커뮤니티 예시: 1비용 3스탯+효과, 2비용 5스탯+효과, 3비용 6~7스탯+효과 | [19][20] (커뮤니티 공개 분석, 연도 오래됨) |
| 드로우 가치 | 카드 1장 ≈ 약 1.5~2마나 가치(추정, 커뮤니티 통설) | **추정** |
| 직접 피해 주문 효율 | 비용당 약 1.5~2 피해(하수인 대상 제거용은 더 높게) | **추정**(공개 카드 관찰) |

시뮬레이터에 넘길 때 주의:
- 위 턴 수는 "각자 턴 번호" 기준(마지막 턴 번호)입니다. 양쪽 합 반턴 수로 세면 약 2배(약 15)입니다. **정의를 1-1에서 하나로 고정**하세요.
- 사람 플레이 시간(분)은 시뮬레이터로 잴 수 없으니 턴 수로만 목표를 잡고, 분은 턴당 연출 시간 예산(art·dev)으로 따로 맞춥니다.

### 7-2. 요청자 지시(중복 = 동일 카드 경험치 → 돌파 강화)와의 차이

| 항목 | 레퍼런스 | 우리(요청자 지시) | 결과 |
|---|---|---|---|
| 중복의 쓸모 | 분해해 범용 재화 → 원하는 카드 제작(막힌 카드 찾기 보장) | 같은 카드의 경험치 → 돌파 → 능력치 강화 | 원하는 카드를 "찍어서 얻는" 길이 없어짐 → **제작 수단 별도 필요**(아래 제안) |
| 덱 장수 제한 | 같은 카드 2장(최고 희귀도 1장)까지라 3장째부터는 덱에 쓸모 없음 | 덱에 넣는 장수와 별개로 중복이 성장 자원 | 중복이 "꽝"이 아니라 보상이 됨(좋은 점) |
| 강함의 원천 | 카드 소유 여부만(같은 카드면 누구나 같은 성능) | 소유 + 돌파 단계 | **같은 카드라도 성능이 다름 → PvP 공정성 위험** |

### 7-3. 돌파 강화가 PvP 공정성에 주는 위험 (다른 게임 사례)

| 사례 | 구조 | 공정성 처리 | 배울 점 |
|---|---|---|---|
| Clash Royale (실시간 카드 대전) | 중복 카드로 카드 레벨업, 레벨마다 공격력·체력 상승(공개 위키 기준 레벨당 약 10 %, **추정**) | 레벨 차가 승패에 크게 작용한다는 "과금 승리" 비판이 꾸준함. 대회·일부 모드는 **레벨 상한 고정(모든 카드를 같은 레벨로 맞춤)**, 랭크도 상한을 둠 [21][22] | 상한·정규화 장치가 없으면 덱 실력보다 수집량이 이김 |
| Marvel Snap (카드 대전) | 중복·재화로 카드 "업그레이드" | **성능 변화 없음(외형만)**, 업그레이드는 수집 레벨 → 새 카드 해금으로 연결 [23] | 성장감과 공정성을 분리하는 대표 해법 |
| 레퍼런스 | 성장 없음 | 같은 카드 = 같은 성능 | 승률 통계(4절)는 모두 "같은 성능" 전제 |

위험 정리:
1. **승률 매트릭스 오염**: 돌파 차이가 아키타입 상성(±15 %p 수준)을 덮으면 "치열한 승부" 지표가 수집량 지표로 바뀝니다.
2. **곡선 왜곡**: 저비용 카드에 +1 스탯은 비율로 크게 작용합니다(1비용 3스탯 → 4스탯 = +33 %). 바닐라 기준선이 한 단계 위로 올라가 빠른 덱만 이득.
3. **신규 유저 이탈**: 첫 랭크 판에서 돌파 덱을 만나면 같은 카드끼리도 짐.

완화 제안(최종은 balance-designer):
- 돌파 강화는 **작은 계단**(카드당 총 스탯 +1씩, 최대 +2 정도)과 **비용 비례**(저비용은 +1에서 멈춤)로 둡니다.
- 랭크전에 **돌파 정규화 모드**(모두 같은 단계로 계산) 또는 덱 강화 점수 차가 큰 상대를 매칭하지 않는 장치를 둡니다. 일반·이야기 모드에서는 강화가 그대로 적용.
- 돌파 일부 단계는 **외형·연출·보조 효과**(첫 등장 연출, 카드 테두리)로 채워 성장감을 성능과 분리합니다.
- 중복이 경험치가 되므로, 원하는 카드를 얻는 길로 **카드 지정 교환 재화**(예: 돌파를 다 채운 뒤 남는 경험치 → 재화)를 별도로 둡니다.

## 9. "치열한 승부"를 만드는 장치

### 9-1. 역전 장치

| 장치 | 작동 | 효과 |
|---|---|---|
| 전체 피해·전체 제거 | 지는 쪽(필드 열세)이 한 장으로 필드를 뒤집음 | 필드 우위가 고정되지 않음. 대신 너무 싸면 어그로가 죽음 |
| 후반 큰 카드 | 마나 상한 10까지 성장 → 늦게 갈수록 한 장 가치가 큼 | 초반 열세 → 후반 역전 이야기 |
| 회복·방어도 | 체력 차를 되돌림 | 마무리 턴을 한 턴 미룸 |
| 직접 피해 마무리 | 필드가 없어도 손패 주문으로 끝냄 | 이기던 쪽도 방심 못 함(체력 낮으면 위험) |
| 손패 장수 | 필드는 밀려도 손패가 많은 쪽이 후반 우세 | 필드 우위 ↔ 손패 우위가 서로 상쇄 |
| 후공 보상 카드 | 후공에 카드 1장 + 한 번 마나 +1 | 선공 템포 우위를 일부 상쇄(편차를 약 1~5 %p로 줄임) |
| 피로 | 덱이 먼저 빈 쪽이 매 턴 늘어나는 피해 | 컨트롤 대결이 무한히 늘어지지 않게 끝을 만듦 |

### 9-2. 손패 자원 관리

- 매 턴 1장 드로우 + 효과 드로우가 유일한 자원 유입. "필드에 다 쓰기(템포)" vs "아껴두기(전체 피해 대비)"가 핵심 판단.
- 손패 상한 10과 넘침 버림이 "드로우만 쌓기"를 막음.
- 상대 손패 장수가 공개돼 있어(내용은 비공개) 상대의 남은 답(제거·전체 피해)을 추정하는 심리전이 생김.

### 9-3. 무작위성의 역할

| 무작위 | 역할 | 과하면 |
|---|---|---|
| 드로우 순서 | 매 판 다른 전개, 멀리건으로 일부 통제 | 핵심 카드가 안 오면 실력과 무관하게 패배 |
| 무작위 대상 효과(무작위 피해 분배 등) | 큰 반전 순간 | "운 게임" 불만 |
| 후보 셋 중 고르기 | 무작위 + 선택이라 실력 개입 | 상대적으로 불만 적음 → **선호** |
| 선후공 | 판마다 바뀜 | 편차가 크면 불공정 |

설계 감각: **"무작위 후보 + 내 선택"**은 접전을 만들고, **"결과가 바로 무작위"**는 역전감은 크지만 실력감을 깎습니다.

### 9-4. 접전 비율을 높이는·낮추는 요소

| 높임 | 낮춤 |
|---|---|
| 마나 +1 성장으로 양쪽 힘이 같이 큼 | 선공 1~2턴 강한 카드(템포 눈덩이) |
| 하수인 교환 시 동시 피해(일방 학살 어려움) | 저비용 과스탯 카드(바닐라 기준 초과) |
| 공격 대상 강제 하수인(어그로 속도 조절) | 한 장으로 필승 상태가 되는 콤보 |
| 전체 피해(필드 눈덩이 차단) | 너무 싼 전체 제거(어그로 소멸 → 컨트롤만 남음) |
| 후공 보상 | 회복이 과하면 판이 늘어지고 결말이 뻔함 |
| 손패 공개 장수(예측 심리전) | 돌파 강화 차이(우리 고유 위험) |
| 피로(끝을 보장) | 상성이 너무 극단(75:25 이상) — 덱 고를 때 이미 승부 결정 |

## 11. balance-designer에게 넘길 정량 목표 후보

AI 대 AI 시뮬레이터(node)에서 잴 지표 후보입니다. 정의는 1-1에서 balance-designer가 확정하고 criteria에 덧붙입니다.

| 지표 | 정의 제안 | 목표 후보 | 레퍼런스 근거 |
|---|---|---|---|
| 아키타입 전체 승률 | 각 아키타입(영웅·덱) vs 나머지 전체 가중 평균, 같은 AI 수준 | **모든 아키타입 45~55 %**, 최고−최저 ≤ 8 %p | 4절 랭크 메타 폭 45~55 %(추정) |
| 매치업 승률 매트릭스 | 아키타입 쌍마다 선후공 반반, 쌍당 2,000판 이상(95 % 신뢰구간 약 ±2.2 %p) | **모든 칸 35~65 %**, 70 % 넘는 칸 0, 상성 고리(가위바위보)가 최소 1개 | 4절 매치업 35~65 %(추정), 6절 상성 |
| 접전 비율 | **승자의 마지막 체력(방어도 포함) ≤ 10**(= 시작 체력의 1/3)인 판 비율 | **40~60 %** | 추정. 레퍼런스는 직접 피해 마무리 구조라 승자 체력이 낮게 끝나는 판이 많음 |
| 일방 비율 | 승자 마지막 체력 ≥ 20 이고 패자가 7턴 이전에 진 판 | **≤ 15 %** | 추정 |
| 역전 빈도 | 각 턴 종료 시 "형세 점수" = (내 영웅 체력 − 상대) + 0.5 × (내 필드 공+체 − 상대) + 2 × (손패 장수 차). 어느 시점이라도 형세 점수가 −10 이하로 뒤졌던 쪽이 이긴 판 비율 | **15~30 %** | 추정. 9절 역전 장치가 실제로 작동하는지 확인 |
| 주도권 교체 | 한 판에서 형세 점수 부호가 바뀐 횟수 | 평균 **≥ 2회** | 추정 |
| 선후공 편차 | 전체 선공 승률 − 50 % × 2 (= 선공 − 후공) | **전체 ≤ 4 %p**, 아키타입별 ≤ 8 %p | 레퍼런스 시기별 1~5.75 %p, 빠른 덱 10 %p 넘으면 문제로 지적됨 [7] |
| 게임 길이 | 마지막 턴 번호(각자 기준) | 전체 중앙값 **7~9**, 빠른 덱끼리 ≥ 5.5, 느린 덱끼리 ≤ 14, 무승부 ≤ 1 % | 레퍼런스 7.4~7.8, 덱 평균 6.5~11.5 [10] |
| 마나 사용률 | 각 턴 쓴 마나 / 가능 마나, 1~6턴 평균 | 미드레인지 기준 **≥ 75 %** | 추정. 곡선이 실제로 작동하는지 |
| 마나 곡선 평균 | 덱 평균 비용 | 어그로 2.0~2.7, 미드 2.8~3.6, 컨트롤 3.6~4.5 | 4절 추정 |
| 바닐라 기준선 | 효과 없는 하수인 공+체 = 2 × 비용 + 1 (1~2비용 +1 허용), 효과 가치는 표로 환산 | 모든 하수인 "스탯 + 효과 환산"이 기준선 ±1 | [19][20] |
| **돌파 강화 허용치** | 같은 덱, 돌파 최대 vs 돌파 0으로 맞붙인 승률 | **≤ 55 %**(정규화 안 하는 모드 기준). 카드당 총 스탯 증가 ≤ +2(1~2비용은 +1). 돌파 적용 후에도 위 매트릭스 35~65 %·아키타입 45~55 % 유지 | 7-3. Clash Royale식 레벨 차 지배를 피함 |
| 돌파 정규화 모드 | 랭크전은 모든 카드를 같은 단계로 계산할지 | balance-designer가 1-1에서 결정 | 7-3 |

시뮬레이터 주의(추천):
- AI가 단순 탐욕이면 어그로가 과대평가됩니다(컨트롤의 "아껴두기" 판단이 없음). **AI 수준 2단계 이상**(탐욕 / 한 턴 앞보기)으로 매트릭스를 따로 내고 둘 다 폭 안에 드는지 봅니다.
- 시드는 판마다 다르게, 병렬 시 시드 인자를 나눕니다(insights QA 절 "고정 시드 병렬" 항목).
- 접전·역전 정의는 체력 30·필드 5칸 전제입니다. 수치가 바뀌면 비례로 고칩니다(접전 = 시작 체력의 1/3).
