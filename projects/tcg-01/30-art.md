## 1. 아트 방향

**한 줄**: "흑조 위에 놓인 소금유리 패" — 어두운 젖은 바닥(흑조) 위에서 밝은 것은 **소금(흰 판)과 심지 불빛(호박색)**뿐인, 법정처럼 정돈된 결투판.

키워드 (모두 이 세계의 말에서 나옴, 레퍼런스 화풍 모방 없음):
1. **소금유리 판** — 카드는 모서리가 한 곳 깨진 직사각 판. 둥근 장식·금속 테두리·보석이 없음.
2. **새김 홈** — 장식 대신 판에 파인 선(음각). 돌파할수록 홈이 깊어짐.
3. **심지 불빛** — 비용·공격 가능·턴 타이머가 모두 "초와 불꽃" 하나의 기호 체계.
4. **흑조** — 큰 순간(심해 희귀도·마지막 일격·공허 호명)에만 화면 아래에서 검은 물과 청록 빛이 솟음.
5. **조수원** — 보드는 젖은 소금 바닥 위의 점선 고리. 판이 길어질수록 바닥이 조금씩 젖어 어두워짐(세계관 "젖은 소금").
6. **평면 도형 + 낮은 채도 + 한 점의 강조색** — 리소스는 임시(도형 SVG)지만 색·형태 규칙으로 세계관 분위기를 냄.

형태 언어(실루엣만으로 구분):
| 대상 | 형태 | 이유 |
|---|---|---|
| 응답자 카드 | 오른쪽 위 한 모서리 깨진 직사각 + 아래 가운데 매달린 스탯 판 | 소금유리 판 |
| 의식 카드 | 위 두 모서리 깨짐 + 아래 가장자리가 물마루(물결) | 한 번 타오르고 사라지는 공식 |
| 인장 카드 | 응답자 판 + 스탯 판(공격·새김 수) | 무기 |
| 보드 위 응답자 | 이름·글 없는 축소 판(그림 + 스탯 줄) | 작은 화면에서 숫자만 읽히게 |
| 호명자(영웅) | 한 모서리 깨진 세로 판 + **아래 가운데 매달린 [껍질 | 명줄] 판**(카드 스탯 판과 같은 언어, 1-2 수정. 후공은 시작부터 껍질 2 표시 — balance `second_start_armor`) | 둥근 초상 틀(레퍼런스) 회피 |
| 버튼 | 한 모서리 깨진 사각(같은 판 언어) | 모든 조작 요소가 "판" |

## 5. 연출 — **템포감·몰입감이 최우선** (요청자 지시 2026-11-17, `art.json tempo`)

### 5-1. 원칙 5개
1. **로직 먼저, 그림은 뒤따름**: 입력 순간 규칙 엔진이 결과를 확정하고, 연출은 확정된 결과를 보여 주기만 합니다(시뮬레이터와 같은 엔진).
2. **입력 후 첫 반응 ≤ 100 ms**: 손가락이 닿은 프레임(≤ 16 ms)에 카드가 들리고 테두리가 켜지며, ≤ 30 ms에 소리가 시작됩니다.
3. **빈 대기 0**: 연출마다 `lock_ms`(다음 입력을 못 받는 시간)를 따로 두고 대부분 0~150 ms입니다. 잠금 중 입력은 버리지 않고 **예약(최대 3개)**, 예약이 있으면 남은 연출을 **2배속**으로 감습니다. 어떤 연출이든 탭하면 끝 상태로 바로 넘어갑니다.
4. **강약**: 잔 행동은 짧고 조용하게, 큰 순간만 길고 강하게(5-3). 한 판에 tier 3이 드물어야 효과가 있습니다.
5. **빠르게 보기**(설정): 시간만 줄이고 정보(피해 숫자·사망·발동 표시)는 하나도 빼지 않습니다(criteria 시각 절 tcg-01 줄).

### 5-6. 몰입 장치
- **호명자 대사**(10-lore 4절 대사표): 말풍선 1800 ms(빠르게 1000), 입력을 막지 않음, 같은 호명자 20 s 안 반복 금지. 언제: 판 시작(상대 → 600 ms → 나), 각자 첫 큰 카드, 상대 명줄 ≤ 10(위협, 한 판 1회), 내 명줄 ≤ 10(한 판 1회), 역전, 승패.
- **명줄 위기 분위기**: ≤ 10 → 화면 가장자리 붉은 기 18 %·1.8 s 숨쉬기, 음악 저역 통과 900 Hz, 지속음 반음 올림 / ≤ 5 → 30 %·1.2 s, 600 Hz, 온음 올림, 1.2 s마다 낮은 쿵 소리.
- **치명 가능 표시**: 내 공격만으로 상대를 쓰러뜨릴 수 있으면 상대 명줄 실이 가늘게 떨림(내 화면만).
- **턴 타이머(50 s, balance 확정)**: 앞 35 s는 가운데 띠에 흐린 선(35 %)만 — 시간 압박을 주지 않음. **남은 15 s**부터 심지 선이 켜져 왼쪽으로 타들어 가고 1 s마다 작은 타는 소리, **남은 5 s**부터 끝 불꽃이 붉어지고(#FF6F5E) 0.5 s마다 소리. 0 s에 자동으로 숨 고르기(`turn_auto_end`). 한 턴 내내 아무것도 안 해서 다음 턴이 15 s로 줄면 처음부터 타는 상태 + 짧은 초 아이콘. 첫 물때(멀리건) 30 s도 같은 선. 상대 턴에는 상대 쪽 끝에서 같은 선이 탐(AI는 12 s 상한이라 보통 경고 전에 끝남).
- **젖어 가는 바닥**: 턴 8부터 턴마다 조수원 바닥 1.5 %씩 어두워짐(최대 15 %) — 판이 길어질수록 긴장.
- **사운드 강약**: 5-3 표의 효과음 dB와 음악 낮춤. 큰 순간 직전 0.2 s 음악이 빠지는 "숨 멈춤"(tier 3만).

### 5-8. 구현 권장: **DOM(카드·UI) + Canvas 한 장(효과)**
- 카드·손패·버튼·메뉴는 **DOM + CSS transform/opacity만**으로 움직임(합성 단계만 쓰므로 모바일에서 60 fps 유지 쉬움, 글자 선명, 접근성 트리·`aria` 지원, 4해상도 배치를 `art.json` 사각형 그대로 적용).
- 초상은 카드 DOM 안에 SVG 노드로 넣지 않고 **생성 SVG → blob URL `<img>` 캐시**(200장 305 KB, 노드 수 절감).
- 입자·공격 궤적·대상 화살표·흑조 물결·흔들림 잔상은 **화면 전체 Canvas 2D 한 장**에서 그림(입자 예산 모바일 120 / 데스크톱 300).
- 화면 흔들림은 보드 컨테이너 하나에 transform. 큰 카드 등장의 어둡게 하기는 Canvas 위 반투명 층.
- 판 시작 전(첫 물때 화면 뒤)에서 양쪽 덱의 초상을 미리 만들어 두어 첫 카드 내기의 프레임 튐을 막음(insights 구현 절 "첫 그림 미리 그리기").
- 시간 값은 `art.json tempo`만 읽고, 모든 연출 시계는 게임 시계(배속 반영)로 돌림(insights runner-01 "게임 시간 기준 UI 타이머").

## 6. 사운드 방향 (`art.json sound`, Web Audio 합성)

공통 바탕 "마른 바다": 55 Hz 톱니 지속음(저역 통과 320 Hz) + 유리 배음(440·660·990 Hz 사인, 아주 작게) + 3~7 s 간격 물방울. 레퍼런스의 선술집 류트·민속 합주 느낌을 쓰지 않습니다.

효과음 29종(`sound.sfx`: 파형·주파수·길이·목표 dB·필터): 카드 들기·내기·뽑기, 심지 켜짐, 타격 약·강(공격력 비례), 소금막 깨짐, 부서짐, 썰물, 의식, 회복·강화·약화, 소금독 틱, 방파제 막음, 봉인문, **큰 카드 등장**(저음 일렁임 + 유리 화음 2 s), 내 차례, 타이머, 공허 호명, 상자 뚜껑, 덩이 부서짐 4단계(모래 잡음 → 진주 유리 1음 → 산호 2음+저음 → 심해 흑조+4음), 승리(장3도 상행)·패배(단2도 하행), 메뉴 탭·거부. 크기 순서 목표: 큰 카드·심해 덩이 > 타격 강 > 카드 내기 > 잔 행동. 1-2에서 빌드 OfflineAudioContext 렌더로 실제 크기를 재고 이 표와 1 dB 이내로 맞춥니다(criteria 시각 절 rhythm 항목, insights 시각 절).
