# 1-0 Hearthstone 시스템 벤치마크

## 요청 받은 일
오케스트레이터가 PIPELINE 1-0으로 `projects/tcg-01/00-benchmark.md` 작성을 요청. 레퍼런스 Hearthstone의 시스템 감각만 공개 자료로 조사하고, balance-designer의 AI 대전 시뮬레이터 목표값 후보를 넘기라는 지시. 요청자 지시: 하스스톤과 비슷한 느낌, 세계관·컨셉별 밸런스가 핵심, 카드 200장(드로우버프 20 / 버프 120 / 공격 60), 중복 = 동일 카드 경험치 → 돌파 강화, 품질 = 대결의 치열함.

## 한 일
1. 공통 지시 블록, CLAUDE.md, PIPELINE(끝 tcg-01 예외 줄), criteria, insights, STATUS 원문, 역할 정의를 읽음.
2. 위키(턴·멀리건·피로·손패·팩·제작·영웅 능력), 통계 사이트 분석(선후공 편차, 게임 길이), 공식 포럼 데이터 글, 커뮤니티 바닐라 테스트 분석, 다른 카드 게임(Clash Royale 레벨 상한, Marvel Snap 외형 업그레이드)을 조사.
3. 적합성 판정: 5~6세·약한 아트는 요청자 지시로 예외 적용(사유 기록), 원본 보호 적합성은 "적합".
4. 00-benchmark.md 0~12절 작성: 규칙 수치표, 게임 감각 수치(출처·추정 구분), 기능명 기믹 어휘 23개, 아키타입 5종과 상성, 메타 콘텐츠와 돌파 강화 위험 분석, 연출, 치열함 장치, 가져올/바꿀/안 가져올 표(세로 화면 필드 5칸 등), 정량 목표 후보표, 원본 보호 체크리스트.
5. (작업 중 요청자 추가 지시 반영) 대상 연령 18세 확정 → 1절 타깃 유저를 "18세(요청자 확정)"로 바꾸고 성인 TCG 기준표(카드 텍스트 복잡도·키워드 수·덱 빌딩 깊이·정보 공개·판 길이·확률 공개)를 넣음. 10절 키워드 수를 10~12개 → 14~18개로 바꾸고, 텍스트 복잡도·덱 빌딩 깊이를 "가져올 것"으로 추가. 0절 판정표 연령 문구 갱신. 게임 이름은 팀이 정함.
6. 키워드 공식 한국어 번역어(발견·연계·은신·빙결류)가 섞이지 않도록 기능명으로 바꿔 다시 확인.

## 검증 결과
- 수치마다 출처 번호를 달았고, 원문으로 확인 못 한 값(마나 곡선 평균, 아키타입·매치업 승률 폭, 드로우 가치, 일일 보상 세부)은 "추정"과 근거를 적음. 통계 사이트 매치업 표는 이미지·403이라 원문 수치 확인 못 함.
- 원본 보호 자기 검사: 문서에 레퍼런스 카드 이름·카드 글·영웅 이름·세계관 용어 없음. 키워드는 기능명만(공식 번역어 grep으로 확인 후 교체). 레퍼런스 덱 이름(카드 이름이 들어간 것)도 넣지 않음.
- 실측은 하지 않음(공개 자료로 1-0 범위 충족, 12절에 필요 시점 기록).

## 문제·남은 일
- minor (balance-designer): 턴 수 정의(각자 턴 번호 vs 양쪽 합 반턴)는 1-1에서 balance-designer가 하나로 정함. 그래야 목표 7~9가 의미 있음.
- minor (balance-designer): 돌파 강화를 랭크전에서 정규화할지 1-1에서 balance-designer가 정함(7-3, 11절). 정규화하지 않으면 "같은 덱 돌파 최대 vs 0 승률 ≤ 55 %"를 지켜야 함.
- minor (balance-designer, lore-writer 협조): 중복이 경험치가 되면 원하는 카드를 얻는 길이 없어짐 → 지정 교환 재화 등 수단을 1-1에서 balance-designer가 정함.
- minor (art-director·game-developer): 세로 360 px에서 필드 7칸은 칸당 약 50 px라 5칸(추천) 또는 6칸으로 줄이자고 제안. 줄이면 balance가 군단·전체 버프 세기를 다시 맞춰야 함.
- 참고(오케스트레이터): 실결제가 없어도 팩 개봉이 무작위 보상이라 모바일 출시 때 연령 등급 표기 확인 필요.
