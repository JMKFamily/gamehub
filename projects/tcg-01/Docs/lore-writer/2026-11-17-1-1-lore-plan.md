# 1-1 세계관·영웅·카드 200장 설정 (썰물 영장)

- 날짜: 2026-11-17
- 역할: lore-writer
- 프로젝트: tcg-01
- 단계: 1-1

## 요청 받은 일
오케스트레이터가 1-1 세계관 작업을 요청. 요청자 지시 요지: "작가의 세계관 설정이 가장 중요", 세계관에 맞는 특징적인 메인 캐릭터(영웅), 카드 200장(드로우버프 20 / 버프 120 / 공격 60 = 즉시타격 18 : 드로우 42, 갈래 여러 개), 이름은 팀이 모두 결정(검색 충돌 확인), 대상 18세 확정. 작업 중 정정: 키워드 수는 00-benchmark 1·10절 기준 **14~18개**, 키워드당 평균 8장 이상, 카드 글은 확대 화면 3줄 이내.

## 한 일
1. 필수 문서(CLAUDE.md, PIPELINE 끝 tcg-01 예외·대상 연령 줄, criteria, insights, STATUS, 00-benchmark, 킥오프 공통 지시 블록, 역할 정의) 확인.
2. 게임 이름 후보 3개를 WebSearch로 확인하고 **썰물 영장 (Ebbwrit)**으로 확정. 검색어와 결과 요지는 10-lore 1절에 적음. "Tidecaller"가 MTG 카드 이름과 겹치는 것을 찾아 쓰지 않음.
3. 세계관 작성: 바다가 빠진 세계(노해), 참이름을 새긴 영장, 심지(마나)·명줄(체력)·껍질(방어), 흑조와 소금 맹약으로 "왜 카드로 싸우는가"를 설명. 연표·지리·세력 6·갈등, 게임 용어 대응표를 정하고 레퍼런스 기본 용어(하수인·방어도·마나 수정·동전)는 쓰지 않음.
4. 호명자 6명(성격·동기·라이벌·대사 7종·호명술·아키타입 3개·시각 힌트)을 쓰고, 상성 고리(어그로·미드·컨트롤·콤보·주문·템포)를 세계관 라이벌과 겹치게 짬.
5. 배분: 영웅 전용 25 × 6 + 공용 50. 갈래 27개(드로우버프 5, 버프 13, 즉시타격 3, 드로우형 6), 혈통(태그) 7개, 희귀도 4단계(모래·진주·산호·심해).
6. 키워드 18개를 새로 지음(첫 숨·썰물·방파제·소금막·물안개·박차·급류·익사·들이켬·이름 지우기·닻·잉걸·봉인문·그을음·뒷물결·인양·차오름·소금독).
7. 메타 포장: 인양 상자(팩)·세력 상자 6종·등대 보장(천장), 소금화·각인 먹·심해 진주, 공명(경험치)·새김 돌파 4단계, 조수 달력·의뢰·순위 띠·모드 4종.
8. UI 텍스트 키 표 약 230개(ko/en), 스토어 문구 초안.
9. 카드 200장 `cards-lore.json` 작성, 검사 스크립트 `check-cards.mjs` 작성·실행.

## 다른 팀에 줄 인사이트
- 이름 검색은 후보 이름만이 아니라 **세력·영웅 이름에 쓸 흔한 조어**(예: Tidecaller)도 함께 검색한다. 후보 게임 이름은 깨끗했지만 세력 이름 후보가 MTG 카드 이름과 겹쳐 있었다.
- 레퍼런스의 **기본 용어**(하수인·방어도·마나 수정·동전 같은 공식 번역어)도 원본 보호 대상이다. 키워드만 바꾸고 기본 용어를 남기면 화면 전체가 레퍼런스처럼 읽힌다. 세계관 문서에 "장르 기능 → 우리 용어" 대응표를 먼저 만들면 UI·카드 글·튜토리얼이 같은 말을 쓴다.
- 대량 카드 데이터는 손으로 JSON을 쓰기보다 한 줄 = 한 카드 원본 + 생성 스크립트 + 검사 스크립트(개수·비율·배분·키워드 등장 수)로 만들면, 비율을 맞추느라 다시 세는 일이 없어지고 다른 역할이 같은 검사를 다시 돌릴 수 있다.
