# 카드 스토리 200장 (세력별 이야기 줄기)

- 날짜: 2026-11-18
- 역할: lore-writer
- 프로젝트: tcg-01
- 단계: 검수 피드백 반영

## 요청 받은 일
요청자 지시: "카드 정보 쪽을 탭하거나 또는 스토리 버튼을 두고, 각 카드 컨셉별로 세계관에 맞는 짧은 스토리를 주세요." 오케스트레이터가 요청한 것은 다음과 같습니다.
- 200장 `story_ko`·`story_en`(키 이름 고정)
- 세력별 이야기 줄기와 카드 순서
- UI 키
- 검사 추가와 셀프 리뷰
- 작업 중 추가 요청: 용어 치환 부작용(`lineage_drowned` "즉사자") 확인

## 한 일
1. 세력 7개(영웅 6 + 공용)로 나눠 카드 200장의 이야기를 ko/en으로 썼습니다(2~4문장, ko 80~160자). 효과가 왜 그런지 사연으로 풀었고, flavor와 겹치지 않게 했습니다.
2. 10-lore 5-5에 세력별 이야기 제목, 한 단락 줄기, 읽는 순서를 넣었습니다.
3. 8-11에 카드 스토리 UI 키 30개를 넣었습니다(버튼·패널·탭·대전 중 안내·순서·잠금·정렬·세력 이름·이야기 제목).
4. `check-cards.mjs`에 다음 검사를 추가했습니다.
   - story 누락, 길이, 문장 수
   - flavor와 같은 문장
   - 금지어, 옛 기능어
   - 5-5 순서 = 세력 카드 목록
   - 세력 이름·이야기 제목 키는 이야기 키로 분류
5. 치환 부작용 4곳을 고쳤습니다: 익사자 합창회와 `lineage_drowned`, 렌 동기 문장, 이브로 플레이 정체성, 5-1 문장. 4~10절 문장도 낱말 단위로 재확인했습니다.
6. `reviews/terms/lore-writer.md`에 "카드 스토리" 절(셀프 리뷰와 dev·art 전달)을 추가했습니다.

## 다른 팀에 줄 인사이트
- 일상어로 쓴 이야기 문장에도 원작 공식 키워드와 같은 낱말(전장·비밀·침묵, en charge·silence·secret·armor 등)이 자주 섞입니다. 이야기 글에도 같은 금지어 검사기를 돌려야 합니다.
- 카드 이야기는 카드마다 따로 쓰기보다 세력 줄기와 읽는 순서를 먼저 정하고 쓰면 이어 읽을 때 이야기가 됩니다. 검사기로 순서 목록과 카드 목록이 같은지 확인하면 빠지는 카드가 없습니다.
