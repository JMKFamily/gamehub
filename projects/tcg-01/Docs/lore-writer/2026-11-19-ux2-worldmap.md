# UX 흥미: 월드맵 스토리·덱 그림 튜토리얼·로비 문구

- 날짜: 2026-11-19
- 역할: lore-writer
- 프로젝트: tcg-01
- 단계: 검수 피드백(UX를 흥미롭게)

## 요청 받은 일
요청자 지시 "이제 UX를 흥미롭게 만들 차례입니다" 11항목 중 lore 몫.
- 월드맵 스토리: "스토리는 이미지가 중요합니다. 이야기를 노출하되 월드맵을 탐험하며 나아가는 느낌을 주세요."
- 덱 그림 튜토리얼 문구
- 퀘스트 위젯·시즌 보상 트랙 문구
- 상대 실력 이름(쉬움부터)
- 팩 연속·모두 열기 문구
- 수집 "이야기" 버튼 문구
심지 표현과 쉬운 용어는 유지합니다.

## 한 일
1. `lore/worldmap.json` 노해 지도를 만들었습니다.
   - 지역 8곳: 맹약 시장, 세력 6곳, 흑조의 균열
   - 노드 30개: 지역 id·제목·본문 ko/en, 여는 조건 제안, 연결 카드 스토리 3장, 좌표, 그림 힌트
   - 5-5 세력 이야기 줄기를 따라가고, 마지막은 흑조의 균열입니다.
2. art가 바로 쓰도록 노드 목록을 먼저 `reviews/ux2/lore-writer.md`에 저장했습니다.
3. 10-lore 7-6에 월드맵 탐험 흐름·조건·노드 순서를 넣고, 8-14에 UX 키 약 60개를 넣었습니다(월드맵, 덱 그림 튜토리얼 5, 퀘스트 위젯, 시즌 트랙과 5구간 이름, 상대 실력 4단계 이름과 쉬운 부제, 팩 연속·모두 열기, 수집 이야기 버튼).
4. `check-cards.mjs`
   - 월드맵 검사를 추가했습니다: 필드, 본문 길이와 문장 수, 제목 길이, 카드 연결 세력, 여는 조건 형식, 금지어·옛 용어·"마나".
   - 튜토리얼 열 파서도 4열 키 표에 맞게 고쳤습니다.
