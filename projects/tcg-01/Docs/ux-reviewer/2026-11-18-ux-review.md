## 검증 결과
- 블라인드 정확도(채점 18장/시각): 유형 12/18(67 %), 종류 18/18(100 %) — 정상·protan·deutan·tritan 모두 같음. 표지가 보이는 카드만은 유형 12/12. 틀린 6장은 모두 부채꼴 손패에서 표지가 가려진 카드.
- 범례 없이: 같은 유형끼리 같아 보임(예), ■ 공격하며 뽑기만 소거법으로 맞힘. 범례 한 번 보면: 보이는 표지 100 %, 가려진 카드는 여전히 못 맞힘.
- 부채꼴 겹침 계산: 360x640 5장 70 %·7장 46 % 노출, 표지는 카드 폭 67~93 % 자리 → 5장부터 가려짐(직접 8장 확인: 7장 안 보임).
- 불가 피드백: 마나 부족 시 150 ms 안 칩 + 막대 테두리 확인. 정렬 유형순 동작 확인.
- 못 한 것: 4해상도 전부 직접 조작(360x640만, 나머지는 QA 사진·코드 계산), 화면 낭독기 트리 점검.
