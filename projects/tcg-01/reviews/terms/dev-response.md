## art-director 구현 목록

| 1 유형 한눈 구분 | 수정 | sync가 `spec.mjs familyOf`로 카드마다 유형(draw·buff·debuff·strike·atkdraw)을 넣고, `assets.mjs familyBadgeSVG`(유형 모양 + 갈래 도형)·`familyPattern`(띠 무늬)을 `data/ux-icons.json`으로 묶음. 빌드 DOM 카드: 이름 띠 = 유형 색 + 무늬, 그림 창 오른쪽 위 유형 표지 34 px(손패 64 px ≈ 1.6배), 무기 가로 날밑, 종류 실루엣(소환수 한 모서리·주문 두 모서리 + 물결·무기 날밑) 유지. 필드 토큰 위 6 px 유형 띠 + 표지 24 px. 수집·덱 빌더·팩 공개·확대·손패 모두 같은 카드 함수. 종류 줄 = 소환수/주문/무기 · 부류 또는 세력 |
| 2 정보 위계·손패 비교 | 수정 | 손패: 이름 숨김, 비용·스탯·유형 표지 크게. 낼 수 있는 카드 4 px 들림 + 주황 2 px 테두리, 못 내는 카드 명도 60 %, 상대 턴 손패 70 %. 펼침: 손패 6장 이상에서 카드 탭 또는 손패 빈 곳 탭 → 세로 2줄 × 5 / 가로 1줄 × 10, 이름 다시 보임, 48 px 정렬 버튼(비용순 ↔ 유형순), 바깥 탭으로 닫힘 |
| 3 안 되는 이유 | 수정 | 10가지 모두: 마나 부족(모자란 막대 붉은 테두리), 필드 가득(내 5칸 깜빡), 대상 없음(카드 ⊘ + `toast_no_target`), 막 나온 소환수·속박(그 소환수 흔들림·빛남), 방벽 먼저(방벽 소환수 깜빡), 위장(대상 빛남), 고유 능력 사용함(✓), 상대 턴(가운데 띠), 손패 넘침(덱 표시). 공통: 5 px·120 ms 흔들림, `ui_deny`, 180 ms 뒤 카드 제자리, 이유 칩(art 색·13 px) 1.2 s(게임 시계). 미리 표시: 못 내는 카드 어둡게, 꺼진 심지 아이콘, 상대 턴 손패 70 % |
| 4 튜토리얼·안내·용어 사전 | 수정 | 대전 튜토리얼 14단계(마나 → 낼 카드 없음 → 소환수·주문·무기 → 필드 → 공격 → 고유 능력 → 방어 → 턴 종료 → 방벽 → 키워드 → 체력 → 덱 고갈): 표 순서 대기열, 조건이 맞는 첫 순간 하나만, 1턴 낼 카드가 없으면 `tut_no_play`, `tut_end`는 낼 카드/낼 카드 없음 안내 뒤, 지나간 단계는 다음 기회에. 대전 밖 단계(`tut_hero`·`tut_deck`·`tut_mulligan`)는 해당 화면 첫 진입, `tut_done`은 결과 화면을 닫은 뒤. 패널·다음·건너뛰기 자리는 `ux.tutorial_layout[해상도].slots_px`·`plan`, 스포트라이트(50 % 어둡게, 여백 8)·#7FE3FF 고리 1.2 s·점선 화살표·끌기 단계 손가락 원 28 px 반복. 잠금 0, 패널 밖 탭으로 넘김(행동 단계는 그 행동으로). 본 단계·건너뛰기 저장 → 다시 안 뜸, 설정 "튜토리얼 다시 보기"로 초기화. 메뉴 안내 8개(카드 팩·제작·카드 경험치/돌파·랭크전)는 같은 패널로 한 번만. 용어 사전: 검색 48 px → 유형 범례(type-*·kind-*) → 기본 용어·키워드 두 묶음, 줄 ≥ 56 px(아이콘 32·용어 16·설명 13·흔히 부르는 말 12), 가로 2열. 새 아이콘(icon-ability·board·kin·breakthrough·rank) 사용. 팩 개봉 덩이를 카드 뒷면 비율 5:7로 |
