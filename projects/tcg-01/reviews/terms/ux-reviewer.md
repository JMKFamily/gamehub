- **틀린 6장은 모두 같은 원인**: 기본 대전 화면의 부채꼴 손패에서 유형 표지(카드 오른쪽 위 67~93 % 자리)가 다음 카드에 덮임. 손패에서는 이름 띠(유형 색·무늬)도 숨겨져서 유형 단서가 **0개**.
- 색약: protan·deutan에서 즉시 타격(진홍 ◆)과 공격하며 뽑기(분홍 ■)가 둘 다 회색·올리브로 비슷해지지만 **모양(◆/■)과 도형(번개/칼·검)으로 맞힘**. deutan에서 약화 보라가 파랑으로 바뀌어 뽑기 파랑과 가까워지지만 ▼/● 모양이 달라 혼동 0. 색 하나에 기대지 않는 설계는 통과.

### 1-4. 두 가지 판정
- **범례 없이 "같은 유형끼리 같아 보이는가"**: 예. 약화 2장(▼↓·▼X), 공격하며 뽑기 2장(■칼·■검), 강화(필드·손패 ▲)가 바깥 모양·색으로 묶여 보임. 모양 뜻도 대부분 짐작됨(● 카드 묶음 = 뽑기, ▲ = 강화, ▼ = 약화, ◆ 번개 = 타격). **■ 분홍만 "남는 것"으로 맞힘** — 안의 칼 도형(적중 뽑기)이 "즉시 타격"처럼 읽혀 처음엔 망설임.
- **범례를 한 번 보면 맞힐 수 있는가**: 예, 표지가 보이는 카드는 12/12. 범례 띠(용어 사전 위)가 표지 5 + 실루엣 3을 한 줄에 보여 줘서 한 번에 익힘. 단, 부채꼴 손패에서 가려진 6장은 범례를 봐도 맞힐 수 없음(67 %에서 안 오름).

## 2. 그 밖의 UX 판정
- **정보 위계**: 비용(왼쪽 위 마나 판)이 부채꼴에서도 모든 카드에 보이고 가장 먼저 읽힘. 공/체 판도 아래에 보임. 유형 표지가 비용·스탯을 가리지 않음(30-art 11-3대로). → 통과. 다만 위계 3순위인 "유형"이 부채꼴에선 사라짐(이슈 1).
- **"왜 안 되는지"**: 마나 1에서 3코스트 카드 내기 → 150 ms 안에 "마나가 모자랍니다" 칩 + 마나 막대 붉은 테두리(`live-deny-no-mana-360x640.png`). 낼 수 없는 카드 60 % 명도(`.hcard.dimc`), 낼 수 있는 카드 주황 테두리·4 px 들림. 10가지 이유 모두 코드(`battle.js deny`/`denyAttack`)에 있음. → 통과.
- **손패 비교·정렬**: 6장 이상에서 손패 탭 → 2줄 펼침, 이름 다시 보임, 정렬 버튼 96×48(왼쪽 위). "유형순"이 ● ▲▲▲▲ ▼ ■■로 실제로 묶임(`live-spread-sort-family-360x640.png`). 좋음. 다만 버튼 글이 **"종류"**(유형순일 때)·"마나"(비용순일 때)라 용어 사전의 "종류 = 소환수·주문·무기"와 겹치고, 지금 상태인지 누르면 바뀔 상태인지 알 수 없음(이슈 5). 5장 이하는 펼침이 안 되는데, 5장부터 표지가 이미 가려짐(이슈 1).
- **튜토리얼 가리킴**: 스포트라이트 고리 + 패널 → 대상 점선 화살표 + 「다음」·「건너뛰기」 48 px, 한 번에 한 용어(`tut-360x640-02-tut_play_spell.png`). 좋음. QA가 잰 패널-대상 겹침(640x360·1280x720)과 360x640 「다음」이 덱 수를 덮는 것은 QA 이슈 3 그대로 동의. **유형 표지 5가지를 알려 주는 단계가 없음**(14단계 중 0, 이슈 3).
- **용어 사전 찾기**: 맨 위 검색 칸 + 유형 범례 띠(표지 5 + 실루엣 3) + 한 줄 = 아이콘·용어·설명·흔히 부르는 말. 찾기 쉬움. 범례 띠의 종류 실루엣 3개(소환수·주문·무기)는 약 18 px라 모서리 깨짐 차이가 거의 안 보임(이슈 6).
- **카드 스토리 열고 닫기**: 상세에서 글 상자 탭/「스토리」 버튼으로 열림, 닫기 4가지 모두 동작(QA 128/128). 그림·비용·이름·유형 표지가 그대로 보임. 대전 길게 누르기는 효과 먼저 + "이야기는 대전 밖에서" 안내 — 판단 정보 우선 원칙에 맞음. → 통과.
- **첫 사용 학습 흐름**: 영웅 → 덱 → 손패 바꾸기 → 마나 → 주문·소환수·무기 → 필드 → 공격 → 고유 능력 → 턴 종료 순서, 용어 첫 등장 때 한 문장. 좋음. 빠진 것은 "카드 오른쪽 위 표지 = 유형"(이슈 3)과, 수집 첫 진입 안내 패널이 카드 상세의 비용·유형 표지를 덮는 점(이슈 4).

## 잘 된 점
- 유형 표지 = 색 + 바깥 모양 + 안 도형 3겹, 확대·상세는 이름 띠 무늬까지 4겹. 색약 3종에서 정확도가 정상과 같음(색 하나에 기대지 않음).
- 요청자 발단 쌍(즉시 타격 ◆ 진홍 vs 뽑기 ● 파랑)은 표지가 보이는 모든 화면에서 0.5초 안에 구분됨.
- 필드 토큰 위 6 px 유형 띠 + 표지로 판 위 소환수 유형도 바로 보임.
- 불가 피드백: 칩 + 원인 요소 빛남 + 60 % 명도, 150 ms 안. 펼침 정렬이 실제로 유형별로 묶임.
- 용어 사전 맨 위 범례 띠, 스토리 패널이 판단 정보를 가리지 않고 대전에선 안 열림.
