# art-director: UX2 "모바일 게임형 화면" + 심지 촛불 — game-developer 구현 목록 (2026-11-19)

정본은 `30-art.md` 12절, 수치는 `art.json ux2`·`candle`·`ux.tutorial_layout`입니다. 목업은 `assets/samples/ux2-*.svg`(한눈 보기 `ux2-sheet.html`)입니다. 시작 전에 `art.json`·`assets/`를 빌드 `data/`에 다시 복사합니다. 대전 조작은 바꾸지 않습니다.

## 1. 메인 로비
1. 단순 메뉴 목록을 `ux2.lobby_rects_px["WxH"]` 사각형 배치로 바꿉니다.
   - 위 HUD: 레벨(경험치 고리)·재화 3·상점(오른쪽 위)
   - HUD 아래: **시즌 보상 트랙 위젯**
   - 왼쪽 가장자리: **퀘스트 위젯**(3줄 진행 막대 + 보상 아이콘, 완료 = 초록 + 빨간 점) + 이야기 지도
   - 오른쪽 가장자리: 카드 팩(배지)·수집·덱
   - 가운데 아래: 전투(큰 주황, 1.8 s 숨쉬기) + 양옆 돌파·제작
   - 왼쪽 아래: 설정
   - 배경: 영웅 큰 실루엣 + 등불 빛 + 흑조 물결
2. 시즌 위젯 내용: 단계 수, 눈금 막대(지난 단계 채움 + 다음 단계 큰 점), 다음 보상 그림(`crate-*.svg` 등). 탭하면 보상 트랙 화면으로.
3. 하위 화면 공통 틀: 위 HUD(제목 + 재화) · 왼쪽 아래 「뒤로」 · 가운데 아래 핵심 행동 하나.

## 2. 전투 진입
- 「전투」를 누르면 상대 실력 고르기 화면이 뜹니다(`ux2.difficulty`). 그림 카드 3장이고 **기본 선택은 쉬움**입니다.
- 단계 수·잠금 규칙은 balance 값을 따릅니다. 그 다음에 기존 영웅·덱 고르기가 이어집니다(순서는 balance·lore와 맞춤).

## 3. 덱 첫 화면
- 1차 버튼은 3개까지만 둡니다: 덱 그림 카드, 「+ 새 덱」, 「이 덱 편집」. 나머지는 「⋯ 더보기」로 접습니다.
- 첫 진입 때 그림 튜토리얼 4장을 띄웁니다(`ux2-deck-tutorial-4.svg`). 문구는 lore, 자리는 가운데 35~65 % 띠, 한 번만.

## 4. 튜토리얼 자리
- 대전 튜토리얼 패널 사각형이 바뀌었습니다(`ux.tutorial_layout`). 가로 화면은 두 필드를 세로 가운데로 옮기고 가운데 띠를 48 px로 키웁니다(`art.json layout.screens.640x360`·`1280x720` 사각형 재적용).
  - 보조 자리도 가운데 띠입니다(세로는 폭만 줄이고 「다음」을 왼쪽으로).
- 메뉴 튜토리얼도 패널 가운데가 화면 높이 35~65 % 안이고, 대상의 반대쪽 절반에 둡니다.

## 5. 수집 카드 보기
- 기본은 확대 카드 한 장(글 상자 포함)입니다.
- 「이야기」를 누르면 카드가 220 ms 동안 왼쪽으로 옮겨 가며 폭 46 %가 되고, 오른쪽 50 %에 이야기 판이 열립니다. 다시 누르면(「효과」) 되돌아옵니다.

## 6. 카드 팩 열기 3모드 (`ux2.packs`)
- 아래 버튼 줄은 「1개 열기」「다음 팩 (n)」「모두 열기 (n)」입니다.
- 연속 열기: 공개 뒤 가운데에 「다음 팩」 큰 버튼 + 요약 한 줄.
- 모두 열기: 희귀도 순 격자 + 희귀도별 장 수. 60 ms 간격으로 공개하고, 전설은 600 ms 멈춤(최대 3번), 전체 4 s 상한. 탭하면 남은 공개를 바로 합니다.

## 7. 이야기 = 월드맵
- `tools/art/ux2.mjs`의 `worldmapSVG(nodes)`를 빌드에서 그대로 쓰거나 그 결과 SVG를 씁니다. 노드 상태는 저장값에서 읽습니다.
- lore 노드 목록(`reviews/ux2/lore-writer.md`)이 확정되면 노드 배열로 넣습니다. 노드 하나는 `{id, region, title, state: cleared|current|locked, final}`이고, `region`은 `ux2.worldmap_regions` id 7개 중 하나입니다.
- 화면에서는 현재 노드를 가운데로 스크롤합니다. 아래 장 카드에 「들어가기」(48 px 이상)를 둡니다.

## 8. 심지 = 촛불 (`art.json candle`, `assets/candle-{lit,spent,spare,soot,empty}.svg`)
1. 대전 HUD의 심지 막대를 촛불 10자루로 바꿉니다(`A.candleRowSVG` 규칙). 순서는 그을음 → 켜짐 → 씀 → 빈 자리, 여분 심지는 오른쪽 끝.
2. 불꽃 흔들림: 촛불마다 `.flame` 그룹에 CSS로 rotate ±4°·scaleY 0.92~1.06, 1.1~1.7 s 주기, 위상 무작위. 캔버스로 매 프레임 그리기는 금지합니다.
3. 카드를 내면 오른쪽 켜진 촛불부터 비용만큼 꺼집니다.
   - 촛불마다 40 ms 간격, 불꽃 opacity 140 ms, 연기 160 ms, 전체 ≤ 500 ms, 입력 잠금 0.
   - 턴 시작에는 30 ms 간격으로 다시 켭니다.
4. 카드 비용 판이 촛농·심지가 있는 초로 바뀌었습니다(`cardSVG` 다시 생성).

## 9. 재질 보강 (12-9)
- 판·버튼에 목재 결 + 소금 껍질 윗선을 넣습니다(`ux2.mjs`의 `plate()`와 같은 모양, CSS 배경 SVG로 가능).
- 글자 색·대비, 유형 신호는 바꾸지 않습니다.
